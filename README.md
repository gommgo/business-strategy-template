# ST IT — шаблон проекта дизайна

Шаблон, который импортируется **под проект**. Дизайнер описывает интерфейс
аналитическими артефактами в `docs/interface/` и композицию/облик —
артефактами в `docs/screens/`. По `docs/screens/` автор макета **вручную**
собирает wireframe и hi-fi субстрат на библиотеке `@stit-design/ui`.

Поток: **аналитика интерфейса (7 файлов сущностей) → артефакты экранов
(4 kind) → wireframe → hi-fi субстрат.** Артефакты — чистая аналитика и
на код напрямую не мапятся; превращение в код — ручная работа автора
макета, не отдельный артефакт.

## Два репозитория

| Репо | Что | Роль |
|---|---|---|
| **этот** | артефакты аналитики интерфейса и экранов, воркфлоу скиллов | проектный шаблон |
| **`@stit-design/ui`** (репо `ui-lib`) | библиотека компонентов + галерея | потребляется как зависимость из Gitea registry |

Граница чистая: библиотека строится один раз и версионируется; проект её
**потребляет**, не правит.

## Структура

```
docs/interface/   аналитика интерфейса — source of truth (см. docs/interface/README.md):
  who.md           участники
  stage.md         этапы бизнес-процесса (порядок строк = порядок этапов)
  situation.md     ситуации (кто/когда/что/ради чего/с какими данными)
  zone.md          зоны интерфейса (parent-zone — вложенность)
  block.md         блоки (узел навигации + контейнер субстратов)
  ux-substrate.md  UX-субстраты (type + name + situation)
  data-items.md    элементы данных (entry/exit ситуации)
docs/screens/     аналитика композиции и облика (см. docs/screens/README.md):
  flows/           пользовательские сценарии (viewport-вариативность)
  screens/         route/view с типизированными слотами
  blocks/          раскрытие interface-block в дерево компонентов
  shells/          каркасы со слотами
  assets/          визуальные референсы артефактов
.claude/
  skills/          interface-deep-dive · interface-audit · screen-deep-dive · screen-audit
  rules/           forward-only
```

## Воркфлоу

```
1. /interface-deep-dive   — завести и углубить сущности в docs/interface/.
2. /interface-audit       — проверить консистентность артефактов интерфейса.
3. /screen-deep-dive      — синтезировать flows/screens/blocks/shells из interface.
4. /screen-audit          — проверить консистентность артефактов экранов.
```

## Инварианты

- **Forward-only** — только «что есть и куда идём», без журналов прошлого.
- **Артефакты — source of truth**, всё остальное собирается по ним.
- **Дизайн-облик — из craft-экспертизы библиотеки**, не из головы агента.
- **Коммит / push — гейт человека.** Без явной просьбы агент не коммитит.
