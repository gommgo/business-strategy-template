### 1.3. Токены и дизайн-система (фокус)

**Что есть** (09/04, 14/08, генератор):
- **Формат** — DTCG 2025.10, `$schema` `https://www.designtokens.org/schemas/2025.10/format.json`:
  - `dimension` — объект `{value, unit}` в px или rem;
  - `lineHeight` — число;
  - цвет — `{colorSpace: oklch, components, hex}`.
- **Два уровня**: 104 примитива + 185 семантических = 289. По группам: primitive.color 45, primitive.size 33, primitive.font 13,
  primitive.duration 8, primitive.easing 5, color 60, space 19, size 31, radius 6, border 4, elevation 4, z 9, opacity 5,
  motion 25, motionScale 4, breakpoint 3, type 15 (09/04 §7.4).
- **Режимы** — внутри токена в `$extensions.org.ui-research.modes`: тёмная тема — 60 переопределений, плотность
  compact / comfortable — 20.
- **Правила применения** — `$extensions.org.ui-research.llm`: `usage`, `rules` (MUST / RECOMMENDED / Use for / Do NOT с причиной),
  `doNotUse`, `alternatives`. Есть у 185 из 185 семантических. Формат скопирован с Primer `org.primer.llm`.
- **Выпуск**: `build_reference_tokens.py --out` пишет четыре файла:
  - `tokens.json`;
  - `tokens.css`: `:root` + `[data-theme]` + `[data-density]` + блок reduced motion;
  - `theme.css`: `@theme inline` для Tailwind v4, обнулённые дефолтные пространства, брейкпоинты tablet 640 / desktop 1024 / wide 1440;
  - `report.txt`: 87 пар контраста, коридор APCA для disabled, ΔE палитры графиков в трёх симуляциях дальтонизма, арифметика
    интерлиньяжа. Строка `<<<` означает непройденный порог.
- **Имена CSS-переменных** выводятся механически, с четырьмя переименованиями против коллизий с Tailwind (09/04 §6.3):
  `color.text.*` → `--fg-*`, `radius.*` → `--corner-*`, `elevation.*` → `--elevation-*`, `breakpoint.*` → `--bp-*`.
  Примитивы — `--palette-*` и `--scale-*`.
- **Мост к shadcn/ui** — 19 строк (`--color-primary: var(--accent-solid)`, `--color-input: var(--border-strong)` …).
  - Чинит `--input`: было 1.23:1, стало 4.76:1.
  - Ловушка одноимённости: в shadcn `accent` — поверхность взаимодействия, в схеме — акцент бренда (09/04 §6.4).
- **Не проверено сборкой**: `--duration-*` и `--spacing-<имя>` как утилиты Tailwind (09/04, открытые вопросы 4–5; README
  «Что осталось» п. 18).
- **Контролируемый словарь `usage`** (14/08 §4) в схему не внесён: в схеме 307 свободных меток (README «Что осталось» п. 17).

### 1.11. Термины (для общего словаря)

- **«Зона»** — зона каркаса: сайдбар, шапка, контент; «sticky-зоны» (05/02).
- **«Слот»** — слот внутри компонента: префикс или суффикс поля, правый слот шапки у Primer. У словаря `usage` есть грань «Слот» —
  это место применения токена (14/08 §4).
- **«Блок»** — визуальный блок страницы. «Блокер» — уровень серьёзности (13/01).
- **«Flow»** — только в CSS: `overflow`, reflow по 1.4.10. Сценариев в ui нет.
- **«Пресет»** — три разных смысла:
  - A–D — внутренне согласованные наборы значений (14/11);
  - `admin|consumer` — пресеты `ui_audit`;
  - «А/Б» — пресеты движения (08/03 §7).
- **«Ручка характера»** — одна из 7. «Карточка стиля» ≠ «style tile» (00-glossary §14).
- **«Состояние»** — 14 визуальных состояний элемента (06/07). В ux — 11 состояний элемента плюс S01–S22 экрана.
- **«Режим» (mode)** — контекст оси темы. «Мода» в атласе — самое частое значение выборки.

## 9. Неожиданное

1. **Пресет A — единственный живой.** Генератор выпускает только A; «семь ручек» — правка кода, CLI без параметров. B–D существуют
   только как числа (подтверждено кодом).
2. **`ui_audit` не проверит C и D без своих токенов.**
   - Пресеты зашиты в код: у D кегль 13 и контрол 20/28 выпадут в ложные H2 и B2.
   - Маркетинговый профиль живёт в creative и импортирует ui_audit — интерфейс ui_audit стал межбазовым контрактом.
3. **Токены ui и ДС CD не совместимы напрямую.**
   - В CD нет движения, плотность темой не выражается, `rules` сводятся к одной строке `usage`.
   - `ui_audit --tokens` не читает `tokens.json` CD.
   - Имена переменных при этом совпадут один в один (вывод).
4. **Сжатый слой отстаёт от реестра.** Выжимки 01/04 и 04/02 спорят с [C5], счётчики 184 / 287 / 56 местами старые. README велит
   читать «рецепт → Выжимка → § по ссылке», поэтому агент по инструкции базы получит старое правило.
5. **Эталон нарушает собственные правила.** Шрифт по умолчанию в схеме и в русскоязычных примерах — Inter, без `@font-face`. Обе
   вещи база сама называет ошибкой (02/01, 14/03, 11/04 маркер 6).
6. **13 % объёма ui — журнал.** Это отчёты `examples/audit/`, ≈ 285 тыс. ток.
7. **Спор с `frontend-design` уже, чем заявлено.**
   - «Атмосферные фоны» — не из текущего SKILL.md (кэш 22.09).
   - Реальный спор: «оркестрованный момент загрузки» и выразительность против спокойных стилей.
   - Кластер 1 «дефолтного вкуса» — это вид самого Claude (#D97757).
8. **ux ждал от ui формат «блока Дизайн-система» — его нет ни у одной стороны.** Передача ux пришла после синтеза ui и осталась
   без ответа.
9. **Готовая заготовка закрытого словаря не применена.** Словарь `usage` из 94 меток (грань «Слот» — 40) — ни к схеме, ни к
   screens.
10. **Пакет 12/04 §2.6 почти совпадает с артефактом Design System CD** (вывод):
    - DESIGN.md и `guidelines/` ↔ бренд-бук README;
    - `guidelines/components` ↔ `components/<Comp>`;
    - `starter/` ↔ эталонные экраны холста;
    - `checks/` ↔ автопроверки `kit`.
11. **README неточен про зависимости утилит.** «Без внешних зависимостей, кроме Playwright у двух» — на деле Playwright у трёх
    (`render_fetch` тоже), `fetch` требует requests и bs4, `yt_transcript` — yt_dlp. Касается только утилит ресерча.
