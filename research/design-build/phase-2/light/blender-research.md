**Без Blender можно** (с числами):
- шейдерный фон — 1 вызов, ≈ 1,45 мс, 0 байт ассетов (`12/11`, `09/04`);
- CSS `animation-timeline` для DOM-эффектов прокрутки (`09/03`);
- глобус cobe — 5 КБ;
- продукт кодом «код v3» — 0 КБ ассетов, кадр 4,72 мс, JS 234,1 / 135,7 КБ br (`14`, `12/14`);
- предрендер (картинка, видео, секвенция) требует Blender, но не three: 0 КБ JS 3D.

**Бюджеты героя** (канон — ворота F1 `09/05 §7.2`, обоснование — `01/02 §3.1`):
- телефон / десктоп: 3D ≤ 0,8 / 1,5 МБ, ≤ 50 / 100 тыс. треуг., ≤ 30 / 60 вызовов в покое, DPR ≤ 1,5 / 2;
- TBT от 3D ≤ 300 / 150 мс (с транскодером KTX2 — 200);
- вся страница ≤ 3 / 7 МБ; LCP ≤ 2,5 / 1 с;
- JS 3D ≤ 200 / 300 КБ br. Для L1 и L2 (KIT §5, из creative): ≤ 200/300 и ≤ 250/350.
- Сцена-«мир» — другая величина: до 1–1,5 / 3 МБ, канон `08/03 §6.5` (R2). Сцена ниже первого экрана не откалибрована (T18).
- Антиориентир: медиана наградных сайтов 12,6 МБ, первый 3D-кадр 14 с (`01/04`).

**Ответ испытания на «нужен ли Blender» (26.09, один судья):**
- **Вслепую по кадрам:**
  - главный кадр «Звена» B > A > C; «Сдано» B > A 4 из 4;
  - клавиатура A = B по первому экрану; Velmora — 4 ничьи с Kling;
  - доля побед гибрида над кодом **0,40** по 5 парам → «по бюджету» (порог 0,4–0,75). Интервал Уилсона ≈ [0,12; 0,77] накрывает
    все три зоны правила.
- **Вживую:** лучший — гибрид C во всех трёх предметах; Velmora — равны (`vote/live-assessment.md`, правило 102).
- (вывод) Решение по дороге для живой страницы в базе **не измерено**: второй тур «живой проход» (2–3 судьи вслепую, `11/06 §1`) не

### 1.11. Термины (для общего словаря)
- **«паспорт»** — трёх видов: паспорт ассета (части, метры, опорная деталь, бюджет), паспорт стиля серии (камера, свет, вид, фон)
  и паспорт арт-дирекшна предмета (`art-direction.md`, KIT §4). Совпадает с «паспортом» ai-media только словом (вывод).
- **«ворота»** — ворота публикации: `gate_check()`, `qa_pipeline`, тишина. Не путать с экраном «Enter / Click to start» наградных
  сайтов (глоссарий, «Ложные друзья»).
- **«слот»** — слот материала или слот действия (Action Slot, 5.x). Не слот страницы.
- **«слой»** — слой действия или View Layer.
- **«зона»** — зона текста в кадре (`img_metrics --text-zone`), зона отдыха формы, пустышки `zone_*`.
- **«блок»** — 3D-блок страницы или блоки кода.
- **«flow»** — не термин: встречается только как Webflow, workflow, RetopoFlow, QuadriFlow.
- **«уровень L0–L2»** — уровень амбиций creative. **«дорога»** — A код, B Blender, C гибрид. **«дорожка»** — агент-трек испытания
  (Z, CD, KB, SD, VD).
- **«эталон»** — эталонная страница или ассет, к которому подставляют свой. **«якорь класса»** — кадр чужого наградного сайта в паре.
- **«тихий замер»** — под тяжёлым замком очереди, парой с эталоном.
- **«3D по намерению»**, **«постер = LCP»**, **«крюк гибрида»**, **«вау на рубль»**.
- **«ИИ-отсев»** — судья только ищет брак.
- **«исполнилось ≠ годится»**.

## 9. Неожиданное

1. **Ответ «нужен ли Blender» зависит от метода оценки.** Вслепую по кадрам — Blender; вживую — гибрид во всех трёх; доля гибрида
   0,40 с интервалом [0,12; 0,77]. Правило решения `11/06` (0,75 / 0,4) по одному судье ничего не различает. Второй тур «живой проход» —
   в плане, но не проведён. Это прямо влияет на развилку workflow (вывод).
2. **Витрина — это 3D поверх примеров creative** (L0 `l0-sdano`, L2 `l2-zveno`): эталоны рецептов 13–17 — надстройки над демо тройки.
   Связь сильнее ссылок: ворота, рубрика, формат `motion-spec`, уровни, шрифты.
3. **MCP в реальной работе не использовался.** Испытание шло через `blender -b` + `blender_run.py` (MCP в песочнице «не видит базу»).
   Официальный Blender Lab MCP — **коннектор Blender в каталоге Claude** (`04/02` п. 2), то есть часть экосистемы Anthropic.
   mcp-for-blender с 3 неисправленными CVE в шаблоне включать не стоит (вывод).
4. **Воспроизводимость держится на кэшах вне базы.** Страницы собираются из `~/.cache/blender-research/npm-trial` (198 МБ); кэш
   `npm-F1` для `hero-lazy` уже пуст (24 КБ), то есть пересборка эталона 23.09 требует переустановки.
5. **Рецепты 13–17 написаны за ночь и не прогонялись свежими агентами.** Код — отрывки `# run: skip`; «воспроизводимость (≥ 2 из 3
   прогонов) не проверена» (VERDICT §8, §12 п. 4).
6. **Стенд — одна машина** (Iris Xe без CUDA: Cycles только на CPU, 15 ГБ). Ночью ожидание очереди в 2,7 раза больше работы; пять агентов
   по 5–9 ч. Все мс кадра — отсюда и «в тишине». Правила 94–101 — эксплуатация многоагентного стенда, у пользователя шаблона всё будет
   иначе (вывод).
7. **База перевернула свои же умолчания за ночь:** KTX2 → WebP (T9, правило 41); `compileAsync` (T19); свет героя `rk.studio` → этюд

   пар негодны). Ценно для протокола «судья — только фильтр».

    вложенностью, супервизор не стартует; ошибка теперь понятная (вывод).
