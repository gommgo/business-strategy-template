# Журнал сборки design-deep-dive

Рабочий журнал сборки скилла `.claude/skills/design-deep-dive/`: состояние, решения, план, отчёты фаз, инструменты переноса.
Живёт только в ветке `feat/design-deep-dive`; перед слиянием в main убирается. Правило forward-only к нему не применяется
(исключение — в `.claude/rules/forward-only.md`).

## С чего начинать
`STATE.md` → `DECISIONS.md` → `PLAN.md` → `phase-3/SKILL-MAP.md`. Промпт для новой сессии — `NEXT-SESSION-PROMPT.md`.

## Как читать старые пути
- Журнал собирался снаружи, в папке `_skill-build/` рядом с базой: в текстах `_skill-build/…` — это сама эта папка.
- Пути к базам вида `<база>-research/…` и `/home/mm/Документы/app-design/…` ведут в замороженный источник; где файл лежит теперь,
  показывает `phase-3/migration/path-map.tsv` (старый путь → новый путь → sha256 источника).
- Р-номер решения — номер строки `DECISIONS.md`; в `phase-2/SYNTHESIS.md` ссылки Р75–Р80 соответствуют нынешним Р78–Р83 (Р98).
- `digests/` — ранние дайджесты корневых README; свежее — выжимки `phase-2/light/`, `phase-2/ux/` и `phase-2/SYNTHESIS.md`.
- Большие таблицы инвентаря (`files.tsv`, `links.tsv`) и полный манифест заморозки в журнал не входят — они остались в источнике.
