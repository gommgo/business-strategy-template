# ai-media-research — дайджест корневого README

## 1. О чём ресерч
Как агент, собирающий сайты, делает нейросетями визуальные ассеты (hero, петли, иллюстрации, иконки, товар, OG, текстуры) и доводит их до страницы без «нейрослопа»: модель, промт, постобработка, проверка, встраивание. Читатель — агент и его настройщик; каналы — polza.ai (главный, ₽), RouterAI, Gen-API. Статус 24.09.2026: волны 1–4 завершены, живая фаза 5 не начата — ни одной генерации. Объём: 58 файлов (27 012 строк), 17 рецептов, 94 порога.

## 3. Ядро: ключевые выводы
1. **Нейросеть — атмосфера, код — геометрия и текст**: градиенты, паттерны, схемы, линейные иконки, UI-текст — CSS/SVG/HTML за 0 ₽ (лестница «текст → SVG → CSS/шейдер → картинка → видео → 3D»); знакомые иконки — из набора продукта (Lucide).
2. **Слоты-доказательства не генерировать** (отзывы, команда, логотипы, товар «как есть»): синтетические лица кажутся реальнее (65,9 % против 51,1 %), раскрытие ИИ снижает доверие; по 25 слотам — «сам / спрашиваю / не делаю».
3. **Первый экран ≤ 2,5 МБ / ≤ 1,5 МБ (телефон)** вместе с видео, hero ≤ 150/80 КБ; «дорого» — меньше картинок, один приём, реальный материал.
4. **Модель, провайдер, цена — только из `routing.yaml`**, ценовые параметры явно (иначе — запасная ступень, часто максимум: Seedance 2 — 415 ₽); фото-hero — 7 ₽.
5. **Спецификация раньше промта**: `asset-spec.schema.json` → `prompt_compile.py` → диалект; JSON — контракт, не формат промта. Промт — английский, 30–80 слов; правка — ≤ 5 изменений целевыми значениями.
6. **Паспорт визуала из токенов UI до первой картинки** (утверждает человек): палитра, грейд, свет, зона текста — числами; бренд-цвет — `.cube` и ΔE, не hex в промте.
7. **Против «среднего вида»**: объект в правой трети, 40–50 % кадра пусто под текст; фото — 2K + зерно 1–3 %. Слоп — в содержании: ≥ 3 маркера, увиденных человеком, → не публиковать.
8. **Выход модели — не как есть**: AVIF по SSIMULACRA2 ≥ 80 (hero) / ≥ 70; апскейл — Lanczos, не Real-ESRGAN.
9. **LCP и адаптив**: полноэкранный hero не бывает LCP (LCP = H1, 12 из 12); телефону — свой мастер 4:5 через `<source media>`; OG 1200×630 ≤ 300 КБ.
10. **Видео-hero — постер + видео после `load`**; reduce/Save-Data — 0 байт; петля — кнопка паузы 44 px (WCAG 2.2.2).
11. **Текст поверх медиа — только HTML**; контраст F83 по буквам и кадрам, скрим по p99,9 полосы текста.
12. **«Код меряет, VLM понимает, человек решает вкус»**: `asset_audit.py --strict` после каждой генерации, пороги — `thresholds.yaml`; видео VLM не судит (48,6 %). Не в финал: Qwen 2.1, Midjourney, RMBG-2.0, FLUX.2 dev.

## 5. Как README предлагает этим пользоваться
- «Как пользоваться (для агента)» — прямые инструкции: 60 правил + строка задачи → рецепт `14-recipes/0N` (10 звеньев: слот → паспорт → спецификация → маршрут → компиляция → задание → проверка → постобработка → провенанс → доставка; детали — по ссылкам `→ §`) → модель только из `routing.yaml` после свежего снимка и `routing_check.py` → сухой прогон и `estimate`, `--live` — только с заказчиком → `asset_audit.py`/`page_accept.py`; спорное — `CONTRADICTIONS.md`.
- Правила адресованы `NN/MM §x` и несут метку доказательности (`[проверено]`…`[не проверено]`); README папок — выжимка на 10 строк.
- Ключи — файлами, не в чат; обновление: снимок → `diff` → валидатор, новая модель — мини-стенд (33–58 ₽).

## 7. Релевантность двум целям
**(а) UX в бизнес-стратегии — низ** (ресерч о производстве медиа):
- план ассетов: секции → слоты (роль, размер, движение, зона текста, бюджет, уместность ИИ) — `01/01 §8`;
- доказательства не генерировать → перечень реального контента от заказчика;
- бюджеты первого экрана и риски (152-ФЗ, AI Act) — как ограничения.

**(б) Макеты в SSR — выс для медиаслоя** (вёрстку не покрывает — вывод):
- визуал кодом за 0 ₽: CSS/SVG-фоны 6–25 КБ, паттерны, зерно `feTurbulence`, Lucide, фавиконы;
- разметку доставки (`<picture>`, телефонный мастер, LCP, постер видео, пауза, текст по F83); эталон — `10-web-integration/pages/`;
- слоты макета — `asset-spec.schema.json` + паспорт визуала, генерация — по рецептам (вывод);
- автоприёмку: `page_accept.py`, `layout_check.py`; OG — HTML → Playwright.
