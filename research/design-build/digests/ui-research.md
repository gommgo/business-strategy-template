# ui-research — дайджест корневого README

## 1. О чём ресерч
База по визуальному слою веб-сервисов (админки, клиентские сервисы) отвечает, какие величины брать и как проверять экран: правила с числами, условиями и источниками. Читатель — ИИ-агент, собирающий интерфейсы генераторами картинок и кода; UX вынесен в `../ux-research/`. 22.09.2026, «синтез завершён»: 14 папок, 104 .md, 54 068 строк, 391 источник; замеры: 24 живых продукта, 16 генераций.

## 3. Ядро: ключевые выводы
1. **Цвет:** палитра в OKLCH, бренд якорится по светлоте, затем контрастная коррекция; нейтраль одна, C 0.004–0.020; тёмная тема не инверсия — фон L 13–19 %, тени остаются.
2. **Контраст дважды:** WCAG 2 AA обязателен (4.5:1 текст, 3:1 нетекст и граница поля), APCA — качество (Lc 75 тело … 30 disabled); цвет не единственный сигнал.
3. **Шрифт:** база 14 (админка) / 16 (клиент), 15 не делать; 5–7 кеглей, веса 400/500/600; интерлиньяж тела 1.4–1.5, кратно 4 px.
4. **Русский:** гарнитура по кириллице (Golos Text, IBM Plex Sans, PT Sans; не Inter); надписи шире ×1.41–1.49 — ширины по русскому; `1 234 567,89 ₽`, `tabular-nums`.
5. **Отступы:** шкала 0/2/4/8/12/16/24/32/40/48/64/96 (+6, 10); между группами ≥ 2× внутри; плотность — высотами и padding, не кеглем; цели ≥ 24 px, тач 44–48.
6. **Пресеты, не смешивать** (база/контрол/строка/радиус/сайдбар×шапка): A админка 14/32/36/6/240×48; B B2C 16/40/48/10/264×64; C SaaS 14/36/40/8/256×56; D тёмный инструмент 13/28/28/4/224×40; одна высота на ряд.
7. **Форма:** радиус 4–6 px (админка) / 8–12 (клиент), вложенный = внешний − padding; граница 1 px; карточка на границе, тень — с меню; фокус outline 2 + offset 2.
8. **Раскладка:** брейкпоинты 640/1024/1440, адаптив до 320 px; сайдбар 240–288, шапка 48; max-width по содержимому; страница: шапка → вкладки → тулбар → контент → пагинация; одно первичное действие.
9. **Компоненты и движение:** цвет кнопки = иерархия; ошибка поля = граница + иконка + текст; длительности 0–400, дефолт 150, потолок 300; только `transform`/`opacity`; никогда `transition: all`.
10. **Токены:** примитивы → семантика, DTCG 2025.10, правила внутри токена (`usage`, MUST/Do NOT); характер = 7 ручек (акцент, нейтраль, радиус, плотность, шрифт, тени, тема); правка визуала — сначала в токены.
11. **Генерация:** картинкам — карточка стиля 10–15 строк с hex, коду — токены без литералов; бриф жёсткими числами (recall 92.3 % против 70.4 %), пустое поле → дефолт модели; картинка — направление, не спецификация; судья только с рубрикой.

## 5. Как README предлагает этим пользоваться
Инструкция для агента (раздел «Как пользоваться»): рецепт по таблице 14 задач → «Выжимка для агента» файла (15–40 правил) → детали по `→ §`; экран — `ui_audit.py ПУТЬ --preset admin --scheme both --hover --tab 24` (профиль и пороги, не балл); спорное — `CONTRADICTIONS.md`. Пресеты не смешивать; после смены акцента пересобрать схему, в `report.txt` не должно быть `<<<`.
