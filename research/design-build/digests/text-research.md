# text-research — дайджест корневого README

## 1. О чём ресерч
База отвечает, **что написать на странице и как проверить написанное**: смысл до слов, тексты по слотам и типам страниц, голос, антислоп RU/EN, SEO/GEO, право РФ и набор, генерация и оценка нейросетями. Читатель — ИИ-агент (Claude, Kimi через Claude) и настраивающий его человек. Главный артефакт — **copy deck**: файл текстов страницы с фактами, вариантами, статусами и проверками. На 24.09.2026 волны 1–4 завершены, живая фаза не начата (модели не вызывались); 30 содержательных и 55 машиночитаемых файлов, Python-утилиты проверки.

## 3. Ядро: ключевые выводы
1. **Факты до слов**: число, имя, дата, цитата, логотип, цена, гарантия — только из `facts.yaml` (источник вне модели); нет — `[PLACEHOLDER: что]` и вопрос заказчику; выдумать число — худший исход; текст не сильнее факта («1 200+» при 1 146 — нельзя).
2. **Смысл после фактов**: бриф даёт 6–24 % утверждений смысла, без анкеты смысл на 55 % из допущений; допущение → вопрос (≤ 7, с умолчаниями); смысл сверяют с фактами до текста.
3. **Осведомлённость трафика** задаёт тип первого экрана и порядок доказательств; одна иерархия — один уровень; блокеры — до главного призыва, не в FAQ.
4. **Первый экран**: что, для кого, результат, отличие, действие; ядро ≤ 40 слов (100 % лидеров RU); заголовок RU 3–10 слов, EN 2–15, суть — в первых двух словах; длина — сигнал, не ворота. Кнопка — следствие нажатия, 1–4 слова, RU — инфинитив СВ + объект.
5. **Приметы ИИ-шаблона**: три карточки одной длины (42 % секций наивного ИИ, 0 у лидеров), надзаголовок чаще чем у каждой 3-й секции, числа без факта; рваные фразы — `overcorrected`. Маркеры на 100 слов (landing: 2,71 warning / 4,07 error) — порог слоп-прозы, не детектор ИИ.
6. **Объём — по цене ошибки**: лидогенерация RU у людей — 933 слова, наивный ИИ — ≈ 256 на любой тип; короткий hero и GEO-слой ниже первого экрана совместимы.
7. **Голос выводят**, а не придумывают; незнакомому бренду — формальнее середины; юмора нет в цене, условиях, праве.
8. **Право РФ — на весь сайт**: условие «бесплатно» — в том же предложении или у кнопки; «лучший», «№ 1» — с критерием и источником; гарантий дохода нет; согласие на ПДн — отдельная пустая галочка; отзывы — дословно с разрешением; людей не генерировать.
9. **Набор RU**: «990 ₽», «20 %», «−20 %», тире по грамматике; «no em dashes» — только EN.
10. **SEO/GEO**: одна страница — один интент; `title` RU 40–70 знаков, `description` 110–180; ответ первым; GEO — слой того же текста, без `llms.txt`.
11. **Проверка**: факты и право → линтер жанра → длины и мета → судья (сигнал, после 0 error: демо с выдуманными отзывами получило 5,0/5) → человек; правка по находкам, ≤ 3 прохода, без перегенерации; `approved` и слепой выбор — человек; детекторы ИИ и формулы читаемости — не ворота.

**(а) «Проектирование UX» в бизнес-стратегии — сред** (`02-strategy-messaging` — выс):
