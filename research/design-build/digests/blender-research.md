# blender-research — дайджест корневого README

## 1. О чём ресерч
Как ИИ-агент через Blender 5.2 делает модели, сцены, рендеры и анимации для лендингов, продуктовых и маркетинговых сайтов и как их показывает three.js. Читатель — ИИ-агент-дизайнер и настраивающий его человек. 23.09.2026, волны 1–4, 29 агентов, «синтез завершён»; Blender 5.2.2, three r186. Объём: 82 MD-файла ≈ 28 000 строк, 156 экспериментов, 12 рецептов, 468 источников, 106 роликов. Вне рамок: игры, кино/VFX, CAD, AR/VR как продукты; UX и UI — соседние базы.

## 3. Ядро: ключевые выводы
1. **Сначала задача страницы, потом техника**: товар — постер, видео, model-viewer или hero-GLB; бренд без предмета — шейдер или скульптура; кампания — прокрутка; 25 из 70 эффектов — без Blender. Нет интерактива — предрендер: иконка AVIF 2–6 КБ, петля VP9-alpha 30–124 КБ, 0 КБ JS.
2. **Бюджет героя телефон/десктоп**: ≤ 0,8/1,5 МБ, ≤ 50/100 тыс. треуг., ≤ 30/60 вызовов в покое, DPR ≤ 1,5/2, TBT от 3D ≤ 300/150 мс; сцена-«мир» — другая величина.
3. **Canvas не участвует в LCP**: LCP — постер из того же GLB, 3D — после `load`; цикл — только при видимости и без reduce; автодвижение > 5 с — пауза (WCAG 2.2.2).
4. **Стек**: `WebGLRenderer` + `GLTFLoader` (Meshopt) + бандлер со своего домена; React ради одного 3D-блока не тянуть; WebGPU — только compute/сплаты/TSL, с откатом.
5. **Прокрутка даёт только прогресс** → `damp` → кадр по требованию; простые DOM-эффекты — CSS `animation-timeline`, без WebGL.
6. **Цвет бренда**: Khronos PBR Neutral ↔ `NeutralToneMapping` (ΔE 1,8–1,9); AgX выцветает бренд (ΔE 7–9); в шейдере — `colorspace_fragment`.
7. **Паспорт до кода → идемпотентный `build(P)` → числа кодом раньше картинки**: «исполнилось ≠ годится» (sonnet: 8/8 без исключений, годный 1); координаты — кодом от габаритов.
8. **bpy «по памяти» устарел**: 87 из 95 фрагментов падают в 5.2.2 → таблица дрейфа и `bpy_probe.py`; ≤ 2 повторов; финал — `assert` + строка JSON (треть ошибок тихие).
9. **Отбор вместо доводки**: 2–4 варианта, ≤ 2–3 итерации; VLM-судья — попарно, в двух порядках, только после проверок кодом (иначе 3 из 4 выборов — брак).
10. **Экспорт**: пресет вместо умолчаний; Meshopt + квантование (7,1 МБ → 353 КБ br); процедурные материалы — запекать (иначе ΔE 18–33).
11. **Лицензии и безопасность**: без вопроса — только CC0 (CC BY — с атрибуцией); в сцене человека — только своё по тегу; в MCP — без `sys.exit()`; без окна — внешний супервизор и `bwrap`; mcp-for-blender 2.0.3 — три неисправленных CVE.

## 5. Как README предлагает этим пользоваться
«Как пользоваться (для агента)» — прямые инструкции ИИ-агенту: сценарий → рецепт; до кода Blender — дрейф `03/03 §4`, правила чужой сцены `02/01 §1–2`, `lint_agent_code.py`; готовое — `qa_pipeline.py` + `11/05`. Конвейер любого сценария: паспорт → `build(P)` → `qa scene` → рендер → экспорт пресетом → `qa glb` → страница по эталону → `qa page`. Роутинг — 8 сценариев (чтение → рецепт → проверка): hero, иконки, витрина/AR, прокрутка, фон без Blender, готовый ассет, проверка, агент без окна. В каждом файле «Выжимка для агента» (10–25 правил с `→ §`), в каждой папке README на 10 строк.

## 7. Релевантность двум целям
**(а) «Проектирование UX»: низ; сред, если в продукте 3D (вывод).**
- «Нужен ли 3D и какой» — от задачи страницы (`12/00 §1`, `01/02`, `01/01`).
- Бюджет героя и a11y (п. 2–3) — как нефункциональные требования.
- Антиориентир: медиана наградных 3D-сайтов 12,6 МБ, первый 3D-кадр 14 с.
- Риски: лицензии ассетов; GSAP в no-code-конструкторе — к юристу (R13).

**(б) Макеты во фронтенде SSR: сред (вывод).**
- `hero-lazy`: постер → 3D после `load`, ассет через `window.HERO_CFG` — ложится на SSR (вывод).
- `12/03-device-mockup`: телефон со скриншотом → постер, GLB 53 КБ — витрина сгенерированных экранов (вывод).
- Без Blender: шейдерный фон `12/11` (1 вызов, 1,45 мс), CSS scroll-driven.
- Методика п. 7, 9 и `qa_pipeline.py page` переносима на макеты (вывод).
