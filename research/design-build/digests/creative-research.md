# creative-research — дайджест корневого README

## 1. О чём ресерч
База о **подаче** маркетинговых сайтов: «как страница выглядит и движется, чтобы продавать и не быть „нейрослопом“» — от уровня амбиций L0/L1/L2 и концепции до эффектов, стека, спецификации для ИИ-исполнителя и проверки. Читатель — ИИ-агент (Claude — арт-директор, K3 — исполнитель) и настраивающий его человек. На 25.09.2026 волны 1–4 завершены, живая фаза не начата: K3 не запускался, реальные телефоны, Safari и Firefox не проверялись. Объём: 36 содержательных и 42 машиночитаемых файла, 42 лабораторные страницы, 3 рабочих примера, 23 утилиты.

## 3. Ядро: ключевые выводы
1. **Уровень — странице и секции**: внутренние — L0, лендинги и главные — L1, кампании и портфолио — L2; конверсия всегда L0. JS эффектов 20 / 100 / 150–200 КБ br, WebGL 0 / 1 / 1–2, доступно эффектов 16 / 47 / 56. CWV едины: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1.
2. **Концепция словами до эффектов**: механизм, сцена, что доказывает первый экран, тезис ≤ 240 знаков; эффект без «связи с концепцией» не берётся; главный приём делает то, что делает продукт.
3. **3–5 направлений (умолч. 4)**, пары различаются ≥ 2 из 4 осей; «хвост»: 8 кандидатов → 3–5 наименее типичных.
4. **Конвенции не ломать**: логотип слева → главная, подписи в навигации, нативная прокрутка.
5. **Типографика**: `clamp()` max ≤ 2,5 × min; H1 ≤ 2 строк (1440) и ≤ 4 (390); гарнитуры — только из `cyrillic-display-fonts.yaml`; метрический фолбэк (CLS 0).
6. **Контраст — в худшей точке градиента, текст на медиа — на скриме (α ≥ 0,6)**; продукт — HTML-фрагмент, а не скриншот.
7. **Движение и доступность**: > 5 с — пауза (2.2.2), ≤ 3 вспышек/с (2.3.1); «reduce, not remove»; прокрутку не перехватывать; LCP-элемент — без анимации (максимум `transform` ≤ 24 px).
8. **Числа — токены `motion.marketing`**: вход `cubic-bezier(0.16, 1, 0.3, 1)`, появление 400–700 мс, стаггер 40–80; `transform`/`opacity` (+ `clip-path`, `mask` на L1–L2), раскладку — никогда; петель в кадре ≤ 1 / 2 / 3, под текстом — ноль.
9. **Эффект — только из `effects.yaml`** (`id`, `level_min`, `limits`); цену мерить главным потоком, CLS, покоем — не FPS.
10. **Стек снизу вверх**: CSS → свой код → малые библиотеки → GSAP → WebGL → no-code; L0 без анимационных библиотек; смысл — в серверном HTML (SSR/SSG, не SPA); модуль эффекта `{id, budget, supports, init, reduce, mobile, pause, resume, destroy}`.
11. **Клише — приём, который никто не выбирал**: пять проверок (концепция, бренд, исполнение, эпоха, единственность) → `use` / `twist` / `avoid` в `decisions[]`; диагноз по кластеру.
12. **Передача и проверка**: `art-direction` → `treatment` → `motion-spec` (таймлайн, контракт разметки `data-*`); сначала ворота (0 B и 0 S), потом рубрика попарно; ИИ-судья — фильтр, не арбитр.

## 5. Как README предлагает этим пользоваться
Раздел **«Как пользоваться (для агента)»**. Встроенная поэтапная загрузка: папка → `README.md` (10 строк) → файл → «Выжимка для агента» (15–40 правил) → разделы → «Частые ошибки» → «Чек-лист». Адресация по id (`effect:<id>`, `cliche:<id>`, `X-NN`); «одна норма — одно место», при расхождении действует `CONTRADICTIONS.md`. Сценарии: **1** — подача по брифу (12 шагов, вход `10-recipes/00-how-to-use.md`, рецепт по `page_type` × уровень); **2** — проверка (статика → движение и цена → контраст на медиа → ворота site → рубрика → человек); **3** — исправление (блокеры B → серьёзные S → клише; «не улучшай сверх списка»).

## 7. Релевантность двум целям
**(а) «Проектирование UX» — сред (вывод).** Брать: выбор уровня по `page_type` и правило лидогенерации (L0 при горячем мобильном трафике ≥ 50 % и `price_band` low/mid); процедуру «концепция → 3–5 направлений» и `art-direction` как выход этапа; мудборд с Take / Do not take и правами; конвенции и два теста уникальности (П8).

**(б) Макеты SSR — выс (вывод).** Брать: токены и кириллические гарнитуры; `effects.yaml`, лестницу стека и модуль эффекта (смысл в серверном HTML); реестр клише и «чего не ставить»; рецепты 01–03 и примеры как эталон кода («Звено» L2 — 0,365 МБ, ворота 0/0/0); автопроверку `marketing_audit.py` + `motion_check.py`.
