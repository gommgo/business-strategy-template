## 3. Базы

### ux — поведение и структура приложений

**Вопрос:** как из брифа получить работающие экраны приложения. **Владеет:** процедурой «бриф → экраны», объектами,
ИА и навигацией, каркасом, поведением компонентов, состояниями экрана S01–S24, текстами интерфейса, доступностью,
мобильной адаптацией, контрактом генерации, экспертизой; визуальные числа — у ui. Для site · text · creative ux — база форм,
микрокопи, доступности и оценки (`common/owners.md`).

Тематические файлы — 17–60 тыс. токенов: «Выжимка для агента», затем раздел по ссылке `→ §`.

### ui — визуальная система интерфейсов

**Вопрос:** какими числами и токенами выразить интерфейс. **Владеет:** схемой токенов (брейкпоинты, отступы,
плотность, длительности), цветом и контрастом, шкалой кеглей, каркасами, видом компонентов и их состояний, иконками и
иллюстрациями, движением приложения, направлениями и приметами интерфейса, визуальной рубрикой. Для страницы сайта
ui — база цвета, шрифтов и токенов: creative её расширяет, а не переписывает.

Рецепты `ui/14-recipes/` (6–14 тыс. токенов) читают целиком; тематические файлы — от «Выжимки».

**Машинные файлы.** Эталонная схема — 289 токенов DTCG с правилами применения внутри токена; её выпускает
`scripts/ui/build_reference_tokens.py`, читают маркетинговые токены creative, паспорт визуала ai-media, дизайн-система
Claude Design и `ui_audit.py --tokens`. `ui/14-recipes/examples/` — семь эталонных экранов пресета A с отчётами проверки.

**Утилиты.**
- `scripts/ui/ui_audit.py` — визуальная проверка экрана или HTML-копии макета: шкалы, контраст, состояния, фокус, цели,
  тёмная тема, сокращённое движение, сверка со шкалами токенов; для страницы сайта — через `scripts/creative/marketing_audit.py`.
- `scripts/ui/build_reference_tokens.py` — токены и 87 пар контраста; `scripts/lib/color.py` — контраст WCAG 2 и APCA.
- `scripts/ui/measure_ui.py` — замер живого сайта-референса: кегли, отступы, радиусы, контрасты, цели.
