## 3. Отступления от спецификации
1. **Объём.** `phases.md` — 1 059 строк при плане ≈ 600, `field-checklists.md` — 358 при ≈ 180. Причины: 25 контрактов с
   «С середины», три таблицы маршрутов (сводная, сайт, кабинет), таблица шагов ux 13/04, блок PRE 01–18, таблица S1–S11;
   норма ассетов перенесена полностью. Варианты: (а) оставить — файл читается разделами по оглавлению (рекомендую);
   (б) сжать строки «Нормы» до адресов `kb/INDEX.md` §5 — минус ≈ 60 строк, но исполнитель теряет адрес под рукой;
   (в) разбить по слоям — пересматривает решение «один файл» (H9), нужно слово заказчика.
2. **Id этапов SaaS.** T4 §3.1 — `vision`, `roles`, `surfaces`, `objects`, `capability`; фазы `/project-deep-dive` —
   `discovery`, `user`, `surface`, `objects` (её добавляет зона 7a), `capability` и `cohesion`. Взяты id §3.1,
   соответствие — колонка «ведёт» в §1 и §4. Id этапов маршрута и фазы исполнителя — разные словари, конфликта нет.
3. **`directions`** — этап сборки входа холста (формы зоны 1), а не этап маршрута: страницу «Направления» публикуют
   `moodboard` и `style-tiles` (§6 вступление). В §3.1 T4 такого этапа нет — расхождения нет, пометка для Z5c и Z8.
4. **Словарь `stage` в `REVIEW.md`** (`wireframe`, `mockup`, `fix`, `widths`, `motion`, `audit`, `acceptance`) — вид
   итерации, а не id этапа; соответствие — §6 вступление (`fix` — раунд правок, `widths` — промежуточные ширины, `audit` —
   свежий аудит).
5. **Черновик copy deck — `draft`**, а не `assumed`, как пишет T4 §3.1: статуса `assumed` в схеме copy deck нет (форма
   зоны 1, бриф); у текстов интерфейса — `assumed` → `checked` → `approved`.
6. **TX-30:** `voice.scope.surfaces` — каналы схемы, а не slug'и поверхностей (форма и решение по зоне 1).
7. **«Д1» и «Д2»** из текста брифа заменены на «первый / второй вход дизайна кабинета» (урок CHAIN 01).
8. **Числа — адресом базы**, где спецификация писала числа: направления — creative 01/01 §6 (VI-45), карточки —
   ui 11/02 §2.4 (VI-46), вопросы — cd 06/01 §4 (VI-47), пункт правки — cd 06/03 §2 (CN-105), бюджет раундов —
   умолчания формы `ARTIFACTS.md`.
9. **GT-41:** `ac-profile.tsv` не назван — он в `99-raw` и нормой не служит; назван `ux-marketing-profile.tsv`.
10. **VI-60** названа обобщённо: «колонка `copies` её строки в `kb/common/canon.tsv`» — строку и копии заводит зона 10.
11. **Утилит нет:** каркас copy deck из плана и проверка арт-дирекции по примерам (`ad_check.py` разбирает только
    примеры базы) — чтением; §0 «Где утилиты нет» — «собран без утилиты», та же проверка чтением.

Других расхождений id между §3.1 T4 и разделами 3 спецификаций не выявлено.
