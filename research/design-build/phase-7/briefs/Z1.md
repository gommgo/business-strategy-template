## Как писать
- README слоя — как у соседних слоёв шаблона: вопрос слоя, файлы и их форма, статусы и `draft → stable` (у машинных
  файлов — статусы по схеме базы: T1 §4.2, T2a §4.3), связи с другими слоями, язык контракта, anti-patterns. Нормы базы —
  ссылкой на канон, не пересказом.
- Формы YAML — с комментариями к полям (что это, откуда берётся, кто заполняет), без значений проекта; пример —
  помеченный.
- Производные файлы (`input/`, `ready.yaml`, статичные копии, производные ДС) README описывает как собираемые утилитой
  скилла и не правящиеся руками; пока утилиты нет, этап собирает их по форме — одной фразой, без имени фазы.
