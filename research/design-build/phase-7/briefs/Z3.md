## Зона
Шестнадцать правок в канонах трёх слоёв, которые стоят рядом с экранами: FSD-карта фронта, мобильное приложение и бот.
Маршрута макета для `mobile` и `bot` в этой сборке нет (A6): их слои получают только стыки — со словарём состояний, с
текстами интерфейса и ролями, с голосом продукта и токенами дизайн-системы, — чтобы продукт с веб-кабинетом,
приложением и ботом говорил одним голосом и одними словами. Ключи mobile и бота — handoff-контракт с `<org>/mobile` и
`<org>/<bot>` (`CLAUDE.md` §8): их не переименовываешь, только добавляешь новые.

## Как писать
- Стык — ссылкой на канон, а не копией: словарь состояний, приоритет и обязательный набор живут в README screens (норма
  — ux 06/01 базы); mobile и бот держат только таблицу соответствия своих ключей словарю и свои особенности.
- Ключи mobile (`states`, `root`, поля форм) и бота (`fallback`, `errors`, поля окна) не переименовываются — новые ключи
  (`empty`, `escalate`) добавляются рядом со старыми; раздел о языке контракта README слоя дополняется новыми ключами.
- Проход: «craft» → «облик»; фраза о ручной сборке wireframe и hi-fi уходит (связь, если нужна, — «макет собирает слой
  дизайна `design/`»); запрет облика в FSD и mobile остаётся по смыслу — значения темы берутся из токенов ДС проекта, а
  не придумываются в слое.
- Примеры в формах бота — помеченные иллюстрации (`CLAUDE.md` §3), без формулировок за владельца.
