# Ф7 — цепочка агентов зон

Каждый агент Ф7 читает этот файл целиком перед работой. Свою запись он пишет в конец отчёта зоны
(`reports/<зона>.md`, раздел «Запись для CHAIN»), сюда её переносит оркестратор: так два параллельных агента не пишут в
один файл. План — `PLAN.md`, действия по зонам — `ZONES.tsv`, брифы — `briefs/`, решения — `../DECISIONS.md` (Р163 и
дальше).

Формат записи:

```
## <NN>. <зона> — <тема> (<дата>, ≈ <мин> мин, контекст ≈ <тыс.> токенов)
- Сделано: файлы (новые / правленые, строк); решений и действий зоны — с местом реализации.
- Отступления: что сделано не по спецификации и почему; решение оркестратора.
- Стыки: что передаю следующим зонам — кому и что (разделы, id, поля).
- Открыто: что не решено и что это закроет (зона, Ф8, пилот, заказчик).
- Не прочитано: что осталось вне чтения и почему.
```

Время записи — по уведомлению о завершении агента (агенты его завышают).

Порядок (Р164): 1 — Z1 ∥ Z2 → 2 — Z3 ∥ Z4 → 3 — Z5a ∥ Z5b → 4 — Z5c ∥ Z10 → 5 — Z6 ∥ Z7a → 6 — Z7b ∥ Z8 → 7 — Z9 →
8 — проверка (статическая и маршруты).
