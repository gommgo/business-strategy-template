# ДФ9 — цепочка агентов зон разгрузки

Каждый агент ДФ9 читает этот файл целиком перед работой. Свою запись он пишет в конец отчёта зоны
(`reports/D<N>.md`, раздел «Запись для CHAIN»), сюда её переносит оркестратор: так два параллельных агента не пишут в
один файл. План — `DF9-PLAN.md`, находки по зонам — `DF9-ZONES.tsv`, общий бриф — `../phase-8/briefs/COMMON.md` с
поправками `briefs/COMMON-DF9.md`, брифы зон — `briefs/D<N>.md`, решения — `../DECISIONS.md` (Р203, Р216–Р218 и строки
«ДФ9, зона … принята»).

Формат записи:

```
## <NN>. D<N> — <тема> (<дата>, ≈ <мин> мин, в уведомлении — <тыс.> токенов)
- Сделано: файлы (правленые / снятые, строк); находки зоны — с местом.
- Тесты: смоук зоны, самопроверки, `--check`, фикстуры — итог.
- Отступления: что сделано не по плану и почему; решение оркестратора.
- Стыки: что передаю следующим зонам — кому и что (контракты, ключи вызова, форматы, пути).
- Открыто: что не решено и что это закроет (Ф9 — замер, Ф10).
- Не прочитано: что осталось вне чтения и почему.
```

Время записи — по уведомлению о завершении агента (агенты его завышают).

## Уроки Ф8 (для всех зон)
- Файлы результата — рабочие артефакты заказчика: пиши их по мере готовности; сессия может оборваться, работу спасают
  файлы на диске, прерванную зону доводит новый агент по ним (Р119).
- Инструмент может не дать записать отчёт — тогда полный текст в ответе, файл пишет оркестратор.
- Правка по месту, без переформатирования: переписанный под ширину файл раздувает дифф и прячет потери.
- Снимок `CLAUDE.md` в контексте агента бывает старым — главный файл на диске.
- Большие файлы — адресно: `def`, `add_parser`, заголовки, потом `Read` с offset и limit.
- Снятие ветки или ключа ломает соседей: поиск вызывающих по имени во всём `.claude/` — до снятия, смоук — после.
- Правка реестра примет, ворот или вывода утилиты сдвигает отпечатки в фикстурах с собранными файлами: после неё
  `scripts/maint/sync_check.py`, при FAIL строки `fixtures` — пересборка `scripts/maint/fixture_gen.py` по плану.
- Тихие пропуски проверок прячут дефекты: снятое молчаливое «правила не загружены» сразу нашло дыру в данных посева.
  Снимая стоп, понижай тяжесть, а не глуши находку.
- `git stash` в рабочем дереве, где пишет второй агент, — нельзя (стеширует и чужие правки); сверка «до правки» —
  `git show <коммит>:<путь>`.
- Контекст агента — не выше ≈ 940 тыс. токенов (Р201): по сигналу оркестратора — дописать отчёт по текущему состоянию и
  завершиться; остаток доводит продолжатель.
