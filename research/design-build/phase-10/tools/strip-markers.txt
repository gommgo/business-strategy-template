# Образцы для `scripts/maint/normcheck.py --strip`: спаны маркеров, которые текстовая уборка kb/ снимает.
# Собраны из целевых классов `research/design-build/tools/kbscan.py` (CLASSES; справочные `k3` и `ns_dtcg` не входят:
# «K3» у ui — id проверки, `org.ui-research` — имя расширения DTCG). Регулярное выражение Python — одно в строке;
# строка с «#» в начале — комментарий. Совпадение вырезается из обеих сторон сравнения и расширяется до границ слова
# или пути, внутри код-спана — до всего спана, внутри хвоста метки — только в хвосте. Правка класса в kbscan.py —
# правка строки здесь (сверка: `kbscan.py --classes`).
