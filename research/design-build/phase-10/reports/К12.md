## Отступления

1. **F9-135, значение переменной.** В пункте — «переменная окружения с именем замка»; записан абсолютный путь файла замка: он однозначен при разных `$DDD_HOME` у держателя и потомка. Вариант — короткое имя (`browser`, `site/browser`).
   Ограничение способа: потомок, который пережил держателя, продолжает считать замок взятым.
2. **F9-142, снятие кэша.** Кэш модуля пишется до исполнения его кода, поэтому запрет из `kbpaths` не застаёт сам `kbpaths` и модули, импортированные раньше него. Чтобы запрет действовал при любом порядке импорта, `kbpaths` снимает их кэш сам (только файлы под `scripts/`, только пустую папку `__pycache__`). Вариант — одна переменная окружения: тогда `lib/__pycache__` появляется после каждого прямого запуска утилиты.
3. **F9-137.** `--window` обязателен: числа окна в пункте нет. Из прототипа перенесены хвост чтения 4 МБ, пауза 20 с, простой 15 мин и взвод порогов заново ниже 0,8 порога `warn`. Сверх прототипа: запись без токенов (сообщение среды) не считается ответом модели; код 1 — активный агент дошёл до `stop`; файл состояния по умолчанию — `$DDD_HOME/out/maint/ctx_monitor/<16 знаков sha256 пути папки>.json`; `--once` состояние не читает и не пишет.
4. **CA-RC.** Домен распознаётся по форме первого сегмента `имя.зона`; спаны вида `объект.атрибут/вариант` (24 находки по базе) той же формы и находками быть перестали — файлами они не были. Имя с расширением файла перед «/» (`notes.md/json`) остаётся находкой. Тип содержимого — первый сегмент из девяти типов реестра (`application`, `audio`, `font`, `image`, `message`, `model`, `multipart`, `text`, `video`), подтип не вида `NN-…`: битая папка базы `text/09-…` остаётся находкой. Спан с точки без «/» — всегда расширение, в том числе имя вида `.mcp.json`.
5. **OE4-15.** Шаблон ловит только `/home/<имя>/`.
6. **OE4-16.** Групп npm три: `page` (по умолчанию), `media`, `3d`; `media` в пункте не названа — в неё ушли пакеты SVG, иконок и Lottie, которые не относятся ни к замерам страницы, ни к 3D. Установка аддитивна: пакеты групп, поставленных раньше, остаются. scipy записан в двух группах pip (`svg` — как зависимость scikit-image, иначе pip ставит её незакреплённой). Python новее 3.13 — предупреждение, а не отказ.
