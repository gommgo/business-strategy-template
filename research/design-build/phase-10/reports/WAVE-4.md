# Волна 4 кода — машинные файлы базы: приёмка оркестратором

Следы процесса исследования в машинных файлах `kb/` (YAML, JSON, TSV, код примеров). Механика оркестратора, затем десять
зон данных разом (бриф `briefs/DATA-F10.md`, раскладка и шаблон задания — `briefs/DATA-ZONE-TASK.md`). Отчёты зон —
`Д-<зона>.md` рядом, файлы передачи и пакеты замен — `$DDD_HOME/out/f10/<зона>/`. База — `1e0cd2a`.

## Механика (оркестратор, коммит `a13ac23`)

- метки доказательности без пути сырья — `tools/rawlabel.py --machine --apply`: 182 метки в 40 файлах;
- идентификаторы схем `urn:app-design:<база>-research:…` → `urn:app-design:<база>:…`: 58 мест в 37 файлах (схемы, ссылки
  между схемами, цитаты в статьях, две утилиты текста); проект повтора и фикстуры этих идентификаторов не несут;
- малые списки: стили примера ui (`app.css`), пример ДС и два брифа стенда claude-design — штампы сборки и блок запуска
  стороннего исполнителя сняты.

После механики: полный смоук — PASS 336, FAIL 0, XFAIL 0, XPASS 4.
