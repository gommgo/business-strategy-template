## Отступления

1. **F9-037 — поле `variant.checks` утилита не пишет совсем**, и у выбранного варианта тоже: его итоги — записи `lint` и
   `claims` слота, дубль в `checks` и давал рост файла. `export-variants` по-прежнему не выносит на лист вариант, у
   которого в файле записан `checks` с error; новых записей туда никто не ставит — ошибки вариантов видны в отчёте
   `check --all-variants`. Уже записанные `checks` в файлах проектов не удаляются. Вариант — писать `checks` только
   вариантам с error.
2. **F9-103 — запись без `value` и `fragment` действует как раньше** (все находки правила на своём месте): иначе
   утверждённые файлы проектов потеряли бы обходы. `rule: COPY-F-NUM` остаётся семейством (имя совпадает с id находки);
   одна находка — `COPY-F-NUM-MISMATCH`. `value` — только у чисел; слово называет `fragment`.
3. **F9-034 — роли взяты из каталога блоков, а не списком пункта**: семь ролей пункта каталог покрывает вместе с
   остальными. Слоты без `section_roles` (мета, письма, квиз, `messenger-prefill`) оставлены без ограничения. Две пары
   каталог не знает — взяты из примеров базы.
4. **F9-011 — числовой нормы длины у слота нет**: в базе её нет, правило — «короткое» словами (вопрос ниже). Жанр —
   `email-form`, роль — `user-content`: стиль бренда и типографика страницы на сообщение посетителя не действуют.
   Выгрузка `copy.md` не менялась: слот идёт строкой своего id наравне с остальными.
5. **F9-107 — промежуточный файл вне папки copy deck ссылок не разрешает**: `approve` на нём отказывает находкой
   «facts.yaml не найден по facts_ref» (добавлено к пункту: без неё отказ звучал как «заглушка без пробела»). Цепочку
   `check --update` → `approve` держать в папке copy deck (так делает `fixture_gen.py`) или вернуть файл на место.
6. **F9-143 — `--slot` принимает `<section_id>/<slot_id>`** (id слота уникален в секции); `-o` и `--by` обязательны, как
   у `apply-selection`. Мета командой не выбирается: у неё нет места записи `selection`.
7. **F9-039 — неполный образец не находка**: без этого образец проекта повтора получил бы warning, а с `--final` — error.
8. **F9-004 — выбрана ветка «сверка смысла не проверяет `use`»** и ключ `--brief`. У многостраничника факты уместны на
   разных страницах, один тип страницы проекции их не закрывает. Ссылки смысла на бриф схема смысла не несёт.
9. **C15-провенанс — строки `99-raw` не тронуты** (общий бриф), кроме `crosswalk.hallmark_archetypes.source`: в пути
