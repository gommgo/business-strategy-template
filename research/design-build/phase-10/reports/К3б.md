## Отступления

- **F9-053 — заметка направления.** Пункт называет только `bans`; `notes` добавлена, потому что карта арт-дирекции
  в примечании правила `directions[]` называет «заметка (notes)» частью артборда направления. Расширение не читается
  совсем: строки пробелов о нём нет, расхождение расширения с полем сообщает `ad_check.py`.
- **CA-13, OE1-22 — отпечаток.** Строка поверхности «Условий холста» теперь несёт ключ `outside`, поэтому отпечаток
  `ARTIFACTS.md` в манифесте меняется у каждого проекта со строкой поверхности (один раз, до пересборки входа). Строка
  «Ширины приёмки» входит в отпечаток, только когда она есть.
- **OE1-22 — форма строки.** Одна строка на продукт, а не колонка таблицы: `Ширины приёмки: 1440, 1024, 390, 360 —
  <роль>, <дата>, <откуда>`; берутся числа до первого тире. Ключ `acceptance_widths` пишется в манифест всегда —
  потребителю не нужно знать правило переопределения.
- **F9-164 — форма блоков.** У блоков `x-collection` и `x-works` в шаблоне канона нет; читается ровно та форма, которую
  называет пункт: `x-collection.pages[].slots[]` и `x-works.covers[]`, id записи — первое заполненное из `id`, `row`,
  `fact`, `n`. В отпечаток плана входят только демо-кадры записей (путь, вариант, пояснение, варианты записи), блоки
  целиком — нет.
- **CA-11 — число предела.** 16 МБ взято из базы: cd 05/03 §2 «Вызов публикации — 16 МБ». Модель тяжелее предела
  файлом не собирается (строка `assets.md` остаётся, с пометкой). Мегабайт — 2²⁰ байт.
- **CA-11 — `assets.md` этапа motion.** Карта плана ассетов этап motion не называет, поэтому файл собирается правилом
  сборщика со своими колонками (`файл · слот · роль · постер · источник и лицензия · модель`) и только у страницы с
  моделью. Манифест ассетов на этапе motion читается только у страницы с 3D-слотом.
- **F9-039 — тяжесть.** Тексты образца не того статуса — `warning` и на макете: пункт тяжесть не называет, новая
  находка `error` не делается. Отпечаток единицы и партию образец не меняет.
- **OE5-19 — порядок чтения.** Источник слоя проекта — первым, копия брифа — запасной. У кабинета без брифа на вид
  вход теперь несёт постуры (`manager (sovereign)`) и цель доступности в пункте D4 — фикстура `cabinet-demo`.
