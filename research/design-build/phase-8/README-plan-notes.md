## 3. Проверено делом: окружение облака (28.09)

Установка шла во временный `DDD_HOME` в scratchpad; репозиторий не менялся (кэш `__pycache__` и `text/last-run.txt`,
которые оставил смоук, удалены).

- **Python.** По умолчанию 3.11.15; в образе есть `/usr/bin/python3.12` и `/usr/bin/python3.13`, есть `uv`. Закрепления
  `requirements.txt` не ставятся на 3.11: numpy 2.5.3, scipy 1.18.1, tifffile 2026.9.20 и networkx 3.7 требуют ≥ 3.12, а
  шапка файла пишет «3.10–3.13» (ENV-1).
- **Установка.** `install.sh --python /usr/bin/python3.13 --groups core,net,morph --no-npm` — ≈ 19 с, без ошибок.
- **Смоук** на этом окружении — 2,5 мин: PASS 207, FAIL 0, XFAIL 9 (cairosvg, снимки каталогов, c2patool и exiftool,
  Brave) — как в шаблоне после переноса.
- **Браузер.** Playwright 1.63 из закреплений ищет Chromium 1243 (`chromium_headless_shell-1243`), в образе —
  `/opt/pw-browsers/chromium-1194` (Chromium 141.0.7390.37), `PLAYWRIGHT_BROWSERS_PATH` задан, CDN Playwright закрыт (403).
  С `executable_path` 1.63 запускает 141; с `playwright==1.56.0` работают и запуск по умолчанию, и `channel="chromium"`;
  кириллица на снимке рендерится (ENV-2).
- **ffmpeg.** Системного нет; у Playwright — `ffmpeg-1011` без ffprobe, только vp8, webm, png, mjpeg. apt-архив Ubuntu и
  статические сборки на GitHub отвечают (ENV-3).

- **Сеть.** Открыто: PyPI и реестр npm (напрямую), GitHub (релизы и raw), SourceForge, archive.ubuntu.com. Закрыто

## 5. Как собрана `ZONES.tsv`

- Строки 1–165 — строки `actions.tsv` с фазой Ф8 в том же порядке, колонка `action` — как есть; порядок и id сверены
  скриптом (VI-39 — две строки, два действия). Зона — по файлу, который правит действие (колонки `action`, `resolution`,
  `canon` узла); у действия на нескольких файлах — несколько зон, `note` называет часть каждой.
- Строки 166–282 — префиксы: `H10-` — таблица и доработки T4 H10; `T1-`, `T2a-`, `T2b-`, `T3-`, `T4-` — «Ф8 от T…» и
  «Открыто» спецификаций; `S6-` — части Ф8 действий сверки Ф6, которых нет среди 165; `F7-<зона>-N` — открытые пункты
  отчётов Ф7 о коде, схемах и утилитах; `BL-` — бэклог `STATE.md § Дальше`; `ENV-` — окружение (проверено в облаке);
  `DEC-` — решения журнала без строки действия; `H11-Ф8` — пакет закрытий.
- Коды зон: `C1`…`C17` — `PLAN.md` §2; `ОРК` — шаг 10 оркестратора; `МЗ` — шаг на машине заказчика; `вне` — вне Ф8, причина
  в `note` (17 строк: уборка Ф10, пилот, соседние репозитории, решение уже принято, утилиты нет в скилле).
- Скрипт сборки таблицы в журнал не положен (бриф ограничил файлы папки); таблица — сама источник, правится руками.
