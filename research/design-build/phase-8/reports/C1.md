## 3. Отступления от плана и спецификации
- **Снят суффикс старых имён баз в `kbpaths`** (`kb("site-research")` → `kb("site")`). Бриф просил только справку без
  Р-номеров; суффикс — имя из прежней раскладки (forward-only: «нет ссылок на прошлые имена»), вызывающих в `scripts/`
  нет, полный смоук без новых FAIL. Вернуть — одна строка; решает оркестратор.
- **Статический ffmpeg — через PATH процесса.** Утилиты ai-media и creative зовут `ffmpeg` и `ffprobe` по имени
  (`subprocess`, `shutil.which`), а не через `kbpaths.ffmpeg()`, поэтому `_init_env()` ставит `$DDD_HOME/bin/ffmpeg`
  первой в PATH, если сборка стоит. Варианты: (а) так — одно место; (б) владельцы утилит переходят на `kbpaths.ffmpeg()`
  (правки в чужих файлах). Сделано (а).
- **Источник статического ffmpeg — сборки Martin Riedl 7.1.1**, а не GitHub: у BtbN ветки 7.1 больше нет, дневные теги
  живут две недели (месячные — около двух лет), сборки John Van Sickle — 7.0.2 и переезжают в old-releases с новым
  релизом. У Riedl история релизов с 5.0, версия в пути и `.sha256` у каждого файла; зависимости — только glibc ≥ 2.29.
- **Blender Lab MCP — справкой**, без ключа установки: аддон ставится в настройки Blender, сервер регистрирует в Claude
  Code владелец машины, песочница — `bwrap` по рецепту kb; бриф этот вариант допускает.
- **`--playwright-match` не запоминается**: обычный запуск без ключа вернёт закрепление 1.63.0; в среде с браузерами
  образа ключ передаётся каждый раз.
- **esbuild — полем `allowScripts` в `package.json`** (формат npm 12: `"esbuild@0.28.2": true`) и `npm rebuild esbuild`
  на дереве, поставленном без разрешения; старый npm поле игнорирует и скрипт запускает сам. Отпечаток `package.json`
  сменился — ближайший `install.sh` переустановит npm-зависимости в `$DDD_HOME/node` (секунды).
- **Манифест фикстуры шире брифа:** кроме слоёв `kb` и своих файлов — `extends` (ромб собирается один раз), `replace`
  (точная правка положенного файла: C13 сеет дефекты без копий примеров), `drop`, `files` словарём. Самопроверка
  сборщика строго сверяет пометки своих файлов у всех фикстур папки (`example: true`, «иллюстрация» в md) — фикстура
  без пометки валит смоук `tests`.
- **`docpaths` считает `capability` слоем** (файл `capability/<surface>.md` — у каждой поверхности по канону) — чтобы
  `layers` поверхности давал полный набор мест.
- **`smoke.py`:** новая колонка `list` в `--tsv`; `--uncovered` — справка с кодом 0.
- Остального — нет.
