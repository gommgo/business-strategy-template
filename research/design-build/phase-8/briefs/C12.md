## Зона
Оценку картинок и макета делает Claude Opus 5.5 — агент `design-judge` в отдельной сессии с чистым контекстом, по
рубрике владельца, попарно в обоих порядках, с повторами; последнее слово — человек (`kb/common/judge.md`, Р27, Р60).
Код судью не вызывает: он готовит пакет заданий для сессии Opus и разбирает её ответы (Р5, Р47, Р55). В зоне: судья
`asset_audit.py` (вместо вызова модели другого вендора — пакет и разбор), пороги доверия в данных, рубрики без
параметров модели, разбор сетки бренда `vlm_to_dna.py` — пакетом той же формы, схема паспорта визуала.

## Что сделать
- **Пакет судьи** (JU-31, JU-01, JU-20; H4 T4): `judge-jobs` пишет пакет в `$DDD_HOME/out/ai-media/…` или `--out`: кадры
  вслепую (имена без признаков варианта), вопросы рубрики, формат ответа по `judge-response.schema.json`, оба порядка
  пары и повторы — отдельными заданиями, ключ слепоты — отдельным файлом вне пакета (агент его не видит); задания
  калибровки — из `assets/calibration/index.yaml` (пары, рубрика из поля `rubric`). `judge-parse` принимает ответы
  сессий (файлы по формату схемы): находка засчитывается при двух прогонах из трёх, пара — большинством;
  `agree` и `trust_level` — пороги из группы `judge` `thresholds.yaml` (JU-18, JU-19): Уилсон, F1, доля «не уверен»,
  число сессий. Идентификаторов моделей других вендоров как умолчаний оценки в коде нет; `JUDGE_MODEL`, `judge_body` и
  вызов канала для судьи сняты.
- **Рубрики** (JU-07, JU-31): поля `judge.model_default`, `model_cross_vendor`, `temperature`, `seed`, `max_tokens`,
  `reasoning_effort`, `structured` сняты; `judge.system` штрафует избыточность («добавленное без просьбы брифа — такой
  же дефект, как пропущенное», `judge.md §4`).
- **`budget.image`** (GT-20 — часть C12): `hero_image_kb` — бюджет ассета в `thresholds.yaml`, телефонные 80 КБ —
  отдельным ключом; слой подачи ссылается (C4 уже сослался — сверь путь ключа с отчётом C4 §4).
- **`mp_client.py`** (JU-31 — задания судьи не нужны; CN-92 — Gen-API без 3D-моделей).
- **`stand_run.py page`** (JU-23): режим текстовых карточек, вход — варианты copy deck (подкоманду выгрузки вариантов у
  `copydeck.py` найди по отчёту C8 §4).
- **`vlm_to_dna.py`** (DEC-55, VI-49, VI-54): `build` — пакет той же формы для сессии Opus (сетка бренда → паспорт), разбор
  ответа — в паспорт; `validate` — на новой схеме.
- **`visual-dna.schema.json`** (VI-49, VI-51, VI-53, VI-54, H10-visual-dna, T2a-visual-dna, F7-Z6-9): `icon3d` — ссылкой
  на паспорт 3D-серии blender 06/02 §6 вместо своих `key_light`, `fill_pct`, `contact_shadow_alpha_max`, `margin_pct`
  (по CAM-02); `illustration` — поля системы ui 07/02 и список метафор пустых состояний (его читает `design-audit`
  R-REF-007); `video.tempo` += `fast`; в происхождении — ссылка на арт-дирекцию. Примеры паспорта проходят схему.
- **`judge.md §6`** — строка ключей группы `judge` (JU-18).
