## Зона

Утилиты зоны делают из них то, что проверяется: статичные HTML-копии артбордов (на каждой итерации) и сверку адаптивной
копии со статичной (после «Keep», T2b E8), обратный разбор текстов в `copy.md` (правка заказчика на холсте → источник
по роду, E10), проверку «литерал ∈ значений токенов ДС» (Р63), манифест кадров `kit.json` из ширин приёмки; и
проверки макета `mockup_checks.py` без следов прежнего исполнителя.

## Уроки и стыки прежних шагов
- Пороги кеглей и шапки (C2): `scripts/ui/data/thresholds.yaml` — `font_sizes` (`norm: [6, 8]`, `tell_above: 9`),
  `header_height` (`page: {phone: 64, desktop: 80}`, `app: {A: 48, B: 64, C: 56, D: 40}`); телефон — окно уже первого
  брейкпоинта ДС (эталон 640); путь — `kbpaths.data("ui", "thresholds.yaml")`.
- id приметы — `kb/common/tells.yaml#checks`: ключ без префикса — проверка `mockup_checks.py` (K3-*, F-*, M-*, V-*, E-*),
  `tell` строки — id приметы в находке.

- Контракт `copy.md` (C8, отчёт `reports/C8.md` §4 — синтаксис и пример дословно): `## <section_id>` → строки
  `[<slot_id>]: <текст>` (у текстов из исходников холста статуса нет; выгрузка пишет `[<slot_id>] <статус>: <текст>`);
  `## ?` и `[? <подпись>]: <текст>` — тексты без секции или слота плана; абзацы — строки продолжения с двумя пробелами;
  `# …` и `<!-- … -->` — комментарии. Разбор и запись — `copydeck.py` (`parse_copy_md`, `render_copy_md`); приём —
  `copydeck.py import-copy COPY.md --deck DECK --page ID -o OUT`. `dc_texts` пишет этот формат; проверь круг: выгрузка
  C8 → твой разбор исходника → `import-copy` без находок формата.
