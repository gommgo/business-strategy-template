# Словарь перевода жаргон → язык бизнеса

Скилл общается с клиентом **только** правой колонкой. Слой AJTBD богат
жаргоном — переводим всё.

## Сущности

| жаргон | бизнес |
|---|---|
| segment | «тип клиента» / «кого вы обслуживаете» / «ваши клиенты» |
| job (работа) | «за что платят» / «что человек хочет получить» / «зачем приходит» |
| Big Job (верхняя работа) | «ради чего им это в итоге» / «большая цель клиента» |
| Core Job (целевая работа) | «за что конкретно платят» |
| low-level job | «шаги, которые он для этого делает» (обычно не трогаем с клиентом) |
| success-criteria | «что для них “хорошо сделано”» / «по чему судят, что норм» |
| solution (нанятое решение) | «чем пользуются сейчас» / «что используют для этого» |
| satisfaction | «насколько довольны тем, чем пользуются сейчас» |
| Score / приоритизация | (не упоминаем; внутренне складываем из частоты, важности, размера и недовольства) |
| sizing / TAM-SAM-SOM | «насколько их много» (грубо; точную оценку — аналитику) |

## Поля и процедуры

| жаргон | бизнес |
|---|---|
| slug / kind / status | не упоминается |
| draft / stable | «в работе» / «закрыто» |
| name | «как назовём этот тип коротко» |
| description | «коротко, одним предложением, кто это» |
| kind (b2b/b2c) | «вы продаёте людям или компаниям?» |
| who-context | «кто это, в какой ситуации к вам приходит, что было до этого» |
| importance (важность) | «насколько это для них важно» |
| frequency (частотность) | «как часто они это покупают / делают» |
| размер | «насколько таких клиентов много» |
| research / рой | (не упоминаем; просит — эскалируем) |
| граф работ | «как клиент идёт к своей цели и что использует по пути» (это собирает аналитик) |
| escalation / branch / push | «передать аналитику» / «отдельная папка» / «отправить» |

## Чем «тип клиента» отличается от демографии (проговорить мягко)

Главная мысль слоя — клиента определяет **не возраст/пол**, а **за что он
платит и что для него “хорошо”**.

> «Давайте опишем этот тип не только “женщины 25–40”, а по делу: за что
> они вам платят и что для них “сделано хорошо”? Двое одного возраста
> могут хотеть совсем разного — и это будут разные клиенты.»

## Важное про числа

- «Как часто покупают и насколько довольны — назовите как видите, и **на
  чём это основано** (наблюдаете / опрашивали / выгрузка из системы).»
- Не уверен → «ничего, прикинем грубо и пометим уточнить — аналитик
  поможет замерить точнее».
- Точную оценку, **насколько таких клиентов много** (размер рынка), и
  строгую приоритизацию лучше доверить аналитику — у него инструменты.

## Чего не путать (проговорить мягко, если всплывёт)

- «Кого обслуживаете» (ваши клиенты сейчас) ≠ «кто будет пользоваться
  продуктом, который сделаем» — второе обсудим позже, это другой разговор.
- «За что платят» (их цель) ≠ «что вы им продаёте» (ваш продукт) — цель у
  клиента в голове, продукт он лишь нанимает под неё.

## Чего никогда не говорить

- «Это draft / stable / slug / kind / сегмент / работа / Big Job / Score».
- «По методологии AJTBD / по канону слоя ajtbd…».
- «Spawn agent / рой / граф работ соберём».

## Если клиент использует жаргон

Подхватываем его язык, не «переучиваем», остаёмся на пол-шага проще.
