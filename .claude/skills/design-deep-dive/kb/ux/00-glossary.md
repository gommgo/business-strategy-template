| Псевдолокализация | pseudolocalization | Замена строк на удлинённые с диакритикой; находит хардкод, обрезку и конкатенацию за один проход | `07-ux-writing/05 §8` |

| Радиогруппа | radio group | Выбор одного из не более чем пяти вариантов; вертикально, исчерпывающая; предвыбор — по типу вопроса | `04-components-patterns/06 §4` |

| Сигнификатор | signifier | Признак того, что и как можно сделать (Норман); одно из четырёх оправданий движения | `01-foundations/01`; `06-feedback-states-motion/03 §1.1` |

| Словарь запретов | banned words list | Стоп-слова, канцелярит, штампы, англицизмы, нейрослоп и заглушки — правила для линтера с областью и исключениями | `07-ux-writing/06` |
| Снекбар, флаг | snackbar, flag | Варианты тоста в Material 3 и Atlassian; те же правила длительности и дубля | `04-components-patterns/08 §3` |
| Сохранённые виды | saved views | Именованные наборы фильтров, сортировки, колонок и размера страницы с переименованием и удалением | `04-components-patterns/01 §10.2` |
| Спиннер | spinner | Неопределённый индикатор для одного модуля; не по центру пустого экрана вместо каркаса | `06-feedback-states-motion/02 §3` |

## Ложные друзья, омонимы и опасные атрибуции

| Термин | Опасность | Как записано в базе |
|---|---|---|
| Доступность | По-русски одно слово для availability (сервис доступен, аптайм) и accessibility (для людей с инвалидностью) | В базе «доступность» — только accessibility (a11y); для availability — «работоспособность сервиса», «аптайм» |
| Виджет | В русских разборах админок — блок-карточка на экране объекта или дашборде (W9); в англоязычной практике — встраиваемый сторонний компонент | Две записи: «блок» (карточка дашборда, секция экрана объекта) и «сторонний виджет» (чат, реклама — считается в бюджете оверлеев) |
| Дизайн-система / библиотека компонентов / библиотека паттернов | Разные артефакты и владельцы; «дизайн-система — абсурдная задача» у Бирмана — критика постановки, не термина | Три записи; по умолчанию «дизайн-система» означает библиотеку компонентов |
| Обратная карточная сортировка | Местное название tree testing (W4) | Всегда tree testing / тестирование дерева |
| «Табуретка Нормана» | Триада «пользователь — бизнес — технологии» приписывается Норману (W8); восходит к IDEO (desirability / viability / feasibility) | Не приписывать Норману; в базе — «триада IDEO» |
| Когнитивный проход | В `06-feedback-states-motion/04 §4.4` так была названа проверка «от лица уязвимого пользователя»; это линза ревью, не метод Lewis–Polson | Термин — только для метода с четырьмя вопросами на шаг; проверка E2 — «проход от лица уязвимого пользователя (линза)» |
| Критичность проблемы 0 / 0,2 / 0,5 / 1 | Шкала UsabilityLab по сценарию не совпадает с axe (minor / moderate / serious / critical) ни по числу градаций, ни по определениям; шкала Нильсена 0–4 — третья | Три шкалы, не смешивать; в базе серьёзность — 0–4 |
| Консистентность информации | В банковской практике — одинаковость и реалистичность данных на макетах (ИНН, счета, названия), отдельная роль (W12); ≠ консистентность интерфейса | Две записи |
| Экранный диктор | Русский регуляторный термин для screen reader (W12) | Синонимы; искать оба варианта |
| Стрим | В банках — линия разработки (workstream), не видеотрансляция (W12) | Пометка |
| Брейкпоинты / классы размеров окна | Material 3 в мае 2026 переименовал window size classes в breakpoints, responsive layout — в adaptive design | Одна запись «брейкпоинт» с датой; «класс размера окна» не использовать |
| Адаптивный | responsive (CSS-раскладка) против adaptive (серверное определение возможностей и прогрессивное улучшение) | Две записи: «адаптивная вёрстка» и «адаптация по возможностям» — `09-mobile/01 §2.3` |
| Плейсхолдер | Три значения: текст-пример в поле (`04-components-patterns/05 §3.2`), заглушка контента lorem ipsum (`07-ux-writing/06 §5`), плейсхолдер изображения (`06-feedback-states-motion/01 §6.3`) | Указывать значение; в правилах о формах — только первое |
