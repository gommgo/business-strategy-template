# 06 · Состояния, обратная связь, движение, этика

Волна 2 · Агент E2 · 22 сентября 2026. Прочитано целиком 30 текстовых источников (включая четыре нормативных
документа и три правовых акта) и 7 видеодайджестов.

Папка отвечает на вопрос «что интерфейс сообщает пользователю о себе и чего он не должен с ним делать».
Порядок чтения: 01 → 02 → 03 → 04. Файл 01 задаёт закрытый список состояний и годится для подстановки в контракт
генерации; файл 02 детализирует форму индикаторов; файл 03 — движение; файл 04 — запреты.

## Выжимка папки

1. **Пять базовых состояний обязательны для каждого экрана до отдачи** — идеальное, пустое, загрузка, частичное,
   ошибка; остальные 17 из закрытого списка S01–S22 добавляются по типу экрана. Перечислять поимённо, а не словами
   «продумай состояния». `[консенсус]` → 01 §1–2
2. **«Пусто» показывается только после завершения загрузки.** Сообщение «нет записей», сменяющееся данными через
   три секунды, NN/g называет особенно вредным: часть людей уходит, не дождавшись. `[исследование]` → 01 §4.6
3. **У пустого состояния всегда есть причина и выход**, и оно отвечает на четыре вопроса: обработка завершена,
   контент грузится, была ошибка, не те ли фильтры. Различаются «ещё ничего нет», «ничего не найдено» и «всё
   сделано». `[консенсус]` → 01 §4
4. **Три индикатора не взаимозаменяемы**: скелетон — страница целиком, спиннер — один модуль, прогресс-бар — процесс
   с измеримым объёмом. Скелетон только 2–10 с и только для загрузки данных, не для операции. `[консенсус]` → 02 §3
5. **Пороги показа индикатора расходятся вдвое** между NN/g (< 1 с ничего, 2–10 с спиннер, > 10 с процент) и
   Material 3 (< 200 мс, 200 мс – 5 с, > 5 с). Правило примирения: чем менее предсказуема задержка, тем ниже порог;
   против мигания — отложенный показ плюс минимальное время показа. `[спорно]` → 02 §2.4
6. **Честность важнее точности.** Прогресс, замирающий на 99 %, «can even feel deceptive»; лучше объём сделанного,
   чем выдуманный процент. Свежий эксперимент CHI 2026 (N = 425): обратный отсчёт делает ожидание субъективно
   короче, но значимо более фрустрирующим, чем счёт прошедшего времени; отсутствие таймера — худший вариант.
   `[исследование]` → 02 §4.2–4.3
7. **Движение оправдано четырьмя вещами**: обратная связь, смена состояния, пространственная связь, сигнификатор.
   Рабочий диапазон 100–400 мс, выход короче входа, ease-out на входе; чем чаще человек видит анимацию, тем она
   короче. `[консенсус]` → 03 §1, §3
8. **`prefers-reduced-motion` обязателен и пишется «наоборот»**: анимация включается в `no-preference`, а не
   выключается в `reduce`, иначе она останется у браузеров, не понимающих медиазапрос. WCAG 2.2.2 (уровень A)
   требует паузу для любого автодвижения дольше 5 с. `[консенсус]` → 03 §7
9. **Главный формальный критерий этики: отказ не должен быть дороже согласия** — по числу действий, заметности,
   каналам и времени. Отмена тем же каналом и за не большее число шагов, чем подключение, — требование DSA ст. 25(3)(c)
   и ROSCA одновременно. `[консенсус]` → 04 §1.4, §7
10. **Тёмные паттерны измеримы и проверяемы автоматически**: в краулинге 11 тыс. магазинов — 1 818 экземпляров на
    11,1 % сайтов, из 393 таймеров 157 лживых, один сайт генерировал остаток случайным числом при загрузке.
    Мягкие приёмы при этом не всплывают на юзабилити-тестах — нужен структурный разбор.
    `[исследование]` → 04 §5, §8.3
