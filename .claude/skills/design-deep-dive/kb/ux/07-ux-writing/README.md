Волна 3 · Агент G · 22 сентября 2026. Прочитано целиком 28 источников (NN/g ×8, Microsoft Writing Style Guide ×4,
Apple HIG, Shopify Polaris, Atlassian, Mailchimp, W3C i18n ×2, Unicode CLDR, ICU MessageFormat, Контур.Гайды ×7,
обзор русских индексов читаемости) и 10 видеодайджестов.

Папка отвечает на вопрос «что именно написать в каждом месте интерфейса и по каким правилам». Механика компонентов
живёт в `../04-components-patterns/`, сценарии — в `../05-flows-journeys/`, состояния — в
`../06-feedback-states-motion/`; здесь — формулировки.

Порядок чтения: `01` → `02` → язык, на котором пишете (`03` или `04`) → `06`. Файл `05` нужен, когда языков больше
одного или планируется второй.

## Выжимка папки

1. **Порядок применения правил: однозначность → сокращение → человечность.** Сначала фразу нельзя понять двояко,
   потом в ней нет лишних слов, и только потом она звучит как этот продукт. Третий шаг нужен не всякому продукту.
   `[мнение]` → `01` §2
2. **Сокращать надо мусор, а не смысл.** Слово, снимающее двусмысленность, добавляют, даже если строка удлиняется.
   Формальный редактор (Главред) не знает контекста и в микрокопи вредит. `[консенсус]` → `01` §4.3, `03` §7.4
3. **Голос один, тон меняется по ситуации.** Карта тона на 15 ситуаций фиксируется до написания экранов; в
   деньгах, безопасности, правах и деструктивных действиях тон нейтральный. Юмор запрещён там, где человек не
   достиг своей цели. `[консенсус]` → `01` §6–§8
4. **Кнопка = глагол + объект; по-русски — инфинитив совершенного вида.** «OK», «Да/Нет», «Подтвердить»,
   «Submit» как подтверждение действия запрещены. Заголовок — существительное, глагол живёт на кнопке.
   `[консенсус]` → `02` §1, `03` §2
5. **Имя действия одно на весь поток**: кнопка «Опубликовать» → заголовок «Опубликовать статью?» → сообщение
   «Опубликовано» → статус «Опубликован». Закрывает дефект F7.3. `[система]` → `02` §1.6
6. **Ошибка = что случилось + почему + что сделать**, без кода как текста, без «неверно», без «что-то пошло не
   так», без точки и восклицательного знака. Извиняться только там, где виноват сервис. `[консенсус]` → `02` §6
7. **Четыре причины пустоты — четыре разных текста и тона.** «Здесь пусто» и «Нет данных» без продолжения
   запрещены; заголовок утвердительный («Здесь появятся проекты»), кроме случая «ничего не нашлось».
   `[консенсус]` → `02` §5
8. **У русского четыре плюральные формы, и `other` — это дробные.** Ручные тернарники по числу и конкатенация
   строк запрещены; всё через ICU. `[стандарт]` → `03` §4, `05` §4
9. **Русская строка может быть вдвое длиннее английской или на треть короче**: таблица IBM даёт 200–300 %
   расширения для строк до 10 знаков. Проектировать по худшему случаю, а не по среднему «+10–15 %».
   `[исследование]` → `03` §5, `05` §6.2
10. **Типографика фиксируется один раз на продукт**: ёлочки, одно длинное тире, серое тире как прочерк при
    отсутствии данных, «ё» в именах собственных и при разночтениях, неразрывные пробелы, точек нет в подписях и
    заголовках, только первое слово с заглавной. `[система]` → `03` §6
11. **Гайд заказчика о нейрослопе переносится в интерфейс частично.** Лексика и синтаксис — да; правила про число
    тире, разброс длин предложений, личный голос и «сломанный ритм» — нет: в интерфейсе единообразие однотипных
    элементов — достоинство. `[решение базы]` → `06` §6
12. **Словарь запретов подключается как линтер с ролями узлов**, потому что без контекста «Отмена» на кнопке и
    «Отмена» в заголовке неразличимы. Готовый блок запретов для контракта генерации — `06` §9. `[система]`
