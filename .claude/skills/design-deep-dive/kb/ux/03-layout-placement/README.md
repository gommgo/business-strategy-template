## Выжимка папки

1. **Каркас приложения одинаков на всех экранах**; меняется только основная область. Регионы: полосы (шапка,
   панель действий), рейки (навигация слева, инспектор справа), панели (содержимое). `[система]`
2. **Шапка страницы обязательна**: путь назад, H1, статус, действия. Одно главное действие — primary-кнопка
   справа в шапке. Заголовок списка — имя типа объекта во множественном числе. `[система]`
3. **Создание и редактирование по умолчанию — отдельная страница.** Модалка только для короткого
   самодостаточного ввода; «Resist the temptation to use modals and wizards on complex apps… context is king». `[мнение]`
4. **Дашборд — один экран, 3–6 показателей вверху**, только длина и 2D-позиция кодируют величину; круговые,
   кольцевые, tree map и «спидометры» для быстрого чтения не годятся. `[исследование]`
5. **Пространства между группами больше, чем внутри группы**; группировать пространством, а не рамками — на этом
   независимо сходятся Carbon, Fluent и Polaris. `[консенсус]`
6. **Начинай с избытка воздуха и убирай**: «White space should be removed, not added». При этом современные
   страницы скорее слишком разрежены, чем слишком плотны (данные айтрекинга NN/g 2018). `[исследование]`
7. **Плотность — решение под задачу**: эксперт, ежедневная работа, сравнение данных → плотнее; редкая задача,
   клиентский сервис, ввод данных → воздушнее. Разделы могут быть плотными, страница целиком — нет. `[консенсус]`
8. **Три уровня иерархии, не больше трёх размеров и трёх вариантов контраста, максимум два крупных элемента,
   одна primary-кнопка.** Иерархию создают приглушением второстепенного, а не усилением главного. `[мнение]`
9. **Верх экрана решает**: 57% времени просмотра выше сгиба, 74% в первых двух экранах, 42% в верхних 20%
   страницы; разница внимания над и под сгибом — порядка 84%. `[исследование]`
10. **Стандартные места и отсутствие повторов**: логотип слева ведёт на главную (центрированный — провал
    возврата в 6 раз чаще), утилиты справа вверху, действия формы внизу слева под полями (айтрекинг LukeW),
    пагинация снизу, один путь навигации к разделу, одно действие — один раз на экране. `[исследование]`
