# Глоссарий: отступы, размеры, плотность

Волна 1, агент C, 22 сентября 2026. Термины темы «отступы и размеры». Формат: русский термин (английский оригинал) — определение, пример значения. Термины формы и глубины в `../04-shape-elevation/glossary.md`. Сводный глоссарий проекта собирается в `00-glossary/`.

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Базовая единица | base unit, grid unit | Наименьший шаг, на который кратны все отступы и размеры системы | 4 px (Polaris, Primer, Tailwind), 8 px (Atlassian «space.100») |
| Шкала отступов | spacing scale | Закрытый список разрешённых значений отступов | 2, 4, 8, 12, 16, 24, 32, 48, 64, 96 |
| Мини-юнит | mini-unit | Имя базовой единицы в Carbon; токены выражаются в кратных ему | `miniUnit = 8`, `spacing-05 = miniUnits(2) = 16px` |
| Внутренний отступ | padding, inset | Расстояние от границы контейнера до его содержимого | карточка 16, модалка 24 |
| Внешний отступ | margin | Расстояние снаружи элемента; в современных системах вытесняется `gap` | не используется внутри компонентов (Carbon Stack) |
| Зазор | gap | Расстояние между соседними элементами, задаётся родителем | `gap: 8px` в группе кнопок |
| Сжатый внутренний отступ | inset squish | Внутренний отступ с уменьшенной (обычно вдвое) вертикалью | кнопка 6 × 12, ячейка 8 × 16 |
| Растянутый внутренний отступ | inset stretch | Внутренний отступ с увеличенной вертикалью | textarea 12 × 12 при однострочном 8 × 12 |
| Стек | stack | Вертикальный ритм между блоками; компонент-обёртка с `gap` | Primer stack: condensed 8, normal 16, spacious 24 |
| Инлайн-набор | inline | Горизонтальный набор с переносом: теги, крошки, кнопки | gap 8 |
| Внешние поля страницы | page margins, page inline padding | Расстояние от края окна до контента | 16 / 24 / 32–40 по брейкпоинтам |
| Гаттер | gutter | Расстояние между колонками сетки | Carbon 16–24, GOV.UK 30 |
| Правило близости | law of proximity | Принцип восприятия: близкие элементы читаются как группа | отступ между группами ≥ 2× внутреннего |
| Воздух, белое пространство | whitespace, negative space | Незанятая площадь; инструмент группировки и иерархии | «double your whitespace» (Kennedy) |
| Оптическая компенсация | optical adjustment | Ручная правка на 1–2 px ради визуального баланса | иконка сдвинута на 1 px вправо в круглой кнопке |
| Отрицательный отступ | negative space token | Токен с отрицательным значением для выхода за padding контейнера | `space.negative.200` = −16 |
| Плотность | density | Количество информации на единицу площади; задаётся высотами и padding | compact / default / comfortable |
| Шаг плотности | density interval | На сколько меняется высота при переходе на соседний режим | 4 px (Material `$interval`) |
| Шкала плотности | density scale | Числовой параметр режима | Material 0, −1, −2, −3 |
| Компактный алгоритм | compact algorithm | Производная тема Ant Design с уменьшенными размерами | `controlHeight` 32 → 28 |
| Масштабный множитель | scaling factor | Глобальный коэффициент для всех размеров темы | Radix `--scaling` 0.9…1.1, Mantine `scale` |
| Высота контрола | control height | Внешняя высота кнопки, поля, select | 24 / 28 / 32 / 36 / 40 / 48 |
| Контейнерный токен | container token | Токен высоты интерактивного элемента в Carbon | `container-03 = 40px` |
| Цель нажатия | touch target, target size | Область, реагирующая на клик или касание | 24 × 24 (WCAG AA), 44 × 44 (AAA), 48 dp (Material) |
| Недоразмерная цель | undersized target | Цель меньше 24 × 24, проверяется правилом кругов | 20 × 20 с зазором 4 проходит |
| Правило кругов | spacing exception | Круги диаметром 24 px вокруг центров недоразмерных целей не должны пересекаться | из Understanding 2.5.8 |
| Расширенная зона нажатия | expanded hit area | Увеличение активной области без изменения видимой | `::after { inset: -6px }` |
| Асимметрия «видно/нажимается» | view–tap asymmetry | Элемент читается, но слишком мал для касания | точки каруселей iOS, свотчи 1 мм |
| Закон Фиттса | Fitts's law | Время достижения цели растёт при уменьшении размера и росте расстояния | обоснование крупных частых кнопок |
| Плотность указателя | pointer type | Медиа-признак типа ввода | `@media (pointer: coarse)` → цели 44+ |
| Размерный вариант | size variant | Именованный набор размеров компонента | small / medium / large |
| Сайдбар | sidebar, side navigation | Боковая навигационная панель | 240–280, свёрнутый 48–72 |
| Рельс | rail | Свёрнутый сайдбар с одними иконками | Carbon 48 px |
| Верхняя панель | top bar, app bar, masthead | Горизонтальная панель приложения сверху | 48–64 |
| Панель свойств, инспектор | inspector, properties panel | Правая панель с параметрами выбранного объекта | 280–400 |
| Дровер | drawer, side panel, sheet | Выезжающая панель поверх контента | 400–560 или 40 % ширины |
| Оверлей | overlay | Общее имя для всплывающих слоёв (меню, поповер, диалог) | Primer overlay 192/320/480/640/960 |
| Поповер | popover | Всплывающий блок, привязанный к триггеру | 240–320 |
| Выпадающее меню | dropdown menu | Список действий, привязанный к кнопке | 160–280, пункт 32 |
| Тултип | tooltip | Короткая подсказка при наведении | max-width 240–320, padding 6–8 × 8–12 |
| Тост, снэкбар | toast, snackbar | Временное уведомление | ширина 320–400 |
| Смещение слоя | overlay offset | Зазор между триггером и всплывающим слоем | 4 px (Primer) |
| Скрим | scrim, backdrop | Затемняющая подложка под модалкой | 32–60 % чёрного |
| Класс ширины поля | width class | Привязка ширины поля к ожидаемой длине данных | GOV.UK: 2, 4, 10, 20 символов, full |
| Мера строки | measure | Длина строки текста в символах | 45–75, детали в `02-typography/` |
| Высота строки списка | row height | Внешняя высота строки таблицы или списка | 32 / 40 / 48 / 56 |
| Липкая шапка | sticky header | Закреплённая шапка таблицы или страницы | тень появляется при скролле |
| Семантический токен | semantic token, alias token | Токен роли, ссылающийся на значение шкалы | `--space-card-padding: var(--space-5)` |
