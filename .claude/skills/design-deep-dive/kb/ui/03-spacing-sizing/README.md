# 03. Отступы, размеры, плотность

Волна 1, агент C, 22 сентября 2026. Прочитано целиком 39 источников (исходники дизайн-систем, спецификации W3C, материалы практиков) плюс 6 видеодайджестов агента V. Сырые заметки: `../99-raw/notes/wave1/C-notes.md`, отчёт: `../99-raw/reports/wave1-C-report.md`.

## Выжимка папки

1. Базовая единица **4 px**; рабочая шкала 2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 96 (8–13 шагов). Линейно внизу, разреженно вверху.
2. Правило группировки: **отступ между группами ≥ 2× отступа внутри группы**; внешний padding контейнера ≥ внутренних зазоров.
3. Порядок разделения блоков: сначала отступ, затем линия 1 px, затем смена фона, и только потом тень.
4. Padding: кнопка 6 × 12 при высоте 32, поле 12 по горизонтали, карточка 16 (админка) или 24 (клиент), модалка 24, ячейка таблицы 6–16.
5. Поля страницы 16 / 24 / 32–40 по брейкпоинтам; на мобильном сжимаются только отступы выше 16 px.
6. Плотность задаётся высотами и padding, **не размером шрифта**; шаг плотности 4 px; режимов два, максимум три.
7. Цели нажатия: **24 × 24 CSS px** минимум по WCAG 2.2 AA (или зазоры по правилу кругов), **44–48 px** на тач, 32 комфортно для мыши.
8. Высоты контролов из ряда **24 / 28 / 32 / 36 / 40 / 48**; в одном ряду высоты совпадают; иконочная кнопка квадратная.
9. Панели: сайдбар 240–280 (свёрнутый 48–72), верхняя панель 48–64, инспектор 280–400, дровер 400–560, модалки 400 / 560–640 / 800–960, поповер 240–320, тост 320–400.
10. Два готовых пресета (плотная админка и клиентский сервис) и таблица «20 самых частых размеров» лежат в `03-control-and-panel-sizes.md`.
