# Глоссарий: сетка, раскладка, каркасы, анатомия страниц

Волна 2, агент D, 22 сентября 2026. Термины темы «сетка и раскладка». Формат: русский термин (английский
оригинал) — определение, пример значения. Термины отступов и размеров — в
`../03-spacing-sizing/glossary.md`, формы и глубины — в `../04-shape-elevation/glossary.md`. Сводный
глоссарий проекта собирается в `../00-glossary/`.

## Сетка

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Колоночная сетка | column grid | Раскладка из равных колонок с промежутками, к которым выравниваются контейнеры верхнего уровня | 12 колонок (Bootstrap, Atlassian, Fluent), 16 (Carbon), 24 (Ant) |
| Колонка | column | Одна вертикальная дорожка сетки | при контейнере 1200, 12 колонках и гаттере 24 колонка = 78 px |
| Гаттер, межколонник | gutter | Расстояние между соседними колонками | Bootstrap 24, Atlassian 12/16, Carbon wide 32 / narrow 16 / condensed 1 |
| Поле сетки | margin | Расстояние от края вьюпорта до первой колонки | 16 / 24 / 32–40 по брейкпоинтам |
| Резиновая сетка | fluid grid | Число колонок фиксировано, ширина колонки растёт с окном | Carbon fluid |
| Фиксированная сетка | fixed grid | Ширина блока фиксирована, число колонок растёт с окном | Carbon fixed: плитка 320 × 160 |
| Гибридная сетка | hybrid grid | Сочетание fluid и fixed в одной раскладке | Carbon hybrid |
| Ключевая линия | key line | Видимая вертикаль или горизонталь, по которой выровнено несколько объектов | левый край контента: заголовок, тулбар, таблица, кнопки |
| Модель раскладки за максимумом | style model | Что происходит с сеткой выше максимального брейкпоинта | Carbon: editorial (центр), product and docs (влево), high-density (вся ширина) |
| Влияющий на сетку | grid influencer | Элемент каркаса, меняющий сетку при появлении | левая навигация не меняет число колонок, выезжающая панель уменьшает |
| Вложенная сетка | subgrid, nested grid | Дочерняя сетка внутри колонки родительской | Carbon v11 через CSS Grid |
| Базовая единица сетки | mini unit | Квадрат, кратными которому задаются размеры | Carbon 8 × 8 px |
| Соотношение сторон блока | aspect ratio | Пропорция плитки сетки | Carbon: 1:1, 2:1, 2:3, 3:2, 4:3, 16:9 |
| Модульная сетка | modular grid | Колонки плюс ряды: матрица модулей | Fluent 2, один из четырёх типов |
| Рукописная сетка | manuscript grid | Одна колонка для длинного текста | статья, документация |
| Базовая линия | baseline grid | Горизонтальные линии, по которым сидят строки текста | Fluent 2, один из четырёх типов |

## Брейкпоинты и адаптация

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Брейкпоинт | breakpoint | Ширина вьюпорта, на которой меняется раскладка | Tailwind 640 / 768 / 1024 / 1280 / 1536 |
| Класс окна | window size class | Именованный диапазон ширин | Material 3: compact < 600, medium 600–839, expanded 840–1199, large 1200–1599, extra-large ≥ 1600 |
| Класс размера | size class | Пара значений compact/regular по каждой оси (Apple) | iPhone в портрете: compact × regular |
| Запрос к контейнеру | container query | Медиазапрос по размеру родительского контейнера, а не окна | `@container panel (min-width: 400px)` |
| Тип контейнера | container-type | Объявление контекста для container query | `inline-size` — рабочий вариант |
| Единицы контейнера | cqw, cqi, cqb | Проценты от размеров контейнера запроса | `font-size: max(1.5em, 1.23em + 2cqi)` |
| Перетекание | reflow | Перестроение контента без двумерной прокрутки | WCAG 1.4.10: 320 CSS px ширины, 256 высоты |
| Пять приёмов адаптации | reposition, resize, reflow, show/hide, re-architect | Классификация Fluent 2 | reflow: 4 колонки → 2 → 1 |
| Внутренняя раскладка | intrinsic layout | Раскладка без медиазапросов, правила задаются самим компонентом | `flex-basis: 280px; flex-grow: 999; min-inline-size: 50%` |
| Безопасная зона | safe area | Область экрана, не перекрытая вырезом и системными полосами | `env(safe-area-inset-bottom)` ≈ 34 px на iPhone |
| Малый вьюпорт | svh | Высота при развёрнутых панелях браузера | `max-height: 85svh` у нижнего листа |
| Большой вьюпорт | lvh | Высота при скрытых панелях; равен `vh` | `100vh` = `100lvh` |
| Динамический вьюпорт | dvh | Высота, меняющаяся при прокрутке | `height: 100dvh` у каркаса |

| Панель инструментов | toolbar | Полоса с поиском, фильтрами и переключателями вида над контентом | 48 (плотно) / 56–64 (просторно) |
| Контекстная полоса | context bar | Слот шапки страницы, видимый только на узких вьюпортах (Primer) | родительская ссылка + действия контекста |
| Ведущий визуал | leading visual | Иконка или аватар слева от заголовка страницы; виден на всех вьюпортах | 16–32 |

| Дашборд | dashboard | Набор визуализаций в один экран, дающий информацию с одного взгляда | NN/g; 44 % корпуса влезают без прокрутки |
| Операционный дашборд | operational dashboard | Непрерывно обновляемые данные, срочные решения | мониторинг, диспетчеризация |

## Композиция

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Оптическое выравнивание | optical alignment | Выравнивание по зрительному, а не геометрическому центру | сдвиг треугольной иконки на 1–2 px |
| Оптический центр | optical center | Точка, воспринимаемая как центр; чуть выше геометрического | — |
| Точка высокого контраста | high-contrast point | Граница, от которой реально отмеряется расстояние | край заливки, а не текст внутри |
| Правило внутреннего и внешнего | proximity rule, inner/outer spacing | Внутри группы расстояния меньше, чем между группами | 12 внутри → ≥ 24 снаружи |
| Якорный объект | anchor object | Крупный элемент, задающий левый верхний угол блока | заголовок карточки 16 px вес 600 |
| Визуальный вес | visual weight | Сила притяжения взгляда: площадь, контраст, насыщенность, вес шрифта | одно пятно первого уровня на экран |
| Ритм | rhythm | Повтор элементов и интервалов | строки таблицы 36 через 0 |
| Повтор, чередование, градация | repetition, alternation, gradation | Три способа создать ритм | одинаковые карточки; заголовок/текст; шкала кеглей |
| F-паттерн | F-pattern | Сканирование «стены текста»: горизонталь, вторая короче, вертикаль слева | худший из паттернов, возникает при отсутствии зацепок |
| Слоёный пирог | layer-cake | Сканирование по заголовкам с пропуском текста между ними | целевой паттерн интерфейса |
| Пятнистое сканирование | spotted | Взгляд прыгает по выделенным словам и числам | — |
| Отметка | marking | Взгляд удерживается в одной точке при прокрутке | чаще на мобильном |
| Обход | bypassing | Пропуск одинаковых первых слов в строках списка | «Заказ № …» игнорируется |
| Диаграмма Гутенберга | Gutenberg diagram | Схема движения взгляда от левого верха к правому низу | **не применима** к интерфейсам с иерархией |
| Залежная зона | fallow area | Угол, который по диаграмме Гутенберга получает мало внимания | правый верх — сильная, левый низ — слабая |
| Сгиб | fold | Нижняя граница первого экрана | 57 % времени просмотра выше сгиба |
| Ложное дно | false floor | Первый экран выглядит законченным, и дальше не прокручивают | лечится обрезкой блока по краю экрана |
| Тест на прищур | squint test | Проверка иерархии на размытом макете | Gaussian blur 6–10 px при ширине 1440 |
| «Почти, но не совсем» | almost-but-not-quite | Разница в 1–3 px между величинами, которые должны быть равны | карточки 204 и 208 |
