## Выжимка папки

1. Приложению хватает **3–4 брейкпоинтов**: mobile < 640, tablet 640–1023, desktop 1024–1439, wide ≥ 1440.
   Главный порог — **1024**: ниже него сайдбар сворачивается, ниже 768 уходит в оверлей.
2. Каркас: **сайдбар 240–288** (измеренная медиана 276, центр 272–288, потолок 319), **шапка 48–64**
   (медиана 56, самое частое значение у приложений 48), правая панель **320–400**. Панелей не больше трёх;
   контентной области всегда оставлять **≥ 640 px**. Геометрия каркаса не зависит от темы.
3. Максимальные ширины по типу контента: абзац **640–720**, форма **480–640**, настройки 640–720, страница
   объекта 1200–1280, таблица и дашборд — **fluid**. Для русского 640 px при 16 px = 73–83 знака.
4. На 1920 и 2560 выбирается одна из трёх стратегий Carbon: центрировать, прижать влево при наличии
   сайдбара, тянуть на всю ширину и добавлять колонки по две. Сайдбар и панели **не растут**.
5. Анатомия страницы всегда одна: шапка страницы (≤ 120 px) → вкладки → тулбар 48 → контент → пагинация 32.
   Отступ «шапка → контент» 24 (плотно) / 32 (просторно), между секциями 32 / 48.
6. Первичное действие **одно** и в первом экране: айтрекинг даёт **57 %** времени на первом экране, **42 %**
   на верхних 20 % страницы, **74 %** на первых двух экранах (до 2160 px).
7. Дашборд — страница-сводка в один экран, а не жанр приложения: **49 %** дашбордов используют раскладку
   «сверху вниз по важности», **61 %** умещаются в одну страницу, **44 %** обходятся без прокрутки.
   Измеренные карточки: KPI 250–276 × 106–237, половина ширины 507–568 × 367–486, gap 16–24.
8. Композиция: всё выровнено по одной левой вертикали, воздуха между группами вдвое больше, чем внутри, над
   заголовком секции втрое-вчетверо больше, чем под ним, одно средство группировки из трёх.
9. Паттерны F, Z и диаграмма Гутенберга к интерфейсам приложений **не применимы**: «паттерны исчезают в
   присутствии дизайна». Целевой паттерн — layer-cake, сканирование по заголовкам.
10. Два готовых пресета каркаса с точными числами и ASCII-схемами лежат в `02-app-shells.md` §10; каталог
    ошибок нейросетей с порогами и скриптом проверки — в `06-ai-errors-and-checks.md`.
