## Выжимка папки

1. **Стабильная версия формата одна: DTCG 2025.10** (Final CG Report, 28.10.2025). `tr.designtokens.org`
   отдаёт черновик 2026 с запретом на реализацию — ссылаться надо на `www.designtokens.org/TR/2025.10/`.
2. **Два уровня токенов обязательны, третий — опция.** Компонентный токен заводят, когда значение нужно
   трём и более компонентам; автор трёхуровневой модели сам пишет, что три уровня «may be overkill».
3. **Семантических токенов продукту нужно 150–300.** У shadcn их 37 (нижняя граница жизнеспособности),
   у Atlassian 596 (платформа из десятков продуктов), у Plasma ~2000 на режим. Эталонная схема — 184.
4. **`dimension` — объект `{value, unit}` только с `px` или `rem`.** Ни `em`, ни `%`, ни строк `"16px"`.
   Трекинг в `em` стандартом не выражается: считается в px на каждую роль.
5. **`lineHeight` в составном типографическом токене — безразмерное число.** Отношения подобраны так,
   что произведение целое: 11 × 1.454545 = 16, 14 × 1.428571 = 20.
6. **Правила применения лежат внутри токена**, в расширении с полями `usage`, `rules`, `doNotUse`,
   `alternatives` — формат `org.primer.llm` у GitHub Primer, скопированный в эталонную схему. Три
   уровня модальности: `MUST use for…`, `RECOMMENDED default for…`, `Use for…`, запрет `Do NOT use for…`
   с причиной в том же предложении.
7. **Тема и режим — разные оси.** Хранить надо оси (бренд, режим цвета, контраст, плотность), а не их
   произведение: 12 наборов вместо 60. Стандартный механизм — Resolver Module.
8. **Переменная-ссылка в CSS разрешается в точке объявления.** Переключатель темы вешается туда же, где
   объявлена семантика (`:root`); блок режима содержит весь транзитивный список изменившихся токенов, а
   не только явные переопределения.
9. **Тёмная тема — не инверсия.** Шаг светлоты между слоями втрое больше, альфа состояний в полтора
   раза выше, сплошные заливки уходят на светлые ступени с тёмным передним планом, глубину несёт кольцо,
   а не тень.
10. **Характер продукта задаётся семью ручками:** акцент, нейтраль, радиус, плотность, шрифт, тени,
    тема. Смена акцента требует перепроверки всех пар контраста — генератор печатает 87 пар и коридор APCA отключённого текста на каждой
    сборке.
