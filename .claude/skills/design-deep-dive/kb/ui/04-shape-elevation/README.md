# 04. Форма и глубина: радиусы, границы, тени, слои, фокус

Волна 1, агент C, 22 сентября 2026. Прочитано целиком 39 источников (исходники дизайн-систем, спецификации W3C и MDN, материалы практиков) плюс 6 видеодайджестов агента V. Сырые заметки: `../99-raw/notes/wave1/C-notes.md`, отчёт: `../99-raw/reports/wave1-C-report.md`.

## Выжимка папки

1. Держи **4–6 радиусов**, выведенных из одного базового числа (`--radius`), и **5–6 уровней теней**. Больше никто не различает.
2. Дефолтный радиус: **4–6 px в строгой админке, 8–10 px в клиентском сервисе**; радиус ≤ 25 % меньшей стороны элемента.
3. Вложенный радиус: **внутренний = внешний − padding**. Apple делает то же на уровне платформы (концентричные углы).
4. Граница **1 px** по умолчанию, 2 px только для фокуса и выбранного состояния; цвет контрастирует и с контейнером, и с фоном.
5. Порядок разделения: **отступ → линия → фон → тень**. Два жёстких разделителя подряд запрещены.
6. Тень это заявление «объект над другим». **Карточки в плотной админке обходятся границей**, тень начинается с меню и поповеров.
7. Модель тени по умолчанию: **key + ambient (две тени) плюс кольцо 1 px**; blur ≈ 2 × offset; один источник света на страницу.
8. В тёмной теме глубина передаётся **осветлением поверхности и усиленным кольцом**, тень остаётся слабым дополнением.
9. `z-index` только из шкалы (10 / 100 / 200 / 1000 / 1100 / 1200 / 1300 / 1400 / 1500), всплывающие слои в порталах.
10. Фокус: `:focus-visible`, кольцо **2 px с offset 2 px**, контраст изменения ≥ 3:1; вдавленное внутрь кольцо требует 3 px.
11. Стекло (`backdrop-filter`) это Baseline 2024, но не больше **двух элементов на экран**, и всегда с непрозрачной подложкой под текстом.
12. `corner-shape: squircle` (то есть `superellipse(2)`) на сентябрь 2026 только в Chromium 139+: применять как прогрессивное улучшение.
