# Глоссарий: форма, границы, тени, слои

Волна 1, агент C, 22 сентября 2026. Термины темы «форма и глубина». Формат: русский термин (английский оригинал) — определение, пример значения. Термины отступов и размеров в `../03-spacing-sizing/glossary.md`. Сводный глоссарий проекта собирается в `00-glossary/`.

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Радиус скругления | border radius, corner radius | Радиус дуги, которой скруглён угол элемента | 6 px (Primer, Ant), 8 px (Polaris) |
| Шкала форм | shape scale | Набор разрешённых радиусов системы | Material 3: 0/4/8/12/16/28/full |
| Вложенный радиус | nested radius | Радиус внутреннего элемента, согласованный с внешним | внутренний = внешний − padding |
| Концентричные углы | concentric corners | Углы вложенных элементов с общим центром кривизны | Apple: контролы концентричны углам окна |
| Пилюля | pill | Форма с радиусом, равным половине высоты | `border-radius: 9999px` |
| Полный радиус | full radius | Токен «максимального» радиуса | 9999 px (Polaris), 10000 (Fluent), 999999 (Carbon) |
| Частичный радиус | partial radius, corner token | Скругление только части углов | `corner-large-top` = 16 16 0 0 |
| Суперэллипс | superellipse | Кривая `x^(2K)+y^(2K)=1`, обобщение окружности | `superellipse(2)` = squircle |
| Сквиркл | squircle | Суперэллипс с K = 2, «эппловское» скругление | `corner-shape: squircle` |
| Сглаживание углов | corner smoothing | Плавное изменение кривизны на переходе сторона-угол | ползунок в Figma, `superellipse()` в CSS |
| Непрерывные углы | continuous corners | Термин Apple для сглаженных углов | `RoundedRectangle(style: .continuous)` |
| Скос | bevel | Прямой срез угла | `corner-shape: bevel` = `superellipse(0)` |
| Вогнутый угол | scoop | Угол, выгнутый внутрь по дуге | `corner-shape: scoop` = `superellipse(-1)` |
| Вырез | notch | Прямоугольный вырез в углу | `corner-shape: notch` = `superellipse(-∞)` |
| Библиотека форм | shape library | Набор именованных фигур системы | Material 3 Expressive: 35 фигур |
| Морфинг формы | shape morphing | Плавный переход одной фигуры в другую | `Morph.toPath(progress)` в Compose |
| Язык форм | shape language | Согласованный набор форм, задающий характер продукта | один параметр `--radius` и множители |
| Граница | border | Линия по периметру элемента, входит в габарит | 1 px |
| Обводка | outline | Линия вокруг элемента, не влияющая на поток | `outline: 2px solid` + `outline-offset: 2px` |
| Кольцо | ring | Граница, нарисованная тенью с нулевым blur | `box-shadow: 0 0 0 1px` |
| Внутренняя тень-граница | inset border shadow | Граница через `inset box-shadow` без сдвига раскладки | Primer `boxShadow.thin`, Polaris `shadow-border-inset` |
| Разделитель | divider, separator, rule | Линия между блоками или строками | 1 px, 0.66 px на HiDPI |
| Поле с обводкой | outlined field | Поле ввода с границей по периметру | стандарт большинства систем |
| Поле с заливкой | filled field | Поле с фоновой подложкой и нижней линией | Material filled text field |
| Высота, глубина | elevation | Условное расстояние элемента от базовой плоскости | Material 3: 0/1/3/6/8/12 dp |
| Ключевая тень | key shadow | Короткая резкая тень от направленного света | M3 level3: `0 1px 3px 0`, opacity 0.3 |
| Рассеянная тень | ambient shadow | Мягкая тень от окружающего света | M3 level3: `0 4px 8px 3px`, opacity 0.15 |
| Ядро тени | umbra | Самый плотный слой тени в модели Material 2 | alpha 0.2 |
| Полутень | penumbra | Средний слой тени в модели Material 2 | alpha 0.14 |
| Слоёная тень | layered box-shadow | Тень из нескольких box-shadow с растущими offset и blur | 5 слоёв с alpha 0.12 |
| Контактная тень | contact shadow | Короткая тень у самой поверхности | `0 1px 3px rgb(0 0 0 / .05)` |
| Размытие | blur radius | Радиус растушёвки тени | blur ≈ 2 × offset |
| Разброс | spread | Расширение или сжатие тени до размытия | `-4px` поджимает, `+3px` расширяет |
| Тень-подсказка переполнения | overflow shadow | Inset-тень у края прокручиваемой области | `inset 10px 0 8px -8px` (Ant) |
| Наложение высоты | elevation overlay | Белая плёнка поверх поверхности в тёмной теме | `--mdc-elevation-overlay-opacity` |
| Оттенок поверхности | surface tint | Подмешивание акцента в поверхность с ростом высоты | Material 3 |
| Скрим | scrim, backdrop | Затемняющая подложка под модалкой | `rgb(0 0 0 / .40)` |
| Контекст наложения | stacking context | Область, внутри которой действуют свои z-index | создаётся `transform`, `filter`, `opacity < 1` |
| Шкала z-index | z-index scale | Набор значений слоёв в виде токенов | Bootstrap 1000–1090, MUI 1000–1500 |
| Портал | portal | Рендер всплывающего слоя в конец документа | обходит контексты наложения |
| Размытие подложки | backdrop-filter | Фильтр, применённый к тому, что за элементом | `blur(12px) saturate(180%)` |
| Стекло | glassmorphism, frosted glass | Полупрозрачная поверхность с размытием подложки | фон 72 % + blur 12 px |
| Liquid Glass | Liquid Glass | Материал Apple (2025): прозрачность, преломление, блики | воспроизводим в вебе частично |
| Слой состояния | state layer | Полупрозрачный слой поверх элемента для hover/pressed | M3: hover 0.08, pressed 0.12 |
| Подъём при наведении | hover lift | Рост тени и сдвиг элемента при наведении | тень на уровень выше, `translateY(-1px)` |
| Индикатор фокуса | focus indicator, focus ring | Видимая рамка у элемента с клавиатурным фокусом | 2 px, offset 2 px, контраст 3:1 |
| Двухцветное кольцо | two-color focus indicator | Индикатор из светлой и тёмной части для любого фона | GOV.UK: жёлтый фон + чёрная полоса 4 px |
| Видимый фокус | `:focus-visible` | Псевдокласс, срабатывающий при клавиатурной навигации | заменяет `:focus` для колец |
| Принудительные цвета | forced colors | Режим высокой контрастности ОС | `@media (forced-colors: active)` |
