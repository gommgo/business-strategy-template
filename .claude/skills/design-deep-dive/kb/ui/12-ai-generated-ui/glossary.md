# Глоссарий: нейросети и визуальный слой интерфейса

Волна 3, агент H, 22 сентября 2026. Термины этой папки: RU, EN, определение в 1–2 строки, пример значения
или ссылка. Термины цвета, типографики, отступов, формы, сетки, компонентов, токенов и стилей — в
глоссариях соответствующих папок.

## 1. Модели и генерация изображений

| RU | EN | Определение | Пример |
|---|---|---|---|
| Генератор изображений, текст-в-картинку | text-to-image model, T2I | Модель, создающая растровое изображение по текстовому описанию | GPT-Image-2.5, Nano Banana Pro, FLUX.2 |
| Картинка-из-картинки | image-to-image, img2img | Генерация нового изображения на основе входного с заданной силой преобразования | скриншот каркаса → стилизованный макет |
| Референс стиля | style reference | Изображение или код, задающие эстетику всей серии | Midjourney `--sref`, Ideogram Style Code, Recraft `style_id` |
| Вес стиля | style weight | Сила влияния референса стиля на результат | Midjourney `--sw` |
| Мультиреференс | multi-reference | Несколько входных изображений в одном запросе | FLUX.2 до 10, Nano Banana Pro до 14 |
| Мудборд | moodboard | Набор изображений как источник стиля, без текстового описания | функция Moodboards в Midjourney |
| Сид | seed | Число, инициализирующее генерацию; должно давать повторяемость | у Midjourney V8.1/8.2 даёт «99 % identical», то есть неполную |
| Шаги | steps | Число итераций сэмплирования; влияет на детализацию и точность типографики | FLUX.2 [flex]: 6 / 20 / 50 |
| Негативный промт | negative prompt | Явное перечисление того, чего не должно быть в результате | «no gradients, no glow, no emoji» |
| Открытые веса | open weights | Модель, чьи веса опубликованы и запускаются локально | FLUX.2 [dev] 32B, Qwen-Image (Apache 2.0) |
| Векторная генерация | vector generation | Выдача SVG, а не растра | Recraft `Vector art`, V4 Styles |
| Цифровой водяной знак | digital watermark | Скрытая или видимая метка происхождения | SynthID у Google; видимая «искра» Gemini на free и Pro |
| Управляющая карта | ControlNet, Canny, Depth | Карта контуров или глубины, задающая геометрию при генерации | вайрфрейм как карта контуров |

## 2. Задачи и бенчмарки

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Макет-в-код | design-to-code, UI-to-code | Генерация кода по скриншоту или прототипу | Design2Code, DesignBench |
| Переход состояния за один шаг | single-step transition | Генерация следующего состояния интерфейса по одному действию | GEBench: > 80 у двух лидеров |
| Многошаговая траектория | multi-step planning | Пять последовательных состояний по общей цели | GEBench: падение ниже 60, у открытых моделей ниже 10 |
| Привязка к координате | grounding | Генерация изменения в заданной точке `[0,1000]` | GOAL 23,9 % у лучшей модели |
| Дрожание, порча макета | jitter | Контролируемое внесение дефекта в исходный макет для обучения и оценки | 9 функций JitterWeb, до трёх одновременно |
| Пертурбация | perturbation | То же для метаданных макета: сдвиг, смена шрифта, смена цвета | 1–3 на макет в AesEval-Bench |
| Совпадение блоков | Block-Match | Доля воспроизведённых и невыдуманных визуальных блоков | GPT-4o 93,0 из 100 |
| Сходство позиции | Position similarity | Нормированное расстояние между центрами сопоставленных блоков | 85,5 у лучшей модели |
| Сходство цвета | Color similarity | Близость цвета текста по CIEDE2000 | 84,1 у лучшей, 71,4 у Claude 3 Opus |
| Похожесть по CLIP | CLIP similarity | Косинусная близость эмбеддингов скриншотов | 90,4 у лучшей |
| Сходство модификации кода | Code Modification Similarity, CMS | Насколько правка попала туда, куда нужно | 0,23–0,68 при компиляции > 0,9 |
| Пересечение по объединению | Intersection over Union, IoU | Мера совпадения предсказанной и эталонной рамки | 0,004 без разметки, 0,222 с патчами |
| Средний обратный ранг | Mean Reciprocal Rank, MRR | Метрика качества поиска по образцам | UIClip 0,3851 против 0,2534 у базового CLIP |
| Каппа Фляйсса | Fleiss' Kappa | Согласие нескольких оценщиков | 0,29–0,31 у экспертов-дизайнеров на критиках |
| Лучший из N | best-of-n sampling | Сгенерировать N вариантов и выбрать лучший по метрике | UIClip ранжирует 5 вариантов HTML |
| Самокритика | self-revision | Просьба к модели исправить собственный вывод без внешнего измерителя | вредит слабым моделям: 39,7 → 30,1 |
| Обогащение текстом | text-augmented prompting | Подача распознанного текста списком вместе со скриншотом | block-match с 0,25 до 0,84 в примере |

## 3. Оценка и критика

| RU | EN | Определение | Пример |
|---|---|---|---|
| Визуально-языковая модель | vision-language model, VLM; multimodal LLM, MLLM | Модель, принимающая изображение и текст | GPT-5, Gemini 3, Qwen3-VL |
| Модель как судья | LLM-as-a-judge, VLM-as-a-judge | Использование модели для оценки чужого результата по рубрике | Пирсон 0,9892 с экспертами на рубрике GEBench |
| Рубрика | rubric | Набор измерений со шкалой и описанными якорями | 10 измерений (папка 13), 12 индикаторов AesEval, 5 измерений GEBench |
| Индикатор | indicator | Конкретный проверяемый аспект внутри измерения | balance, layering, whitespace, alignment |
| Якорь шкалы | anchor | Словесное описание того, что означает каждый балл | «3 — иерархия читается, но два уровня спорят» |
| Визуальный промт | visual prompting | Разметка поверх скриншота, помогающая модели отвечать о местоположении | пронумерованные патчи, координатные подписи по краям |
| Локализация замечания | grounding of a critique | Привязка замечания к области экрана | второй вызов, номера патчей |
| Жёсткое ограничение | hard constraint | Правило вида «делай / не делай» с числом | 228 в KB-Comp DesignRepair, recall починки 92,3 % |
| Мягкое ограничение | soft constraint | Рекомендация без порога | 399 в KB-Comp, recall починки 70,4 % |
| Валидная критика | valid critique | Замечание одновременно точное и полезное | 13,1 % у Gemini zero-shot |
| Профиль вместо балла | profile, not a score | Результат оценки как вектор по измерениям, а не одно число | см. `../13-evaluation-checklists/02` §2.2 |

## 4. Дефолтный вид и его маркеры

| RU | EN | Определение | Пример |
|---|---|---|---|
| Центроид обучающих данных | training centroid | Среднее по корпусу, к которому модель возвращается без различающего сигнала | Inter + zinc + фиолетовый + `rounded-2xl` + тень |
| Регрессия к среднему | regression to the mean | Механизм: наиболее вероятное продолжение и есть среднее | «Variance is penalized; the mean is rewarded» |
| Нейрослоп | AI slop | Сгенерированный результат, узнаваемый по набору дефолтных приёмов | 34 маркера в `../11-styles-trends/04` |
| Шлак | shit, crud | Избыточное или ненужное; захламлённое, неуклюже сложное; намеренно вводящее в заблуждение | определение Брэда Фроста, 2013 |
| Маркер генерации | generation marker, tell | Признак, по которому интерфейс опознаётся как сгенерированный | тень у карточек 84,9 %, эмодзи вместо иконок |
| Набор SaaS-карточек | SaaS-card kit | Контент, нарезанный на одинаковые скруглённые карточки с одной тенью | кластер 4 в списке Anthropic |
| Шаблонная обвязка | template chrome | Приёмы, появляющиеся независимо от темы: ALL-CAPS eyebrow, `A · B · C`, стрелка `→` | кластер 5 в списке Anthropic |
| Дефолты библиотеки | library defaults | Значения, которые применяются, если слой темы не переопределён | принцип shadcn «Beautiful Defaults» |
| Эффект расползания | ripple effect | Правка одного элемента меняет остальной интерфейс | описали 5 из 14 участников CHI '26 |
| Визуальный оптимизм | visual over-optimism | Высокое визуальное качество при нелогичном или галлюцинированном содержимом | парадокс GEBench |
| Галлюцинированный виджет | hallucinated widget | Элемент интерфейса, которого не может быть или который ничего не делает | «карточки-пустышки» |
