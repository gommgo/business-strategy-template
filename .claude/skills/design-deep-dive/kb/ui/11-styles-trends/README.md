# 11. Визуальные стили, тренды, антислоп

Волна 3, агент G, 22 сентября 2026. Прочитано целиком: 30 внешних источников (NN/g, Google Design, Apple,
первоисточники стилей, исходники shadcn и Material, каталоги практиков) плюс 7 видеодайджестов агента V и
измерения 24 живых продуктов агента P. Все контрасты и конверсии посчитаны `../../scripts/lib/color.py`.
Сырые заметки: `../99-raw/notes/wave3/G-notes.md`. Отчёт: `../99-raw/reports/wave3-G-report.md`.

## Выжимка папки

1. **Стиль = семь ручек** (акцент, нейтраль, радиус, плотность, шрифт, тени, тема), а не палитра. Карточка
   стиля выставляет все семь и разворачивается в 289 токенов через резолвер из папки 09.
2. **Из 18 стилей для рабочего веб-сервиса безусловно годятся шесть:** корпоративная классика,
   shadcn-дефолт, Stripe-стиль, плотный тёмный инструмент, швейцарский, flat 2.0. Остальные — экранные или
   не для сервисов вовсе.
3. **Плоский дизайн без сигнификаторов измерен: +22 % времени и +25 % фиксаций** (айтрекинг, 71 участник);
   палитра Flat UI 2013 физически не проходит контраст (белый на `#1abc9c` = 2.41:1).
4. **M3 Expressive — единственный стиль с количественной базой:** 46 исследований, 18 000+ участников,
   ключевые элементы замечают до 4 раз быстрее, но авторы сами пишут, что для банковского интерфейса это
   не подходит и что «strong minority preferred calmer versions».
5. **Устарелость измерима:** доля отступов, кратных 4 (медиана практики 72 %), тип тени (диагональ
   непрозрачным серым = 2006), контраст границ, доля целей меньше 24 px (медиана 14.1 %).
6. **«Дорого» тоже измеримо:** 3–5 радиусов, 0–3 тени, 4–7 кеглей, 2 веса, ≤ 2 хроматических цвета, одна
   модель глубины, нейтраль тонирована на 0.004–0.019, разница яркости фон/контейнер ≤ 7 % (светлая) и
   ≤ 12 % (тёмная).
7. **Выделяться нужно 1–2 фирменными приёмами при полном соблюдении конвенций.** Каталог из 12 приёмов с
   примерами живых продуктов — в файле 03 §5.2.
8. **Тёмная тема по умолчанию — у инструментов разработчика; светлая — в B2B, финансах, медицине.**
   Переключатель обязателен всегда; дефолт по системе, если нет отраслевой причины.
9. **34 маркера «нейрослопа» с проверками**, из них 22 проверяются скриптом по computed styles. Диагноз
   ставится по кластеру: 4 и больше маркеров одновременно.
10. **Маркеры датированы.** 2023–2024 — фиолетовый градиент; 2025–2026 — кремовый `#F4F1EA` с терракотой
    `#D97757` и серифом. Список надо пересматривать раз в полгода.

## С чего начать

- Нужно **выбрать стиль под продукт** → `01-…` §20 (квиз) → §19.2 (таблица пригодности) → карточка стиля.
- Нужно **развернуть стиль в токены** → `01-…` §0.2 (набор значений) → `02-…` §3 (семь ручек) →
  `../09-design-tokens/04-reference-token-schema.md`.
- Нужно **собрать бриф для генератора картинок** → `02-…` §5.
- Нужно **понять, почему макет выглядит старым** → `03-…` §1 (три поколения) → §2 (каталог приёмов с эпохами).
- Нужно **сделать «дорого»** → `03-…` §4.11 (чек-лист одним списком).
- Нужно **отличаться** → `03-…` §5.2 (12 приёмов) и `02-…` §3.5.
- Нужно **проверить сгенерированный интерфейс** → `04-…` §3 (скрипт) → §2 (маркеры) → §6 (порядок правок).

## Чем проверено

Ни один контраст в этих файлах не взят из вторичного источника: все посчитаны `../../scripts/lib/color.py`
(WCAG 2 и APCA 0.1.9, конверсии OKLCH, композитинг альфы). Значения стилей, где возможно, сверены с
измерениями 24 живых продуктов (агент P) и с исходниками систем (`material-web` для baseline M3,
документация shadcn/ui для дефолтной темы). Расхождения с распространёнными описаниями зафиксированы явно:
дефолт shadcn — не zinc и не радиус 6–8, а нулевая хрома и радиус 10 px.
