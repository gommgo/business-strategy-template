25 профилей: чем система отличается, какие у неё значения, что в ней уникального, чем она удобна и

## 1. Material 3 (Google)

**Паспорт.** `material-components/material-web`, выгрузка токенов v0.192; Apache 2.0; ref → sys → comp;
крупные скруглённые поверхности, тональные контейнеры, выраженное движение.

Файлы токенов помечены `!!! THIS FILE WAS AUTOMATICALLY GENERATED !!!` с шапкой, где записаны три оси
контекста выгрузки: `User-configured context group "Audience": "3P"`, `"Platform": "Web"`,
`"Scheme": "Dynamic"`. То есть параметризация начинается ещё до тем.

- **Форма** (`md-sys-shape`): corner-none 0, extra-small 4, small 8, medium 12, large 16, extra-large 28,
  full 9999. Плюс частичные: `corner-extra-large-top` (28 28 0 0), `corner-large-top/start/end`,
  `corner-extra-small-top`.
- **Состояния** (`md-sys-state`): hover-state-layer-opacity **0.08**, focus 0.12, pressed 0.12,
  dragged **0.16**.
- **Высота** (`md-sys-elevation`): level0 0, level1 1, level2 3, level3 6, level4 8, level5 12 dp.
- **Цвет** (`md-sys-color`): **49 ролей**, включая пять уровней поверхности `surface-container-lowest`,
  `-low`, `surface-container`, `-high`, `-highest`, плюс `surface-dim` и `surface-bright`. Пары
  `on-<роль>` у каждой заливки; расстояние между фоном и его `on-`-контентом 50–60 тонов.
- **Движение**: 16 длительностей (short1–4 50/100/150/200, medium1–4 250–400, long1–4 450–600,
  extra-long1–4 700–1000) и 10 кривых.

**Уникальное.** Цвет считается в HCT из seed-цвета — динамическая схема. Тип `motion_path` в генераторе
токенов не поддержан и выдаёт `null`: составная траектория `emphasized` — это две кривые Безье подряд,
в один `cubic-bezier()` не переводится.

**Устарело.** Система длительностей и кривых объявлена неподдерживаемой: «components and motion now use
the motion physics system, which uses springs… the easing and duration system… is **no longer
maintained**». Для веба дана официальная таблица конвертации пружин в `cubic-bezier`; все
пространственные кривые имеют y₁ > 1 (до 1.67), то есть перелёт зашит в кривую. Подробности —
`../08-motion/` и `99-raw/notes/wave2/M-notes.md` S24.

**Для конвейера.** Плюсы: самая полная модель ролей цвета; готовая механика «фон → on-фон»; есть
Web Components. Минусы: радиусы и отступы рассчитаны на мобильный тач-интерфейс (corner-extra-large 28,
цель 48 dp) и в плотной админке выглядят избыточно; шкала отступов токенами не выражена; движение надо
переводить на пружины, а перелёт противопоказан рабочим интерфейсам.

## 2. Apple HIG

**Паспорт.** Актуальная редакция 2026 (Liquid Glass); проприетарная документация; материал-стекло,
системные шрифты, минимум хрома.

Раздел Layout через JSON-API документации отдаёт **только принципы**, без числовых значений: порядок
контента по важности, выравнивание и отступы как выражение иерархии, группировка через негативное
пространство и разделители, прогрессивное раскрытие, отделение контролов от контента материалом Liquid
Glass вместо сплошной подложки, продление фонового контента под сайдбары и панели.

**Для конвейера.** Плюсы: формулировки принципов точнее, чем у большинства систем. Минусы: числовых
значений для веба нет; величины даются в `pt` и привязаны к нативным контролам; лицензия не позволяет
переиспользовать ассеты (в частности, SF Symbols запрещено использовать в логотипах). В атласе строка
намеренно почти пустая.

## 3. Microsoft Fluent 2

**Паспорт.** `microsoft/fluentui`, `packages/tokens/src`; MIT; два уровня прямо в структуре папок
(`global/` и `alias/`); плотный корпоративный интерфейс.

- **Радиусы**: none 0, small 2, medium 4, large 6, xlarge 8, 2xlarge 12, 3xlarge 16, 4xlarge 24,
  5xlarge 32, 6xlarge 40, circular 10000 — 11 шагов.
- **Отступы**: none 0, xxs 2, xs 4, **sNudge 6**, s 8, **mNudge 10**, m 12, l 16, xl 20, xxl 24,
  xxxl 32. Экспортируются **раздельно по осям**: `spacingHorizontalM` и `spacingVerticalM`, 11 × 2 = 22
  токена.
- **Толщины линий**: thin 1, thick 2, thicker 3, thickest 4.
- **Длительности**: ultraFast 50, faster 100, fast 150, normal 200, gentle 250, slow 300, slower 400,
  ultraSlow 500 — 8 шагов, больше всех в выборке.
- **Кривые**: 9, разложенных по осям «ускорение / замедление» × «max / mid / min», плюс `easyEase`
  `(0.33, 0, 0.67, 1)` и `linear`.
- **Темы**: `lightColor` 14.5 КБ, `darkColor` 14.5, **`highContrastColor` 15.9**, `teamsDarkColor` 14.5.

**Уникальное.** Полушаги «nudge» между основными шагами отступов — признание того, что 8 и 12 иногда
слишком далеко друг от друга. Разведение отступов по осям — признание того, что вертикальный и
горизонтальный ритм разные. Высокий контраст — отдельный полный набор, а не модификатор.

**Для конвейера.** Плюсы: самая подробная сетка кривых; готовый высококонтрастный набор; мелкие радиусы
и плотные отступы подходят админкам. Минусы: 22 токена отступов вместо 11 удваивают словарь; формат — TS,
не DTCG; радиусов 11 при реальной потребности в 5.

## 4. Shopify Polaris

**Паспорт.** `Shopify/polaris`, `polaris-tokens/src`; MIT; один общий ряд `size` на всё; серый холст,

- **Единый ряд `size`**: 0, 0.66, 1, 2, 4, 6, 8, 11, 12, 13, 14, 16, 18, 20, 22, 24, 28, 30, 32, 36, 40,
  48, 64, 80, 96, 112, 128 px. Имена — **сотые доли от 4px**: `100` = 4px, `400` = 16px, `1000` = 40px,
  `3200` = 128px.
- **Отступы**: 18 шагов из этого ряда плюс **4 алиаса-назначения**: `space-button-group-gap` =
  `space-200` (8px), `space-card-gap` = `space-400` (16px), `space-card-padding` = `space-400` (16px),
  `space-table-cell-padding` = `space-150` (6px).
- **Радиусы**: 0, 050 (2), 100 (4), 150 (6), 200 (8), 300 (12), 400 (16), 500 (20), 750 (30),
  `full` 9999.
- **Толщины границ**: 0, 0165 (0.66), 025 (1), 050 (2), 100 (4).
- **Брейкпоинты**: xs 0, **sm 490**, md 768, lg 1040, xl 1440.
- **Движение**: 12 длительностей (0…500 плюс 5000), 5 функций, **6 keyframes как токены** (bounce,
  fade-in, pulse, spin, appear-above, appear-below).
- **Шрифт**: Inter; 13 кеглей (275 = 11px … 1000 = 40px), 8 интерлиньяжей, 4 трекинга (`densest`,
  `denser`, `dense`, `normal`), 4 веса.
- **Поверхности**: фон страницы **серый** gray 6 `#f1f1f1`, карточка белая. Граница
  `color-input-border` `#8a8a8a` даёт 3.06:1 к белому — одно из двух соблюдений WCAG 1.4.11 в выборке.

**Уникальное.** Алиасы-назначения: решение «padding карточки 16, padding ячейки таблицы 6» зафиксировано
прямо в токенах. Анимации как токены. Брейкпоинт 490 вместо привычного 480 или 576.

**Для конвейера.** Плюсы: единый ряд размеров убирает вопрос «это отступ или размер»; назначения
экономят решения; контраст границ соблюдён. Минусы: формат TS; брейкпоинты нестандартные; тёмная тема в
этой работе не проверена.

## 5. IBM Carbon

**Паспорт.** `carbon-design-system/carbon`; Apache 2.0; DTCG-выгрузка с `$schema`; прямые углы,
IBM Plex, слои вместо теней.

- **Отступы** (`miniUnits`): 01 = 2px, 02 = 4, 03 = 8, 04 = 12, 05 = 16, 06 = 24, 07 = 32, 08 = 40,
  09 = 48, 10 = 64, 11 = 80, 12 = 96, 13 = 160 — 13 шагов. Плюс `fluid-spacing` 0 / 2vw / 5vw / 10vw.
- **Высоты контролов** (`container`): 01 = 24, 02 = 32, 03 = 40, 04 = 48, 05 = 64.
- **Размеры** (`size`): xs 24, sm 32, **md 40 («Default component size»)**, lg 48, xl 64, 2xl 80.
- **Иконки**: 16, 20.
- **Радиусы**: 0, 2, 4 («Default rounding for inputs, cards»), 8, 16, 24, `max` 999999.
- **Темы**: white, g10 («subtle contrast for data-dense interfaces»), g90, g100 — четыре внутри одного
  файла, значение на тему в `$extensions["carbon.themes"]`. Alpha состояний **0.12 в светлых, 0.16 в
  тёмных**.
- **Слои**: `layer.01/02/03`, `layer.accent.*`, плюс **контекстные токены без номера** (`$layer`,
  `$field`, `$border-subtle`), значение которых подставляет компонент-обёртка `<Layer>` по глубине
  вложенности.
- **Депрекация**: вся группа `layout` (01 = 16px … 07 = 160px) помечена «Replaced by spacing scale. Do
  not use in new work».

**Уникальное.** Единственная система в выборке, чьи токены выпущены в DTCG с валидацией
(`ajv validate -s https://tr.designtokens.org/format/schema.json`). У **каждого** токена обязательный
`$description` с правилом применения. README содержит разделы «Tip for agents», включая предупреждение
«Do not grep for the full hyphenated name — it will not match». Маршрутизация по группам, а не по
префиксам имён: «The group name is the authoritative category… no name-prefix inference, no hidden
ordering rules».

**Расхождение со спекой.** `dimension` записан голым числом (`"$value": 2`) плюс расширение
`carbon.layout.converter`, тогда как спека 2025.10 требует объект `{value, unit}`.

**Для конвейера.** Плюсы: формат DTCG; описания применения у каждого токена; модель слоёв для плотных
интерфейсов; прямые углы и высокая плотность подходят таблицам. Минусы: контекстные токены требуют
React; `dimension` не по спеке; радиус 0 и строгий вид годятся не всем продуктам.

**Практика** (`05-live-products-profiles.md` A3): DataTable в Storybook — база 14 px, всего 2 кегля,
радиус 0, теней 0, кратность 4 — 94.7 %, высота строки 48, кегль ячейки 14, цели нажатия < 24 px — 0 %.

## 6. GitHub Primer

**Паспорт.** `primer/primitives`, JSON5; MIT; base → functional; компактный контентный интерфейс.

- **Отступы**: xxs 2, xs 4, sm 8, md 12, lg 16, xl 24 — шесть шагов, самая короткая шкала в выборке.
- **Радиусы**: small 3, medium 6 (= `default`), large 12, full 9999.
- **Толщины границ**: thin 1, thick 2, thicker 4. Плюс приём `boxShadow.thin/thick/thicker` =
  `inset 0 0 0 {borderWidth.*}` с описанием «used instead of a border to prevent layout shift»
  (нестандартный тип `custom-string`).
- **Режимы**: light, dark, dark-dimmed × (обычный, high-contrast, tritanopia-high-contrast,
  protanopia-deuteranopia-high-contrast) — значения лежат в `org.primer.overrides` внутри токена.
- **Контраст**: `borderColor.default` `#D1D9E0` — 1.43:1, `borderColor.emphasis` `#818B98` — **3.45:1**
  (одно из двух соблюдений WCAG 1.4.11 в выборке).

**Уникальное — `$extensions.org.primer.llm`.** Правила применения токена для языковой модели прямо в
токене: поля `usage` (метки в kebab-case), `rules` (одно-два предложения с модальностью `MUST use` /
`RECOMMENDED default` / `Use for` / `Do NOT use for`), `doNotUse`, `alternatives`. 126 блоков в выборке,
**только на функциональных токенах, ни одного на примитивах**. Формат разобран в
`../09-design-tokens/04-reference-token-schema.md` §3 и принят за образец эталонной схемы.

Рядом два других расширения: `org.primer.figma` со `scopes` (где переменная предлагается) и
`codeSyntax.web` (готовая строка для вставки в код), и `org.primer.overrides` с режимами.

**Для конвейера.** Плюсы: лучший в выборке способ передать правила применения модели; `dimension` по
спеке; контраст границ соблюдён; компактные отступы. Минусы: JSON5 (не все парсеры); шкала отступов из
шести шагов тесновата для крупных макетов; теней почти нет, глубина передаётся границей.

**Практика** (`05-live-products-profiles.md` B1, C1, C2): каталог компонентов — база **16 px** (редкость),
кратность 4 — 97.6 %, кратность 8 — 96.2 %, цели < 24 px — 0 %. Живой GitHub — база 12–14, радиус 6,
высота кнопки 32–40, сайдбар 256, шапка 72, кольцо фокуса `outline: 2px solid #0969da; offset -2px`.

## 7. Atlassian Design System

**Паспорт.** `@atlaskit/tokens@18.2.1`; Apache 2.0; девять групп токенов; мягкие тени, богатая палитра
графиков.

**596 токенов**: color 442, motion 72, space 23, font 23, elevation 21, radius 8, border 3, opacity 2,
utility 2. Внутри цвета: `color.background` 208, **`color.chart` 100**, `color.text` 49,
`color.border` 40, `color.icon` 23, `color.rovo` 11 (ИИ-функции), `color.link` 4, `color.blanket` 3,
`color.skeleton` 2, `color.interaction` 2.

- **Отступы**: 0, 025 = 2, 050 = 4, 075 = 6, 100 = 8, 150 = 12, 200 = 16, 250 = 20, 300 = 24, 400 = 32,
  500 = 40, 600 = 48, 800 = 64, 1000 = 80. Плюс **9 отрицательных** от −2 до −32.
- **Радиусы**: xsmall 2, small 4, medium 6, large 8, xlarge 12, xxlarge 16, full 624.9375rem, плюс
  **`radius.tile` = 25 %**.
- **Границы**: 1, `selected` 2, `focused` 2. **Прозрачность**: `disabled` 0.4, `loading` 0.2.
- **Тени**: `raised` `0px 1px 1px #1E1F2140, 0px 0px 1px #1E1F214F`; `overlay`
  `0px 8px 12px #1E1F2126, 0px 0px 1px #1E1F214F`; `overflow` `0px 0px 8px #1E1F2129, 0px 0px 1px
  #1E1F211F`. Каждая — две тени, вторая `0 0 1px` работает как кольцо.
- **Движение**: длительности 0, 50, 100, 150, 200, 250, 400, 600; кривые `out.practical`
  `(0.4, 1, 0.6, 1)`, `in.practical` `(0.6, 0, 0.8, 0.6)`, `inout.bold` `(0.4, 0, 0, 1)`, `out.bold`
  `(0, 0.4, 0, 1)`; **`easing.spring` = `linear(0, 0.021, 0.058, …, 1)` из 65 точек**.
- **Композитные анимации как токены**: `motion.avatar.enter` = `150ms cubic-bezier(0.4,1,0.6,1)
  ScaleIn80to100 backwards, 150ms … FadeIn0to100 backwards`; плюс 18 токенов `motion.keyframe.*`
  (`scale.in.small` 95 → 100 %, `fade` 0 → 100 %).
- **Типографика записана CSS-shorthand одной строкой**: `font.body` = `normal 400 0.875rem/1.25rem …`;
  заголовки xxsmall 12/16 … xxlarge 32/36. Веса 400, 500, 600, **653** (нестандартное значение
  переменной оси `wght`). Отдельная группа `font.metric.{small,medium,large}` — **кегли для чисел на
  дашборде** (16/20, 24/28, 28/32).
- **Темы файлами**: `atlassian-light`, `atlassian-dark`, `atlassian-light/dark-increased-contrast`,
  `atlassian-legacy-light/dark`, `atlassian-light/dark-brand-refresh`. Цвета считаются в **HCT**.

**Уникальное.** Отрицательные отступы как легальные токены. Пружина, выраженная CSS-функцией `linear()`.
Композитные анимации целиком в токене. Отдельные кегли для чисел на дашборде. Правило асимметрии выхода
сформулировано численно: «reduce the duration by 50 ms or 100 ms compared to the entrance»;
`motion.duration.instant` = 0 ms означает, что **фокус не анимируется**.

**Для конвейера.** Плюсы: самая богатая палитра графиков; готовые токены движения на компонент; три оси
тем в именах файлов. Минусы: 596 токенов на один продукт избыточны; типографика shorthand-строкой плохо
разбирается; формат — JS-артефакты.

## 8. Ant Design 5

**Паспорт.** 5.x; MIT; seed → map → alias, где **map вычисляется формулами**; плотная форма, много
готовых компонентов.

**Seed (12 значений):** `colorPrimary #1677ff`, `colorSuccess #52c41a`, `colorWarning #faad14`,
`colorError #ff4d4f`, `colorInfo #1677ff`; `fontSize: 14`; `lineWidth: 1`; `borderRadius: 6`;
`sizeUnit: 4`, `sizeStep: 4`, `sizePopupArrow: 16`; **`controlHeight: 32`**; `zIndexBase: 0`,
`zIndexPopupBase: 1000`; `motionUnit: 0.1`, `motionBase: 0`; `wireframe: false`; `focusOutline: true`.

**Формулы map:**

```
fontSize_i      = base × e^((i−1)/5), округление до чётного  → 12 14 16 20 24 30 38 46 56 68
lineHeight      = (fontSize + 8) / fontSize                  → 1.667 1.571 1.5 1.4 1.333 1.267 …
абсолютный lh   = 20 22 24 28 32 38 46 54 64 76 px
sizeXXL         = sizeUnit × (sizeStep + 8) = 48; XL 32, LG 24, MD 20, MS 16, SM 12, XS 8, XXS 4
controlHeight   SM = ×0.75 = 24;  XS = ×0.5 = 16;  LG = ×1.25 = 40
motionDuration  Fast = motionBase + motionUnit = 0.1s;  Mid 0.2s;  Slow 0.3s
lineWidthBold   = lineWidth + 1 = 2
```

**Радиусы — кусочно-линейная функция** `genRadius(borderRadius)`, а не умножение. При базе 6:
`borderRadiusXS` 2, `SM` 4, `borderRadius` 6, `LG` 8, `Outer` 4. Правила: `LG = base + 1` при
base ∈ [5, 6), `base + 2` при [6, 16), 16 при ≥ 16; `SM` = 4 при [5, 7), 5 при [7, 8), 6 при [8, 14),
7 при [14, 16), 8 при ≥ 16; `XS` = 1 при [2, 6), 2 при ≥ 6.

**Кривые (8 в seed):** `motionEaseOutCirc (0.08, 0.82, 0.17, 1)`, `motionEaseInOutCirc
(0.78, 0.14, 0.15, 0.86)`, `motionEaseOut (0.215, 0.61, 0.355, 1)`, `motionEaseInOut
(0.645, 0.045, 0.355, 1)`, `motionEaseOutBack (0.12, 0.4, 0.29, 1.46)`, `motionEaseInBack
(0.71, −0.46, 0.88, 0.6)`, `motionEaseInQuint`, `motionEaseOutQuint`.

**14 пресетных цветов:** blue #1677FF, purple #722ED1, cyan #13C2C2, green #52C41A, magenta #EB2F96,
red #F5222D, orange #FA8C16, yellow #FADB14, volcano #FA541C, geekblue #2F54EB, gold #FAAD14,
lime #A0D911; `pink` помечен устаревшим в пользу magenta.

**Уникальное.** Единственная система, где средний уровень токенов порождается кодом: тема задаётся 12
числами. Сознательное **нелинейное сжатие шкалы радиусов**, чтобы мелкие элементы не выглядели
переокруглёнными.

**Для конвейера.** Плюсы: тема из 12 чисел — идеальный размер «ручек характера»; плотная форма подходит
админкам; полнота компонентов. Минусы: значения нельзя подправить точечно, не сломав формулу; их нельзя
прочитать глазами — надо выполнить код; формат TS.

**Практика** (A2): Ant Design Pro — база 14, радиус 6, высота кнопки 32, поле 22, сайдбар 256, шапка 56,
кратность 4 — 85.0 %, иконка 14 × 14, `transition` 0.3 s, фокус `outline: 3px solid #91d5ff; offset 1px`.

## 10. Radix Themes

**Паспорт.** 3.x; MIT; тем как файлов нет — есть семь ручек `<Theme>`; настраиваемый характер поверх
готовой механики.

Параметры: `accentColor`, `grayColor`, `panelBackground` (`solid` / `translucent`), `scaling`, `radius`,
`appearance` (light / dark).

- **`--scaling`**: 0.9 / 0.95 / 1 / 1.05 / 1.1 — множитель **всех** размеров.
- **Отступы**: `--space-1…9` = `calc(4px × var(--scaling))`, 8, 12, 16, 24, 32, 40, 48, 64.
- **Радиусы**: `--radius-1…6` = `calc(3px × scaling × radius-factor)`, 4, 6, 8, 12, 16.
  `--radius-factor`: none 0, small 0.75, medium 1, large 1.5, full 1.5. Плюс `--radius-full` (0 или
  9999) и `--radius-thumb` (0.5px или 9999) — **два независимых механизма**: коэффициент для
  прямоугольных и флаг «пилюля» для круглых.
- **Типографика**: `--font-size-1…9` = 12, 14, 16, 18, 20, 24, 28, 35, 60 (× scaling);
  `--line-height-1…9` = 16, 20, 24, 26, 28, 30, 36, 40, 60 px — **абсолютный интерлиньяж**; трекинг
  **непрерывный**: +0.0025em на шаге 1, 0 на 2–3, затем −0.0025, −0.005, −0.00625, −0.0075, −0.01,
  −0.025em. Веса 300, 400, 500, 700 — **без 600**. `--default-font-size` = 16, `--default-line-height`
  = 1.5, плюс `--default-leading-trim-start` 0.42em и `-end` 0.36em.
- **Тени**: `--shadow-1…6`, **каждая начинается с кольца `0 0 0 1px var(--gray-a3)`** (для shadow-1 —
  inset), уровни 2–6 из 4–5 слоёв. При поддержке `color-mix(in oklab, …)` кольцо пересчитывается. В
  тёмной теме кольцо усиливается до `gray-a6`, тени переводятся на `black-a*`.
- **Цвет**: 30+ акцентных шкал по 12 шагов плюс альфа-версии; акцент и нейтраль независимы. Смысл
  ступени фиксирован: 6 — граница неинтерактивного, 7 — интерактивного, 8 — усиленная и кольцо фокуса,
  9 — сплошная заливка, 11 — текст, 12 — основной текст.
- **Движения токенов нет вообще.**

**Уникальное.** Характер как семь значений. Два механизма радиуса. Кольцо в каждой тени. Фиксированная
семантика ступени шкалы вместо запаса на вставку.

**Для конвейера.** Плюсы: самая близкая к конвейеру модель параметризации; шкалы со смыслом ступени
снимают вопрос «какой шаг взять». Минусы: умножение на `--scaling` даёт дробные px (4 × 0.95 = 3.8);
абсолютный интерлиньяж не переносится в составные токены DTCG; токенов движения нет.

**Практика** (A6): playground — 18 кеглей, 17 радиусов и **25 теней** на одном экране (это витрина, а не
продукт); кратность 4 — 87.3 %; высота кнопки 40, поле 30; цели < 24 px — 19.6 %.

## 25. Open Props и Panda CSS (инструменты, не системы)

**Open Props** — набор готовых CSS-переменных-примитивов без компонентов и без семантики. Группы: sizes,
colors, gradients, shadows, easings, animations, borders, typography, aspect ratios, z-index, masks.
Подключается одним CSS-файлом. Ценен как пример «токены без системы»: даёт примитивный слой, не
навязывая ролей. Для конвейера — источник примитивов, если не хочется тащить Tailwind.

**Panda CSS** — движок токенов и CSS-in-JS. Разделяет `tokens` и **`semanticTokens`** прямо в API.
Категории: `aspectRatios, borders, colors, durations, easings, fonts, fontSizes, fontWeights,
letterSpacings, lineHeights, radii, shadows, sizes, spacing, zIndex, gradients, assets, animations,
blurs, opacity`. Режим записан **внутрь значения**:

```js
semanticTokens: { colors: {
  danger:  { value: { base: '{colors.red}',   _dark: '{colors.darkred}' } },
  primary: { DEFAULT: { value: '{colors.gray.100}' }, muted: { value: '{colors.gray.100}' } } } }
```

`DEFAULT` даёт токену и собственное значение, и группу — тот же приём «двойного узла», что у Carbon.
Формат значения `{ value: … }` общий с Chakra v3. Для конвейера — готовая модель двух уровней и режимов,
если проект не на Tailwind.
