## Цветовые модели и координаты

**Оттенок** (hue) — положение цвета на цветовом круге, 0–360°. В OKLCH: красный ≈ 20°, жёлтый ≈ 90°,
зелёный ≈ 140°, синий ≈ 220°, фиолетовый ≈ 320°. → `01-…` §1.1

**Насыщенность** (saturation) — доля пигмента относительно максимума ДАННОЙ модели, 0–100 %. Есть в HSL и HSB;
у разных оттенков одинаковый диапазон, хотя реальные максимумы различаются. Пример: `hsl(210 60% 64%)`.

**Хрома** (chroma) — абсолютная «цветность» без верхнего предела. OKLCH: 0 … ~0.37; LCH: 0 … 130+;
HCT (Material): 0 … 120+. Пример: `oklch(0.62 0.214 260)` — C = 0.214.

**Светлота** (lightness) — воспринимаемая яркость. В HSL математическая и неточная, в LCH/OKLCH перцептивная.
Пример: OKLCH L 0.54 у #0969da.

**Яркость** (brightness, value) — координата модели HSB/HSV, 0–100 %. Не равна воспринимаемой светлоте.

**Относительная яркость** (relative luminance) — физическая мера света 0–1 по формуле WCAG:
`0.2126·R + 0.7152·G + 0.0722·B` в линейном sRGB. → `03-…` §1.1

**OKLCH** — цилиндрическая запись пространства Oklab: `oklch(L C H / a)`. Создано Björn Ottosson в 2020.
Пример: `oklch(0.683 0.169 258)`. → `01-…` §1.3

**Oklab** — декартова запись того же пространства: `oklab(L a b)`, где `a` — зелёный↔красный, `b` — синий↔жёлтый.
Используется для градиентов: `linear-gradient(in oklab, …)`.

**CIELAB (Lab)** — перцептивно равномерное пространство CIE 1976. L* 0–100. Пример лестницы: 98, 93.3, 88.6, 79.9,
71.2, 60.5, 49.8, 38.4, 27, 15.6 (Postmark).

**LCH (CIELCh, Lch(ab))** — цилиндрическая запись CIELAB. Имеет баг: сдвиг синего в фиолетовый при смене хромы в
диапазоне H 270–330°. → `01-…` §1.3

**HCT** — пространство Material 3 (Hue, Chroma, Tone) на базе CAM16 и L* из CIELAB. Chroma в HCT не равна chroma
в OKLCH: Material задаёт нейтраль chroma 4–6 HCT. → `01-…` §3.3

**Гамут** (gamut) — множество цветов, воспроизводимых устройством. sRGB покрывает ~35 % видимых человеку цветов,
P3 добавляет ещё ~30 %. → `01-…` §1.4

**Отображение в гамут** (gamut mapping) — приведение цвета в доступный диапазон. Два способа: клиппинг каналов
(быстро, меняет оттенок) и снижение хромы в OKLCH (правильно). Спека CSS Color 4 требует второй.

**Максимальная хрома** (max chroma) — наибольшая C, при которой пара (L, H) остаётся в гамуте. Находится бинарным
поиском. Пример: при L 0.30 и H 90° (тёмно-жёлтый) она почти нулевая. → `01-…` §1.4

## Шкалы

**Шкала** (scale, ramp) — упорядоченный набор оттенков одного цвета. Tailwind 11 шагов (50–950), Radix 12 (1–12),
Geist 10, Polaris 16, Primer 14/10, Material 13 тонов. → `01-…` §2.1

**Шаг шкалы** (step, shade, tone) — одно значение в шкале. У Radix и Geist за шагом закреплена РОЛЬ, у Tailwind и
Polaris — положение на шкале светлоты.

**Тональная палитра** (tonal palette) — термин Material 3: 13 тонов одного (hue, chroma): 0, 10…90, 95, 98, 99,
100. Пример: `primary40` — тон 40 палитры primary. → `01-…` §3.3

**Ключевой цвет** (key color) — вход алгоритма Material: из него выводятся пять тональных палитр (primary,
secondary, tertiary, neutral, neutral-variant) плюс error.

**Тинт** (tint) — цвет, смешанный с белым. GOV.UK: `tint-25`, `tint-50`, `tint-80`, `tint-95`.
Пример: blue tint-80 = #d2e2f1.

**Шейд** (shade) — цвет, смешанный с чёрным. GOV.UK: `shade-25`, `shade-50`. Пример: blue shade-50 = #0f385c.

**Тон** (tone) — цвет, смешанный с серым; у Material — ступень тональной палитры.

**Лестница светлоты** (lightness ladder) — заданный набор L для всех шагов шкалы. У Tailwind разные лестницы для
хроматических и нейтральных семейств: на шаге 500 средняя L 68.3 % против 55.5 %. → `01-…` §2.3

**Кривая хромы** (chroma curve) — распределение C по шагам, колокол с пиком на 500–600. Tailwind: 0.018 на 50,
0.214 на 500, 0.088 на 950. → `01-…` §2.4

**Сдвиг оттенка** (hue shift) — изменение H по шкале. Tailwind amber: 95.3° на 50 → 45.6° на 950 (−50°).
Ant Design задаёт формулой ±2° на шаг. → `01-…` §2.5

**Компенсация оттенка** (hue compensation) — намеренный отрицательный сдвиг для жёлтых, чтобы тёмные шаги не
зеленели (термин Accessible Palette).

**Якорение** (anchoring) — привязка точного цвета бренда к шагу шкалы, чья светлота ближе всего к его светлоте.
→ `01-…` §3.3

**Чистый оттенок** (pure hue) — оттенок 0/60/120/180/240/300°, у которого минимум два RGB-канала равны.
Признак: `rgb(77, 232, 232)`. В интерфейсе выглядит ядовито; отступать 5–10°. → `01-…` §2.5

## Нейтрали

**Нейтраль, нейтральная шкала** (neutral scale, gray scale) — шкала серых, на которой строятся фоны, границы и
текст. «Almost everything in an interface is grey» (Refactoring UI).

**Чистый серый** (pure gray) — OKLCH C = 0. Tailwind `neutral`, Radix `gray`.

**Тонированная нейтраль** (tinted neutral) — серый с малой хромой в оттенок акцента. Рабочий диапазон
OKLCH C 0.005–0.05. Примеры: Radix `slate`/`mauve`/`sage`/`olive`/`sand`; Tailwind `slate`/`zinc`/`stone`/
`taupe`/`mist`/`mauve`/`olive`. → `01-…` §4.2

**Нейтраль-вариант** (neutral variant) — вторая, чуть более насыщенная нейтральная палитра Material
(HCT chroma 8 против 4–6 у основной); используется для границ (`outline`).

**Тёплая / холодная нейтраль** (warm / cool neutral) — нейтраль с оттенком H 40–110° (тёплая: stone, taupe, sand)
или H 200–330° (холодная: slate, gray, mist, zinc, mauve).

## Семантика и архитектура

**Примитив** (primitive, reference token, global token) — точка шкалы без смысла: `blue-600`, `neutral.9`,
`primary40`. Компоненты их НЕ используют. → `02-…` §1.1

**Семантический алиас** (semantic token, system token, alias) — роль в интерфейсе: `--color-accent-solid`,
`fgColor.muted`, `--md-sys-color-primary`.

**Компонентный токен** (component token) — значение одного компонента: `$button-primary-hover`,
`--color-input-border`.

**Контекстный токен** (contextual token) — термин Carbon: значение подставляется в зависимости от слоя, на
котором находится компонент. `$layer` без номера против `$layer-02`.

**Парный контентный цвет** (on-color, foreground token) — цвет текста и иконок на данной поверхности:
`--md-sys-color-on-primary`, `--primary-foreground`. Расстояние до фона у Material — 50–60 тонов. → `02-…` §1.2

**Поверхность** (surface) — фон элемента, лежащего над фоном страницы: карточка, панель, поповер. Material
различает 5 контейнеров: `surface-container-lowest/low/base/high/highest`.

**Слой** (layer) — термин Carbon: `background`, `layer-01`, `layer-02`, `layer-03`.

**Инлайн-тема** (inline theming) — кусок страницы в другой теме (шелл или боковая панель в тёмной при светлой
основной). Термин Carbon.

**Инверсная поверхность** (inverse surface) — тёмная плашка в светлой теме и наоборот: тултип, снекбар.
Material `inverse-surface`, Polaris `color-bg-inverse`.

**Статусный цвет** (semantic status color) — info, success, warning/caution, danger/critical, neutral.
ВНИМАНИЕ: `warning` у Polaris оранжевый, а у Primer оранжевый называется `severe`, жёлтый — `attention`.
→ `02-…` §4.1

**Субтильный стиль статуса** (muted, subtle, soft) — светлая плашка + тёмный текст того же оттенка + граница.
Primer: `bgColor.<role>.muted` = hue.0, текст = hue.5. Реальный контраст 7–11:1.

**Сплошной стиль статуса** (emphasis, solid, fill) — насыщенная заливка + контрастный текст.
Primer: `bgColor.<role>.emphasis` = hue.5.

**Magic** — роль Polaris для ИИ-функций (пурпурный). Аналог у Carbon — «AI tokens». → `02-…` §4.5

## Контраст

**Контрастное отношение WCAG** (contrast ratio) — `(L1 + 0.05) / (L2 + 0.05)`, диапазон 1:1 … 21:1.
Пороги AA: 4.5:1 текст, 3:1 крупный текст и нетекстовые элементы. AAA: 7:1 и 4.5:1. → `03-…` §1

**Крупный текст** (large text) — 18 pt (24 px) и больше, либо 14 pt (≈ 18.67 px) и больше при `font-weight` ≥ 700.

**APCA** (Accessible Perceptual Contrast Algorithm) — перцептивный метод Andrew Somers (Myndex), кандидат в
WCAG 3. Величина Lc от 0 до ±106. → `03-…` §2

**Lc** (lightness contrast) — значение APCA. Знак кодирует полярность: положительный — тёмный текст на светлом,
отрицательный — светлый на тёмном. Уровни: 90 / 75 / 60 / 45 / 30 / 15.

**Полярность контраста** (contrast polarity) — положительная (светлая тема, тёмный текст на светлом) или
отрицательная (тёмная тема). Термин из литературы по читаемости. → `04-…` §1

**Пространственная частота** (spatial frequency) — размер и толщина элемента. Чем выше (мельче и тоньше), тем
больше нужно контраста. По Somers, влияет сильнее, чем цвет. → `03-…` §2.3

**Критический контраст** (critical contrast) — минимальный контраст, при котором скорость чтения и понимание
перестают расти. Для fluent reading нужен контраст ≥ 10× порога различимости (JND), предпочтительно 20×.

**Запас остроты** (acuity reserve) — по Lovie-Kitchin: spot-чтение 1.3:1, fluent 2:1, максимальная скорость
3:1 … 8:1.

**Fluent / sub-fluent / spot readability** — категории ARC: беглое чтение (body и основной контент), мягкое
чтение (вторичное), точечное чтение (плейсхолдеры, disabled, копирайт). → `03-…` §2.2

**Галация** (halation) — ореол вокруг светлого текста на тёмном фоне при избыточной яркости. Лечится
затемнением самого светлого элемента, а не осветлением тёмного. → `04-…` §5.3

**Композитинг альфы** (alpha compositing) — вычисление фактического цвета полупрозрачного слоя над фоном:
`out = fg·α + bg·(1−α)`. Контраст меряется ПОСЛЕ него. → `03-…` §6.1

## Цветовая слепота

**CVD** (color vision deficiency) — сниженная способность различать оттенки, около 5 % населения.

**Протанопия / протаномалия** (protan) — проблема с L/красным конусом. Красный на чёрном для них почти не
контрастен: пара запрещена.

**Дейтеранопия / дейтераномалия** (deutan) — проблема с M/зелёным конусом. Самый частый тип.

**Тританопия** (tritan) — проблема с S/синим конусом, редко.

**Ахроматопсия** (achromatopsia) — отсутствие цветового зрения, очень редко; сопровождается низкой остротой и
светобоязнью.

**ΔE** (delta E, color difference) — мера различия цветов. Формулы: CIEDE2000, CMC, евклидово расстояние в
Oklab. Ориентир для различимости категорий: ΔE(OKLab) ≥ 0.05 в норме и во всех симуляциях CVD. → `02-…` §5.2

**Правило «не только цветом»** (WCAG 1.4.1 Use of Color, уровень A) — цвет не может быть единственным носителем
смысла.

**«Get it right in black & white»** — приём Datawrapper: перевести палитру в ч/б; если категории неразличимы,
значит различаются только оттенком.

## Состояния

**Слой состояния** (state layer) — полупрозрачный слой цвета `on-<container>` поверх контейнера.
Material v0.192: hover 0.08, focus 0.12, pressed 0.12, dragged 0.16. → `05-…` §1.2

**Hover / active (pressed) / selected / focus / disabled** — состояния. Active — момент нажатия, selected —
устойчивое состояние выбора; разводить их обязательно.

**Фокус-ринг** (focus ring, focus indicator) — визуальный индикатор клавиатурного фокуса. 2 px толщина, 2 px
offset, ≥ 3:1 к обоим соседним цветам. Реализуется через `outline`, а не `box-shadow`.

**Двойной ринг** (double ring) — обводка из двух контрастных линий (тёмная + светлая), работает на любом фоне;
так делают современные Chrome и Edge.

**Скрим** (scrim, backdrop) — затемнение под модалкой. 32–50 % чёрного в светлой теме, 60–75 % в тёмной.
Polaris: 71 %.

**Выделение** (selection) — `::selection`; если не задать, браузер возьмёт системный `Highlight`.

**Каретка** (caret) — курсор ввода; `caret-color`.

## Режимы

**`prefers-color-scheme`** — медиафича предпочтения светлой/тёмной темы.

**`color-scheme`** — CSS-свойство, объявляющее поддерживаемые схемы. `light dark` обязательно, иначе не работает
`light-dark()` и нативные контролы остаются светлыми.

**`light-dark()`** — CSS-функция, возвращающая первое значение при светлой схеме, второе при тёмной.
Baseline с мая 2024. Принимает и `<color>`, и `<image>`.

**Оверлей высоты** (elevation overlay) — приём Material 2: белый с альфой поверх тёмной поверхности,
0 % при 0 dp … 16 % при 24 dp. Заменяет тени в тёмной теме.

**`forced-colors`** — режим принудительных системных цветов (Windows High Contrast). Подменяет `color`,
`background-color`, `border-color`, `outline-color`, SVG `fill`/`stroke` и др.; принудительно убирает
`box-shadow`, `text-shadow` и не-url-овые `background-image`. → `04-…` §9.3

**`forced-color-adjust`** — свойство управления подменой: `auto` | `none` | `preserve-parent-color`.

**Системные цвета CSS** (system colors) — `Canvas`, `CanvasText`, `LinkText`, `ButtonFace`, `ButtonText`,
`ButtonBorder`, `Field`, `FieldText`, `Highlight`, `HighlightText`, `GrayText`, `AccentColor` и др.

**Backplate** — подложка, которую браузер рисует под текстом в forced-colors, чтобы сохранить контраст поверх
изображений.

**`prefers-contrast`** — медиафича: `no-preference` | `more` | `less` | `custom`.

## Палитры данных

**Категориальная палитра** (categorical, qualitative palette) — 6–10 цветов для несравнимых категорий. Требует
РАЗНОЙ светлоты, иначе схлопывается при CVD. → `02-…` §5.2

**Последовательная палитра** (sequential palette) — один оттенок, монотонная светлота, ΔL ≈ 10 п.п. при 7
ступенях. Для непрерывной величины.

**Расходящаяся палитра** (diverging palette) — два оттенка через нейтральную середину, симметричные светлоты,
нечётное число ступеней. Для величины с осмысленной серединой. Не красный↔зелёный.

**Viridis** — семейство перцептивно равномерных шкал, монотонных по светлоте и пригодных при CVD.

**Радуга (rainbow, jet)** — шкала, немонотонная по светлоте; для непрерывных данных не годится.

## Инструменты и форматы

**Design Tokens (W3C DTCG)** — формат описания токенов; поддерживается на выходе Leonardo. Подробности — папка
`09-design-tokens/`.

**Leonardo** (`@adobe/leonardo-contrast-colors`) — генерация шкал по СПИСКУ ЦЕЛЕВЫХ КОНТРАСТОВ, а не по светлотам.
Параметры темы: `lightness`, `contrast`, `saturation`.

**Huetone** — генератор шкал с отображением контраста каждого шага по WCAG и APCA; использует chroma.js.

**culori** — JS-библиотека: конвертации, `wcagContrast`, `clampChroma`, `toGamut`, `filterDeficiency*`,
`interpolate`.

**colorjs.io** — JS-библиотека с классом `Color`: `.oklch.l`, `.inGamut('srgb')`, `.toGamut()`.

**Accessible Palette** — веб-инструмент: лестница светлот CIELAB + компенсация оттенка + двойная проверка
контраста.

**oklch.com** — пикер OKLCH с графиком границы гамута sRGB/P3 (Evil Martians).

**Bridge-PCA** — метод, обратно совместимый с WCAG 2, но с перцептивной математикой.

**`stylelint-gamut`** — линтер, находящий цвета вне sRGB, не обёрнутые в `@media (color-gamut: p3)`.
