# Глоссарий: оценка визуального качества

Волна 3, агент I, 22 сентября 2026. Термины оценки, проверок и рецептов. Формат: русский термин (английский
оригинал) — определение в 1–2 строки, пример значения. Смежные глоссарии: `../01-color/glossary.md`
(контраст, APCA, CVD), `../09-design-tokens/glossary.md` (токены), `../10-design-systems-atlas/glossary.md`
(декларация против практики). Сводный глоссарий собирается в `../00-glossary/`.

## Жанры оценки

| RU | EN | Определение | Пример |
|---|---|---|---|
| Чек-лист | checklist | Закрытый список проверок «да/нет» с порогом у каждой | 117 проверок в 13 группах |
| Рубрика | rubric | Шкала с якорями по каждому измерению | 0–5 по десяти измерениям |
| Якорь балла | anchor, descriptor | Словесное описание того, что значит конкретный балл | «3 — система есть, нарушения единичны» |
| Критика | critique | Проза с замечаниями, без оценки и без таблицы | «правая колонка, третья карточка: …» |
| Аудит | audit | Таблица по пунктам чек-листа со статусом у каждого | пройдено / частично / нет / неприменимо / не видно |
| Дизайн-ревью | design review | Процесс приёмки визуального слоя перед выпуском | второй человек обязателен |
| Приёмочный шлюз | acceptance gate | Бинарное условие, без которого релиз не выпускается | контраст 4.5:1, цели 24 px |
| Порог приёмки | acceptance threshold | Числовое условие прохождения проверки | «доля отступов из шкалы ≥ 95 %» |
| Серьёзность | severity | Уровень нарушения: блокер, серьёзно, полировка | блокер — нарушение норматива A/AA |
| Профиль оценки | score profile | Набор баллов по измерениям вместо одного числа | десять столбиков вместо «3.4» |
| Скрининг | screening | Отбор кандидатов метриками до человеческой проверки | отсеять перегруженные раскладки |
| Definition of done | definition of done | Список условий, при которых работа считается законченной | восемь измерений качества компонента |
| Kitchen sink | kitchen sink page | Страница со всеми вариантами и состояниями компонента для QA | `buttons-sink.html` |
| Тест на прищур | squint test | Проверка иерархии на размытом макете | Gaussian blur 6–10 px при 1440 |

## Метрики вычислимой эстетики

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Визуальная сложность | visual complexity | Воспринимаемое количество и разнообразие элементов | R² модели .65 (Reinecke) |
| Прототипичность | prototypicality | Насколько страница похожа на типичную страницу своего класса | η²p .55–.81 (Tuch) |
| Цветность | colorfulness | Формула Хаслера–Зюсструнка `σ_rgyb + 0.3 µ_rgyb` | 33 «умеренно», 59 «весьма» |
| Доминирующие цвета | dominant colors | Число цветовых кластеров, покрывающих заметную площадь | коррелирует с красотой **отрицательно** |
| Глубина цвета | color range, color depth | Число различных значений цвета | коррелирует **положительно**, r +.56 |
| Плотность контуров | contour density, edge density | Доля контурных пикселей | хорошо 0–0.0296, плохо ≥ 0.0495 |
| Сгущение контуров | contour congestion | Доля контуров, у которых есть сосед в 20 px | хорошо 0–0.6033 |
| Контраст фигуры и фона | figure-ground contrast | Взвешенная сумма краёв, найденных Canny на семи порогах | хорошо ≥ 0.6856 |
| Feature Congestion | feature congestion | Мера зрительного шума через локальную ковариацию признаков | хорошо 0–3.771 |
| Subband entropy | subband entropy | Энтропия вейвлет-поддиапазонов; веса 0.84 яркость, 0.08 + 0.08 цветность | хорошо 0–2.7153 |
| Квадродерево | quadtree decomposition | Рекурсивное деление кадра по энтропии | r .28 со сложностью — слабо |
| Пространственная сегментация | space-based decomposition | Рекурсивный X-Y cut по видимым разделителям | r .50 со сложностью |
| Белое пространство | white space ratio | Доля кадра, не покрытая визуальными блоками | практически не коррелирует |
| Grid quality | grid quality | Пять мер сетки: число блоков, точек выравнивания, размеров блоков, покрытие | допуск выравнивания 2 px |
| Баланс | balance | Равномерность визуального веса по осям | r .57–.72 с красотой (Zheng) |
| Равновесие | equilibrium | Центрирование массы вокруг середины кадра | на веб-страницах **не коррелирует ни с чем** |
| Симметрия | symmetry | Совпадение объектов по осям | частичная симметрия нравится меньше всего |
| Экономность | economy (Ngo) | `1 / число различных размеров` | аналог правила «размеров ≤ 8» |
| Однородность | homogeneity (Ngo) | Равномерность распределения объектов по квадрантам через энтропию Больцмана | 0…1 |
| AIM | Aalto Interface Metrics | Открытый каталог из 26 метрик с порогами good/normal/bad | `github.com/aalto-ui/aim` |
| Аффект внимания | saliency | Предсказание того, куда смотрит глаз | UMSI, MD-EAM (0.5 / 3 / 5 с) |
| Эффект эстетики и юзабилити | aesthetic-usability effect | Красивый интерфейс делает пользователя терпимее к мелким проблемам и маскирует их при тестировании | «this effect can mask UI problems» |

## Оценка моделями

| RU | EN | Определение | Пример |
|---|---|---|---|
| Модель-критик | VLM critic | Визуально-языковая модель, оценивающая скриншот | GPT-5, Gemini, UIClip |
| Zero-shot | zero-shot | Запрос без примеров | 13 % валидных критик |
| Few-shot | few-shot | Запрос с примерами, подобранными по сходству | 8-shot: качество 0.58 против 0.24 |
| Визуальное сходство | visual similarity | Подбор примеров по эмбеддингу изображения | лучший способ отбора примеров |
| Задачное сходство | task similarity | Подбор примеров по задаче экрана | вместе с визуальным даёт максимум |
| Visual prompting | visual prompting | Подсказки, нанесённые на кадр | координатная рамка: IoU 0.186; сетка поверх кадра: 1.1e−5 |
| Качество комментария | comment quality | Валидный 1, частично валидный 0.5, невалидный 0 | человек 0.75, few-shot 0.58 |
| Точность рейтинга | rating accuracy | Точное совпадение 1, отклонение на 1 пункт 0.5 | 0.53 у лучшего набора |
| IoU | intersection over union | Пересечение предсказанного и истинного bbox | < 0.20 у всех моделей |
| Джиттер | jitter | Контролируемая порча дизайна для обучения | смена цвета, кегля, отступов, контраста |
| CRAP | contrast, repetition, alignment, proximity | Четыре принципа, по которым строятся порчи в UIClip | — |
| Попарное сравнение | pairwise comparison | «Какой из двух лучше» вместо абсолютной оценки | UI-Bench: 4 075 матчей, 194 эксперта |
| TrueSkill | TrueSkill | Рейтинг по парным сравнениям | старт μ 25.0, σ 8.33 |
| Слепая зона | blind spot | Класс дефектов, который инструмент не видит | локализация, стабильность, 1.4.11 |

## Инструменты и их сущности

| RU | EN | Определение | Пример |
|---|---|---|---|
| Правило | rule | Именованная проверка в линтере | `color-contrast`, `target-size` |
| Тег правила | tag | Метка стандарта у правила axe | `wcag2aa`, `wcag143`, `ACT` |
| Нарушение | violation | Проверка провалена | `violations[]` в axe |
| Требует проверки | incomplete, needs review | Проверка не завершена по техническим причинам | градиент под текстом |
| Неприменимо | inapplicable | На странице нет элементов для этой проверки | `inapplicable[]` |
| Воздействие | impact | Серьёзность нарушения в axe | minor / moderate / serious / critical |
| Крупный текст | large text | Текст, к которому применяется порог 3:1 | 18 pt = 24 CSS px, 14 pt bold = 18.667 px |
| Правило кругов | spacing exception | Исключение SC 2.5.8 для недоразмерных целей | круги 24 px вокруг центров не пересекаются |
| Инлайновое исключение | inline exception | Ссылка внутри строки текста не нормируется по размеру | SC 2.5.8, SC 2.5.5 |
| Строгое значение | strict value | Требование, чтобы в CSS стояла переменная, а не литерал | `scale-unlimited/declaration-strict-value` |
| Произвольное значение | arbitrary value | Значение в квадратных скобках у Tailwind | `p-[13px]` — сюда уходят числа вне шкалы |
| Порог диффа | diff threshold | Допустимое различие при сравнении скриншотов | Playwright 0.2 (YIQ), Chromatic 0.063 |
| Маска | mask | Область, исключённая из сравнения скриншотов | `maskColor: "#FF00FF"` |
| Эталон | baseline, golden | Снимок, с которым сравнивают новый | `<test>-snapshots/*.png` |
| Эмуляция медиа | media emulation | Подмена системных настроек в браузере | `color_scheme`, `reduced_motion`, `forced_colors`, `contrast` |
| Обход табом | tab walk | Последовательное нажатие Tab со снятием состояния фокуса | 20–24 остановки |
| Эффективный фон | effective background | Непрозрачный цвет под элементом после композитинга альфы | нужен для честного контраста |
| Композитинг альфы | alpha compositing | Наложение полупрозрачного цвета на непрозрачный | `rgb(2 6 24 / .32)` над `#f8fafc` → `#a9acb3` |

## Маркеры генерации

| RU | EN | Определение | Пример |
|---|---|---|---|
| Антислоп | anti-slop | Группа проверок против типовых следов генерации | эмодзи, градиенты, `scale` на hover |
| «Почти, но не совсем» | almost-but-not-quite | Разница 1–3 px между величинами, которые должны быть равны | карточки 204 и 208 |
| Дефолт библиотеки | library default | Узнаваемый неизменённый набор значений | shadcn: `--radius: 10px`, zinc, Inter, почти чёрный primary |
| Ручка узнаваемости | recognisability knob | Значение, смена которого снимает «вид из коробки» | нейтраль, радиус, тень, шрифт, акцент |
| Кластер маркеров | marker cluster | Совпадение нескольких признаков генерации на одном экране | Inter + индиго-градиент + три карточки + тень 0.1 |
| Карточка, которая ничего не делает | non-functional card | Блок в оформлении карточки без действия и без данных | — |
| Оптимизированный бриф | optimised prompt | Промт с явными значениями и запретами | 86 с → 28 с, 63 % → 100 % (Electronics 2026) |
