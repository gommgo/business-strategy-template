# Примеры экранов на эталонных токенах

Волна 3 · агент I · 22 сентября 2026

Семь собранных экранов веб-сервиса на пресете «плотная админка» (рецепт 11, пресет A). Вся визуальная
часть построена на эталонной схеме токенов `../../09-design-tokens/04-reference-token-schema.md`; в слое
компонентов нет ни одного литерала цвета, размера, радиуса, тени и z-index — только семантические
CSS-переменные.

Экраны нужны для трёх вещей: показать значения базы в работе, дать генератору образец разметки и служить
тестовым стендом для `../../scripts/ui/ui_audit.py`.

## Как воспроизвести прогон

```bash
cd /home/mm/Документы/ui-research
for f in 01-table-with-filters 02-form 03-dashboard 04-empty-state 05-modal 06-settings 07-object-page; do
  python3 ../../scripts/ui/ui_audit.py "14-recipes/examples/$f.html" \
    --preset admin --tokens ./dist/tokens.json \
    --scheme both --reduced-motion --hover --tab 24 \
    --out 14-recipes/examples/audit --quiet
done
```

`dist/tokens.json` получается командой `python3 ../../scripts/ui/build_reference_tokens.py --out ./dist`. Каталог `dist/`
в базе не хранится; при повторном прогоне 22.09.2026 использован временный каталог.

Прогон включает: светлую и тёмную тему, режим `prefers-reduced-motion`, наведение на выборку до 12
интерактивных элементов с расчётом ΔL в OKLCH, обход табом на 24 остановки со снятием индикатора фокуса.

## Единственное нарушение — и почему оно оставлено

**I1c, экран `01-table-with-filters`, тёмная тема:** отключённая кнопка «Назад» в пагинации даёт
APCA Lc 25.0 при коридоре 30–60 из `../../01-color/05-states-and-interaction.md` §4.2. Причина — значение
`fg.disabled` в тёмной теме эталонной схемы (`#62748e` на `#1d293d`). Это не дефект примера, а находка по
схеме: в её собственных проверках контраста (56 пар) отключённого состояния нет.

Нарушение оставлено намеренно: спрятать его, убрав `disabled` с кнопки, означало бы потерять результат.

> Разрешение противоречия [C34] (22.09.2026, волна 4): схема исправлена — `fg.disabled` тёмной темы переведён на neutral-450 `#7d8fa8` (APCA Lc 38 на `bg.surface`, 31 на `bg.surface-raised`), `tokens.css` перегенерирован, все семь экранов перепрогнаны: 1489 OK, 0 FAIL, 74 информативных (таблица выше обновлена). Текст этого раздела сохранён как история находки. См. `../../CONTRADICTIONS.md`.

## Что ещё нашёл прогон в самой схеме токенов

> Разрешение противоречий [C13], [C14] (22.09.2026): пункты 1 и 2 закрыты правкой схемы — добавлена роль `bg.selected-hover` (accent-200 / accent-900; `app.css` переведён на неё вместо кольца), третичный текст тёмной темы переведён на neutral-350 `#aebccf` (5.37:1 на `surface-raised`), `danger.text` на red-300; пары добавлены в проверки генератора. Пункты 3–5 остаются в силе. См. `../../CONTRADICTIONS.md`.

1. **Нет роли `bg.selected-hover`.** Комбинация selected + hover в базе объявлена обязательной
   (`../../06-components-visual/07-states-matrix.md` §10), но фона под неё в схеме нет. В примерах второй
   признак дан кольцом: `box-shadow: inset 0 0 0 1px var(--accent-border)` у активного пункта навигации и
   `outline: 1px solid var(--accent-border); outline-offset: -1px` у выбранной строки таблицы.
2. **`fg.tertiary` не проходит 4.5:1 на `bg.surface-raised` в тёмной теме**: `#90a1b9` на `#314158` даёт
   3.94:1. То же у `danger.text` `#ff6467` на `#314158` (3.59:1). В примерах подсказки внутри модалки берут
   вторичный цвет, а встроенное в карточку меню лежит на обычной поверхности.
3. **Браузерные дефолты попадают в шкалу отступов.** У `button` и `input` есть `padding-block: 1px` от
   пользовательского агента; без явного `padding-block: 0` доля отступов из шкалы падает с 100 % до 91.5 %.
4. **Наследованный интерлиньяж даёт дробные пиксели.** Блок с переопределённым `font-size: 12px` и
   унаследованным `line-height: calc(20/14)` даёт 17.14 px. Интерлиньяж задаётся везде, где задан кегль.
5. **`--space-inset-table-cell-y` = 2 px** рассчитан на строку 28–32; при строке 36 высота задаётся через
   `height` строки, а вертикальный padding ячейки остаётся 0.

## Ограничения примеров

- Это статические HTML без JavaScript: состояния `open`, `loading`, `indeterminate` и реальные оверлеи с
  порталом не показаны; модалка нарисована как постоянный слой.
- Экраны собраны под пресет A (плотная админка) и проверяются им же. Прогон с `--preset consumer` даёт
  ожидаемые расхождения: другой ряд радиусов и кеглей.
- Мобильная адаптация не делалась: прогон `--touch` на 390 × 844 честно показывает цели меньше 44 px и
  сайдбар шириной во весь экран. Это пресет для десктопа.
- Иллюстрация пустого состояния — схематичный SVG 96 px, а не система иллюстраций из
  `../../07-iconography-imagery/02-illustration-system-avatars-images.md`.
