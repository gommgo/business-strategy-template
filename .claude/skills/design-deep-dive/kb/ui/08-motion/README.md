# 08-motion — движение как система токенов

Волна 2, агент M, 22 сентября 2026. Прочитано целиком: 59 внешних источников (исходники токенов 15 дизайн-систем, документация, спецификации W3C и MDN, материалы практиков) плюс 9 видеодайджестов агента V и собственный пересчёт измерений 24 живых продуктов. Сырые заметки: `../99-raw/notes/wave2/M-notes.md`. Отчёт: `../99-raw/reports/wave2-M-report.md`.

## Выжимка папки

1. **Шести длительностей хватает на продукт**: 0, 100, 150, 200, 300, 400 ms. Дефолт 150 ms. Измерения живых продуктов: три значения (150, 200, 300) покрывают **70 %** всех переходов в вебе, длиннее 300 ms — всего 1.4 %.
2. **Четырёх кривых хватает**: standard `cubic-bezier(0.4, 0, 0.2, 1)`, entrance `(0, 0, 0.2, 1)`, exit `(0.4, 0, 1, 1)`, linear. Правило ролей: вход тормозит, выход ускоряется, перемещение внутри экрана симметрично, цикл линеен.
3. **Выход оверлея короче входа на 50–100 ms** (Atlassian: Modal 250 → 200, Popup 150 → 100). У hover правило обратное: приход 125 ms, уход 450 ms.
4. **Фокус не анимируется** — 0 ms, отдельный токен.
5. **Material 3 объявил длительности и кривые устаревшими** («no longer maintained») в пользу пружин motion physics. Официальная таблица перевода пружин в `cubic-bezier` для веба — в файле 01 §4.5; все spatial-кривые с перелётом до 67 %.
6. **Carbon прямо запрещает перелёт** в рабочих интерфейсах, M3 Expressive его требует. Противоречие разрешается типом продукта, а не усреднением.
7. **Длительность растёт от расстояния как корень четвёртой степени**: 36 px → 192 ms, 300 px → 311, 600 px → 376 (формула MUI).
8. **Анимируй только `transform` и `opacity`** (плюс цвет на малых площадях). Бюджет кадра 16.6 ms. Высоту раскрывай через `grid-template-rows: 0fr → 1fr`, не через `height`.
9. **`prefers-reduced-motion` — Baseline с января 2020.** Принцип «reduce, not remove»: пространственное движение заменяется затуханием, длительности сокращаются, а не обнуляются. Реализуется переопределением токенов, а не правками компонентов.
10. **Готовые наборы:** 41 токен движения в DTCG JSON и в CSS, два пресета («плотная админка» — дефолт 100 ms, потолок 200, без масштабов и пружин; «клиентский сервис» — дефолт 150 ms, потолок 400, scale 0.95, одна пружина) — файл 03 §5–§7.

## С чего начать

- Нужно **быстро задать движение новому продукту** → файл 03 §7 (два пресета целиком) → файл 03 §6 (CSS) → файл 02 §3 (каталог по компонентам).
- Нужно **понять, почему числа именно такие** → файл 01 §1–§2 (атласы систем) → файл 01 §6 (что реально применяется).
- Нужно **добавить движение конкретному компоненту** → файл 02 §3.
- Нужно **поддержать сокращённое движение** → файл 03 §3 (реализация) и §2 (что требуют стандарты).
- Нужно **выпустить токены движения** → файл 03 §5 (DTCG) и `../09-design-tokens/` (общая архитектура).
- Нужна **пружина** → файл 01 §4, готовые строки `linear()` — файл 03 §7.2.
