## Как искать

1. По русскому термину: `grep -n "^\*\*Термин" 00-glossary/glossary.md` (термин стоит в начале строки жирным).
2. По английскому термину или синониму: `grep -in "term" 00-glossary/glossary.md`, либо раздел 15 «Указатель по английским терминам»: буква → список «термин → номер раздела».
3. По теме: разделы 1–13 повторяют порядок папок базы (1 цвет … 13 оценка); внутри раздела порядок тот же, что в папочном глоссарии, объединённые из других папок термины стоят в конце раздела.
4. Если у термина в разных папках разный смысл (плейсхолдер, индикатор, overshoot, baseline, mode), в указателе у него два номера раздела, а в разделе 14 объяснено, какое значение принято в базе.

## Формат записи

`**RU термин** (EN термин, синонимы) — определение из папочного глоссария. Пример: значение. → путь к файлу, где термин раскрыт [§раздел]; папки, где он тоже определён. В NN то же под именем «…»: формулировка другой папки.`

Стрелка `→` ведёт к указателю из папочного глоссария (`01-color/01-color-models-and-scales.md` §2.3), иначе к файлу папки, где термин встречается чаще всего, иначе к папке. Метки `[V15]` ведут к дайджестам `91-videos/digests/`, метки `[S17 папки 02]` — к разделу «Источники» указанной папки.

## Как обновлять

Сводный файл собирается из папочных глоссариев скриптами агента Q (разбор `glossary.md` каждой папки, объединение по нормализованным RU и EN ключам с ручными исключениями для омонимов, генерация указателей). При правке папочного глоссария правьте и сводный: найдите термин по `grep`, обновите определение и, если термин новый, добавьте его в раздел темы и в оба указателя.
