## 1. Аватары

### 1.1. Размеры

| Система | Ряд |
|---|---|
| Radix [S6] | **24 / 32 / 40 / 48 / 64** / 80 / 96 / 128 / 160 |
| Spectrum [S10] | 16 / 20 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 52 … 104 (шаг 4) |
| shadcn [S1] | 24 / **32** / 40 |
| Ant [S7] | 24 (SM) / **32** / 40 (LG) |
| Material [S5] | 40 в списке, 24 в input-chip, 30 в search bar |
| Волна 1 | 20 / 24 / 32 / 40 / 48 / 64 |

Где какой: 20–24 в строке плотной таблицы и в чипе, 32 в списке и комментарии, 40 в шапке карточки и в
профиле сайдбара, 48 в карточке пользователя, 64+ на странице профиля.

### 1.2. Инициалы

| Аватар | Одна буква | Две буквы |
|---|---|---|
| 24 | 12 | 10–11 |
| 32 | 13–14 | 12 |
| 40 | 16 | 14 |
| 48 | 18–20 | 16 |
| 64 | 24 | 20 |

Radix держит для одной и двух букв разные токены, причём двухбуквенный вариант на шаг мельче [S6];
вес 500, `line-height: 1`, трекинг по шкале.

### 1.3. Обводка и фон

- кольцо: `box-shadow: 0 0 0 1px var(--avatar-borderColor)` (Primer) [S8], в группе 2 px цвета подложки;
- Spectrum: `avatar-border-width: 1`, цвет белый, `avatar-opacity-disabled: 0.3` [S10];
- фон заглушки: нейтральный `--surface-subtle` или цвет из хеша имени;
- цвет из хеша `[мнение]`: `hue = hash(name) mod 360`, `L = 0.70`, `C = 0.08` в OKLCH — одинаковая светлота
  даёт предсказуемый контраст инициалов (`../01-color/01-color-models-and-scales.md`); не брать случайный
  HSL, иначе половина аватаров окажется тёмной, половина светлой.

### 1.4. Группа

| Параметр | Значение |
|---|---|
| Наложение | **−8** при 24–32, −12 при 40 (shadcn `-space-x-2`, Ant `groupOverlapping: -8`) [S1][S7] |
| Кольцо | 2 px цвета фона у каждого |
| Порядок | первый сверху; `z-index` убывает слева направо |
| Остаток | «+7» тем же размером, фон `--surface-subtle`, кегль как у инициалов |
| Максимум видимых | 3–5 |

### 1.5. Форма

Круг по умолчанию `[V02 12:13]`. Квадратный вариант: радиус `clamp(4px, calc(размер − 24px), 6–8px)`
(Primer) [S8] — при 24 px радиус 4, при 32 px 8. Организации и репозитории обычно квадратные, люди круглые.

### 1.6. Статус на аватаре

Точка 8 / 10 / 12 для аватаров 24 / 32 / 40 (shadcn) [S1], позиция — правый нижний угол, кольцо 2 px
цвета подложки, контраст цвета точки ≥ 3:1 (см. `05-feedback-and-overlays.md` §1.5).

## 2. Прогресс и спиннеры

### 2.1. Линейный прогресс

| Система | Высота | Радиус | Прочее |
|---|---|---|---|
| Primer [S8] | **5 / 8 / 10** | 3 | `gap: 2` между сегментами, `outline: 1px` inset у дорожки, шиммер 1 с |
| Radix [S6] | **4 / 6 / 8** | `max(h/3, radius-thumb)` | дорожка `gray-a3`, у surface-варианта кольцо 1 px |
| Carbon [S4] | **8** (small 4) | максимальный | `min-width: 48` |
| Material [S5] | 4 | — | трек и индикатор по 4 |
| Ant [S7] | 8 | 100 (пилюля) | `remainingColor = colorFillSecondary` |
| Spectrum [S10] | 4 / 6 / 8 / 10 | — | `min-width: 48`, `max-width: 768` |

Индикатор: заливка акцентом; при статусе — цвет статуса. Подпись процента 12–13 справа или над полосой,
`tabular-nums`.

### 2.2. Неопределённый прогресс

Бегущая полоса шириной 30–40 % трека, цикл 1.5–2 с; либо шиммер-маска (Primer: `mask-image` + анимация
`shimmer` 1 с) [S8]. При `prefers-reduced-motion` — статичная полоса 50 % или пульсация вместо движения.

### 2.3. Круговой прогресс и спиннеры

| Система | Размеры | Толщина |
|---|---|---|
| Material [S5] | **48** | 4 |
| Primer [S8] | 16 / 32 / 64 | 2 |
| Radix [S6] | 12 / 16 / 20 | — (8 лепестков по 12.5 % ширины) |
| shadcn [S1] | 16 | — |
| Рекомендация | **16** в кнопке и строке, 20–24 в панели, 32–48 по центру пустой области | 2 при 16–24, 3–4 при 32+ |

### 2.4. Анимация

Radix: 800 мс линейно, `opacity: 0.65`, лепестки затухают по очереди [S6]. Классический вариант: поворот
на 360° за 600–1000 мс, `linear`. Не ускорять быстрее 500 мс: спиннер начинает «дрожать».

### 2.5. Где какой индикатор

| Ситуация | Индикатор |
|---|---|
| Кнопка отправки | спиннер 16 вместо текста, ширина сохранена |
| Загрузка данных в таблицу | скелетон-строки |
| Обновление уже показанных данных | полоса 2–4 px сверху области или спиннер в тулбаре |
| Загрузка файла | линейный прогресс 4–8 с процентом |
| Долгая операция (> 10 с) | прогресс с текстом шага, не спиннер |

## 3. Скелетоны

### 3.1. Геометрия

| Элемент | Высота | Радиус |
|---|---|---|
| Строка текста | 12–16 (Radix `space-3` = 12; Ant 16) | 4 |
| Заголовок | 20–24 | 4 |
| Аватар | = аватару | круг |
| Кнопка | = высоте кнопки | радиус кнопки |
| Карточка-плитка | = карточке | радиус карточки |
| Строка таблицы | = строке | 4 внутри ячеек |

Ширины блоков: 40–80 % колонки, последний в абзаце — 60 %, чтобы имитировать конец текста.

### 3.2. Цвет и анимация

| Система | Фон | Анимация |
|---|---|---|
| Radix [S6] | `gray-a3` → `gray-a4` | пульсация |
| shadcn [S1] | `bg-accent` | `animate-pulse` |
| Ant [S7] | градиент `colorFillContent` → `colorFill` | бегущий градиент |

Пульсация: 1.5–2 с, `opacity` 1 → 0.6 → 1. Шиммер: градиент шириной 30–50 % контейнера, 1–1.5 с. При
`prefers-reduced-motion` — статичная заливка без движения.

### 3.3. Правила

- скелетон имеет ту же высоту, что реальный контент, иначе страница прыгает при загрузке;
- не больше 5–10 строк-заготовок: длинные простыни скелетонов читаются как сбой;
- для точно известного числа элементов (пагинация 20) рисуй столько же строк;
- для текста неизвестной длины — 3 строки, последняя короче.

## 4. Пустые состояния

### 4.1. Состав и размеры

| Часть | Значение |
|---|---|
| Иллюстрация или иконка | 96–160 (на весь экран до 200) |
| Отступ до заголовка | 16–24 |
| Заголовок | 16–18/600 (shadcn `text-lg font-medium` = 18/500) |
| Текст | 14, ширина ≤ 420 (`max-w-sm` = 384 у shadcn), `muted` |
| Отступ до кнопки | 16–24 |
| Кнопка | одна первичная (+ одна вторичная ссылка) |
| Вертикальные поля блока | 48–96 |

### 4.2. Варианты

| Вид | Оформление |
|---|---|
| Пустая таблица | блок по центру области таблицы, высота ≥ 240, без рамки |
| Пустая панель или зона | пунктирная граница 1 px, радиус как у карточки, padding 24 (мобильный) — 48 (десктоп): shadcn `border-dashed p-6 md:p-12` [S1] |
| Первый запуск | иллюстрация 160–200, заголовок 20–24, две кнопки |
| Нет результатов поиска | иконка 48–64, заголовок 16, подсказка «измените запрос», кнопка «Сбросить фильтры» |
| Ошибка загрузки | иконка статуса 48, заголовок 16, кнопка «Повторить» |

### 4.3. Что не делать

Не использовать ту же иллюстрацию во всех пустых состояниях продукта; не делать иллюстрацию шире 240 в
админке; не ставить пустое состояние во всю высоту окна, если под ним есть контент.

## 7. KPI-плитки и метрики

### 7.1. Анатомия

```
┌─ карточка: padding 16 (админка) / 24 (клиент), радиус 8, граница 1 px ─┐
│ Подпись 12–14 muted                                     [иконка 16]   │
│ 1 234 567 ₽          ← значение 28–32/600, tabular-nums, трекинг −0.02 │
│ ↑ 12,4 % к прошлой неделе   ← дельта 12–13, знак + стрелка + цвет      │
│ [спарклайн 32–48 по высоте, во всю ширину]                            │
└────────────────────────────────────────────────────────────────────────┘
```

Роли из пресетов типографики: `text-metric` 28/32/600 в админке и 32/36/600 в клиентском сервисе
(`../02-typography/02-type-scale.md` §7–8), `text-caption` или `text-label` для подписи.

### 7.2. Дельта

- формат: стрелка 12–14 + знак + число + период («↑ 12,4 % за 7 дней»);
- цвет: `success` при росте, `danger` при падении — **но только вместе со стрелкой и знаком**;
- «рост» не всегда хорошо: для метрики «время ответа» рост это плохо, цвет надо инвертировать осознанно;
- фон-бейдж под дельту (высота 20, padding 2 × 6) применяется, когда дельта одна на плитку.

### 7.3. Сетка плиток

4 плитки в ряд при 1152 px (плитка ≈ 270, зазор 16), 2 в ряд при 768, 1 при 480. Высота плитки
одинаковая — задавай `min-height` (100–120 в админке), иначе ряд рваный.

## 8. Визуальный слой графиков

Цвета серий, порядок и контраст — `../01-color/06-character-gradients-tools.md` и
`../01-color/03-contrast.md`. Здесь только геометрия. `[мнение]`, сведено из практики и измерений.

### 8.1. Оси и сетка

| Элемент | Значение |
|---|---|
| Линии сетки | 1 px, `gray-200` (контраст к фону 1.2–1.4:1), только горизонтальные |
| Ось значений | подписи 11–12, `gray-500`, отступ от графика 8 |
| Ось категорий | подписи 11–12, поворот 0° (при нехватке места — 45° или усечение) |
| Нулевая линия | 1 px `gray-400`, если есть отрицательные значения |
| Отступы области | 8–16 сверху, 24–32 снизу (под подписи), 40–56 слева (под значения) |
| Легенда | 12, маркер 8–10 (круг или квадрат 2 px радиуса), зазор 6, между сериями 16 |

### 8.2. Геометрия серий

| Тип | Значения |
|---|---|
| Линия | толщина **2**, точка 4–6 (при наведении 6–8), сглаживание только для непрерывных данных |
| Столбцы | ширина по данным, зазор 20–40 % ширины столбца, радиус 2–4 сверху |
| Стопка | без зазора внутри столбца, разделитель 1 px цвета фона |
| Площадь | заливка 10–20 % цвета линии либо градиент к прозрачному |
| Пончик | толщина кольца 16–24 при диаметре 120–160 |
| Спарклайн | высота 32–48, линия 1.5–2, без осей |

### 8.3. Подсказка (tooltip графика)

Метрика поповера: padding 8–12, радиус 6–8, тень второго уровня, кегль 12–13; заголовок = категория,
строки = маркер 8 + имя серии + значение справа с `tabular-nums`.

| Номера строк | 11–12, `muted`, колонка 32–40, выравнивание вправо, `user-select: none` |
| Горизонтальный скролл | `overflow-x: auto`, без переноса |
| Кнопка «копировать» | 24–28 в правом верхнем углу, появляется при hover, на тач видна всегда |
| Подсветка строки | фон `accent-a3`, полоса слева 2 px |

Моноширинные гарнитуры и метрики — `../02-typography/01-font-selection.md`.

### 9.3. Клавиши (kbd)

Radix задаёт всё в `em`, поэтому клавиша масштабируется с текстом [S6]:
`font-size: 0.75em`, `min-width: 1.75em`, `line-height: 1.7em`, `padding-inline: 0.5em`,
`border-radius: 0.35em`, многослойные внутренние тени для эффекта клавиши.
Упрощённый вариант для админки: высота 20, padding 0 × 6, радиус 4, граница 1 px, фон `--surface-subtle`,
кегль 11–12, моноширинный.

## 13. Мелочи, которые часто забывают

### 13.1. Разделитель с меткой

Линия 1 px, текст 12 `muted` по центру, поля текста 8–12; общая высота 20–24; применяется в формах («или»)
и в лентах («сегодня»).

### 13.2. Метка «новое» и индикаторы

Точка 6–8 акцентом перед заголовком либо бейдж 16–20. Не ставить и то, и другое.

### 13.3. Счётчик символов

12, `muted`, справа под полем; при превышении — цвет `danger` и вес 500.

### 13.4. Полоса прокрутки

Ширина 8–12, бегунок `gray-a5` с радиусом 4, появляется при наведении (`scrollbar-gutter: stable`,
чтобы контент не прыгал). В плотных панелях 6–8.

### 13.5. Резервирование места

Любая величина, которая может появиться и исчезнуть (ошибка, счётчик, бейдж, спиннер), получает
зарезервированное место: `min-height` строки или `visibility: hidden` вместо `display: none`.

## Частые ошибки

1. **Аватар не квадратный по боксу** (`width: 40; height: 36`) — «сплющенный» круг.
2. **Инициалы 16 px в аватаре 24** — текст не помещается.
3. **Случайные цвета аватаров в HSL** — половина фонов тёмные, инициалы не читаются.
4. **Наложение в группе без кольца** — аватары слипаются.
5. **Прогресс 2 px** — не виден; **прогресс 16 px** — выглядит как полоса загрузки 2005 года.
6. **Спиннер 32 в кнопке 32** — не помещается и растягивает кнопку.
7. **Скелетон другой высоты, чем контент** — страница прыгает при загрузке.
8. **20 строк скелетона** — читается как сбой.
9. **Пустое состояние с иллюстрацией 320** в админке.
10. **Один и тот же рисунок во всех пустых состояниях.**
11. **Пагинация без `tabular-nums`** — цифры «дышат» при переключении.
12. **KPI-значение весом 400** — не читается как главное число плитки.
13. **Дельта только цветом** — при дейтеранопии направление неизвестно.
14. **Разная высота KPI-плиток в ряду.**
15. **Сетка графика вертикальная и горизонтальная одновременно** — «миллиметровка».
16. **Инлайн-код того же кегля, что текст** — моноширинный шрифт визуально крупнее на 5–10 %.
17. **Блок кода с переносом строк** — сломанные отступы.
18. **Звезда янтарного 500 на белом** — 2.14:1.
19. **Относительное время «3 года назад»** без абсолютной даты.

### Ошибки, характерные для генерации нейросетями

20. **`rounded-full` на квадратном `div` без `overflow: hidden`** — изображение выходит за круг.
21. **Скелетон `h-4 w-full` для всего подряд** — не повторяет геометрию контента.
22. **`animate-pulse` на всей карточке вместо отдельных блоков.**
23. **Пустое состояние с эмодзи вместо иллюстрации.**
24. **KPI-плитка с `text-3xl font-bold` (30/700)** и подписью `text-sm` — соотношение вместо 12 / 28.
25. **График, нарисованный как `div` с `background` градиентом** без осей и подписей.
26. **`font-mono text-sm` для кода** при основном 14 — моноширинный выглядит крупнее основного текста.
27. **Спиннер, вращающийся 2 с** — интерфейс кажется зависшим.
28. **Пагинация с 15 номерами страниц подряд** вместо «1 … 5 6 7 … 42».

## Чек-лист

- [ ] Аватары из ряда 20 / 24 / 32 / 40 / 48 / 64 и квадратные по боксу?
- [ ] Инициалы ≈ 40 % диаметра, две буквы на шаг мельче?
- [ ] Цвет аватара из хеша с фиксированной светлотой?
- [ ] В группе аватаров кольцо 2 px и наложение −8 / −12?
- [ ] Линейный прогресс 4–8 px с радиусом в половину высоты?
- [ ] Спиннер 16 в кнопке, 20–24 в панели, вращение 600–900 мс?
- [ ] Скелетоны повторяют высоту и радиус контента, не больше 5–10 штук?
- [ ] Анимации скелетонов и спиннеров отключаются при `prefers-reduced-motion`?
- [ ] Пустое состояние: иллюстрация ≤ 160 (админка), текст ≤ 420, одна кнопка?
- [ ] Для «нет результатов» и «ещё ничего не создано» разные тексты и разные действия?
- [ ] Пагинация: кнопка 32–40, счётчик с `tabular-nums`, свёртка номеров?
- [ ] KPI: подпись 12–14, значение 28–32/600, дельта со знаком и стрелкой?
- [ ] Высота KPI-плиток в ряду одинакова?
- [ ] На графике только горизонтальная сетка, подписи 11–12 `muted`?
- [ ] Инлайн-код на 1–2 px мельче основного текста?
- [ ] Блок кода со скроллом, а не с переносом?
- [ ] Звёзды рейтинга с контрастом ≥ 3:1 или с обводкой?
- [ ] Даты и длительности с `tabular-nums` и фиксированной шириной?
- [ ] Для исчезающих элементов зарезервировано место?

## Открытые вопросы и противоречия

1. **Размер спиннера в кнопке**: Primer small 16, Material circular 48 — разные роли, но системы не
   разделяют «спиннер в контроле» и «спиннер области». `[спорно]`
2. **Скелетон против спиннера**: измерений, что лучше, в прочитанных источниках нет; правило «скелетон для
   известной структуры, спиннер для неизвестной» — практика. `[мнение]`
3. **Геометрия графиков** не задана токенами ни в одной прочитанной дизайн-системе (Carbon Charts и
   Material Charts не читались): значения в §8 выведены из практики. `[мнение]`
4. **Цвет из хеша для аватаров** нигде не описан числом; формула в §1.3 предложена мной. `[мнение]`
5. **Высота KPI-значения**: агент B даёт 28–32, но в живых дашбордах встречается 40–48; измерений
   конкретно по KPI в наборе агента P нет. `[спорно]`
6. **Untitled UI и Material Charts** не читались: часть значений (иллюстрации, пустые состояния) взята из
   shadcn и практики. `[не проверено]`
