# Глоссарий: визуальные спецификации компонентов

Волна 2 · агент E · 22.09.2026

Термины анатомии, вариантов и состояний компонентов. Формат: русский термин, английский оригинал,
определение, пример значения. Смежные глоссарии: `../03-spacing-sizing/glossary.md` (отступы и размеры),
`../04-shape-elevation/glossary.md` (форма и глубина), `../01-color/glossary.md` (цвет),
`../02-typography/glossary.md` (типографика).

## 1. Анатомия

| RU | EN | Определение | Пример значения |
|---|---|---|---|
| Анатомия компонента | anatomy | Перечень частей компонента с их размерами и отступами | кнопка: контейнер, ведущая иконка, лейбл, замыкающая иконка |
| Контейнер | container | Внешний бокс компонента, несущий высоту, фон, границу и радиус | высота 32, радиус 6, граница 1 px |
| Ведущий визуал | leading visual | Иконка, аватар или индикатор слева от текста | иконка 16, зазор 8 |
| Замыкающий визуал | trailing visual | Иконка справа: шеврон, внешняя ссылка, счётчик, шорткат | шеврон 16 |
| Лейбл | label | Подпись элемента: текст кнопки, подпись поля, заголовок колонки | 14/20/500 |
| Плейсхолдер | placeholder | Текст-пример внутри пустого поля | `#6a7282`, 4.84:1 к белому |
| Подсказка | helper text, hint | Пояснение под полем | 12/16, `--text-muted` |
| Текст ошибки | error text | Сообщение о неверном значении под полем | 12/16, `--danger-text` |
| Слот | slot | Место внутри контейнера под произвольный элемент (иконку, кнопку) | ширина = высоте поля − 2 |
| Префикс / суффикс | prefix / suffix | Неинтерактивный текст или иконка внутри поля | «₽», отступ 12 / 6 |
| Индикатор | indicator | Полоса, точка или галочка, показывающая состояние | индикатор вкладки 2–3 px |
| Подложка состояния | state layer | Полупрозрачный слой поверх контейнера, дающий hover и pressed | Material: 8 %, 12 % |
| Кольцо | ring | Обводка, нарисованная тенью `0 0 0 Npx` вместо `border` | `0 0 0 1px` у аватара |
| Скрим | scrim, backdrop | Затемнение под модальным слоем | `rgb(0 0 0 / .32)` |
| Каретка | caret | Курсор ввода в поле | `caret-color: var(--text)` |
| Ручка (переключателя) | thumb, handle | Подвижный кружок внутри трека | 16 при треке 36 × 20 |
| Трек | track | Дорожка переключателя, слайдера или прогресса | 36 × 20; прогресс 8 |
| Ручка дровера | drag handle | Полоска для захвата нижнего дровера | 32 × 5, зона 44 |
| Разделитель | divider, separator | Линия между блоками или пунктами | 1 px, поля 4–12 |
| Зебра | zebra striping | Чередование фона строк таблицы | `#fafafa`, ΔL 1.5 п.п. |
| Липкая область | sticky region | Шапка, тулбар или футер, закреплённые при прокрутке | `position: sticky; top: 0` |
| Оптическая коррекция | optical correction | Сдвиг на 1–2 px для выравнивания по восприятию | чекбокс в ячейке: `translate-y-[2px]` |

## 3. Варианты

| RU | EN | Определение | Пример |
|---|---|---|---|
| Первичная | primary, filled | Главное действие, сплошная заливка акцентом | `bg-accent`, белый текст |
| Вторичная | secondary, default | Второе по важности действие | белая с границей или мягкая заливка |
| Третичная | tertiary, subtle, ghost | Прозрачная кнопка, фон появляется при наведении | hover α 4–5 % |
| Текстовая | text, plain, link | Только текст, без фона и границ | подчёркивание при hover |
| Контурная | outlined | Прозрачный фон, видимая граница | граница 1 px |
| Тональная | tonal, soft | Мягкая заливка акцентом | `accent-a3` |
| Деструктивная | destructive, danger, critical | Необратимое действие | красный текст или заливка |
| Инверсная | inverse | Светлое на тёмном (тултип, тост) | `gray-12` фон, `gray-1` текст |
| Плотный режим | compact, condensed | Вариант с уменьшенными отступами | строка 32, padding 8 |
| Просторный режим | spacious, comfortable | Вариант с увеличенными отступами | строка 48, padding 16 |
| Заливной вариант поля | filled | Поле с фоном и нижней границей | Carbon `$field` |
| Подчёркнутый вариант | underline | Поле только с нижней границей | Fluent `underline` |
| Плавающий лейбл | floating label | Подпись внутри поля, поднимающаяся при вводе | Material |
| Пилюля | pill | Полное скругление по высоте | `border-radius: 9999px` |
| Блочная кнопка | block button | Кнопка во всю ширину контейнера | `width: 100%` |

## 4. Состояния

| RU | EN | Определение | Пример дельты |
|---|---|---|---|
| Покой | rest, default, enabled | Исходное состояние | — |
| Наведение | hover | Указатель над элементом | ΔL 2–6 п.п., α 4–5 % |
| Нажатие | active, pressed | Момент нажатия | ΔL 5–9 п.п., α 8 % |
| Фокус | focus | Элемент получил фокус | кольцо 2 px |
| Видимый фокус | focus-visible | Фокус, показываемый при клавиатурной навигации | `:focus-visible` |
| Фокус внутри | focus-within | Фокус на потомке контейнера | показ кнопки очистки |
| Выбрано | selected | Устойчивый выбор строки, вкладки, пункта | фон `accent-a8` + второй признак |
| Отмечено | checked | Состояние чекбокса, радио, переключателя | заливка акцентом |
| Раскрыто | expanded | Открытый триггер меню или аккордеона | `[aria-expanded='true']` = active |
| Неопределённое | indeterminate | Частичный выбор в группе чекбоксов | горизонтальная черта 8–10 × 2 |
| Отключено | disabled | Недоступно для взаимодействия | APCA Lc 30–45 |
| Только чтение | readonly | Значение показано и копируется, но не меняется | граница прозрачная |
| Ошибка | invalid, error | Значение не прошло проверку | граница + иконка + текст |
| Предупреждение | warning | Значение допустимо, но требует внимания | граница `warning` |
| Загрузка | loading, busy | Операция выполняется | спиннер 16, ширина сохранена |
| Перетаскивание | dragged | Элемент тащат | слой 16 % (Material) |
| Зона вставки | drop target | Куда упадёт элемент | линия 2 px акцентом |
| Посещено | visited | Ссылка уже открывалась | фиолетовый в контентных разделах |
| Устойчиво нажато | pressed (toggle) | Кнопка-переключатель во включённом виде | `bg-fill-selected` |

## 5. Величины и правила

| RU | EN | Определение | Пример |
|---|---|---|---|
| Дельта состояния | state delta | Насколько меняется светлота между состояниями | hover −4 п.п. L |
| Альфа-слой | alpha layer | Полупрозрачная нейтраль поверх фона | 4 % чёрного → `#f5f5f5` |
| Слои состояний | state layers | Модель Material: фиксированные альфы на все компоненты | 0.08 / 0.12 / 0.12 / 0.16 |
| Шаг шкалы | scale step | Способ Radix: состояние = следующий шаг палитры | 3 → 4 → 5 |
| Кольцо фокуса | focus ring | Видимый индикатор фокуса | 2 px, offset 2, ≥ 3:1 |
| Смещение кольца | outline-offset | Зазор между элементом и кольцом | 2 снаружи, −1 внутрь |
| Двойное кольцо | double ring | Тёмное + светлое кольцо для любого фона | Chrome, Cal.com, Plausible |
| Цель нажатия | touch target, hit area | Минимальная зона взаимодействия | 24 (WCAG AA), 44 (тач) |
| Зона захвата | hit area | Невидимое расширение цели нажатия | `::before` 44 × 44 |
| Компенсация иконки | icon padding compensation | Уменьшение padding при наличии иконки | 16 → 12 |
| Множитель ширины | width multiplier | Минимальная ширина как доля высоты | кнопка 2.25 ×, поле 1.5 × |
| Табличные цифры | tabular numerals | Моноширинные цифры для колонок | `font-variant-numeric: tabular-nums` |
| Усечение | truncation | Обрезка текста с многоточием | `text-overflow: ellipsis` |
| Резервирование места | space reservation | Место под элемент, который может появиться | `min-height` строки ошибки |
| Вложенный радиус | nested radius | Внутренний радиус = внешний − padding | 12 − 4 = 8 |
| Порядок разделения | separation order | отступ → линия → фон → тень | карточка админки: граница |
| Плотность | density | Режим отступов и высот | compact / default / spacious |
| Инверсная поверхность | inverse surface | Тёмная поверхность в светлой теме | тултип, тост |
| Парные тона | paired tones | Светлая и плотная версия одного статуса | Polaris `tone` / `tone-strong` |
| Компонентный токен | component token | Токен, привязанный к части компонента и состоянию | `button.primary.bg.hover` |

## 6. Приёмы реализации

| RU | EN | Определение | Пример |
|---|---|---|---|
| Граница тенью | shadow border | Граница, нарисованная `box-shadow: inset 0 0 0 1px` | Radix, Polaris |
| Невидимая граница | invisible border | Граница цвета фона, чтобы высота не менялась при подсветке | Carbon `border-block-start` |
| Заливка тенью | shadow fill | Анимируемая заливка через `inset 0 0 0 32px` | чекбокс Polaris |
| Сетка из трёх зон | three-area grid | `grid-template-areas: 'lead text trail'` у кнопки | Primer |
| Скрытие лейбла при загрузке | label hiding | `visibility: hidden` вместо `display: none` | Primer loading |
| Портал | portal | Рендер оверлея вне DOM-родителя | меню, модалка |
| Авторост поля | auto-grow | `field-sizing: content` у textarea | shadcn |
| Отрицательное поле слота | negative slot margin | Прижатие слота к границе поля | Radix `Slot` |
| Маска-шиммер | shimmer mask | Анимированная маска для скелетона и прогресса | Primer, Ant |
| Ripple без JS | CSS ripple | `outline: 0.5em` при `pointer: coarse` | Radix |
| Container queries | container queries | Перестроение набора кнопок по ширине контейнера | Carbon ButtonSet |
