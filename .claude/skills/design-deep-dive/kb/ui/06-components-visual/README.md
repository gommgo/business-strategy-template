# 06. Визуальные спецификации компонентов

Волна 2, агент E, 22 сентября 2026. Прочитано целиком 28 источников: исходники двенадцати дизайн-систем
(shadcn/ui, Polaris, Fluent 2, Carbon v11, Material 3, Radix Themes, Ant Design 5, Primer, GOV.UK,
Spectrum 2, Mantine, MUI), библиотеки Sonner и Vaul, Tailwind v4, шесть статей и исследований, измерения
24 живых продуктов агента P и собственные расчёты контраста. Сырые заметки:
`../99-raw/notes/wave2/E-notes.md`, отчёт: `../99-raw/reports/wave2-E-report.md`.

## Выжимка папки

1. **Дефолт контрола: 32 px в плотной админке, 40 px в клиентском сервисе.** Практика подтверждает 32
   (самая частая высота кнопки и интерактивного элемента вообще); Spectrum держит оба значения в одном
   токене под desktop и mobile.
2. **Padding кнопки имеет два режима: компактный 8 и просторный 16**; декларируемые 12 в измерениях редки.
   Горизонтальный padding уменьшается на 2–4 px, когда внутри есть иконка.
3. **Иконка 16 при тексте 14 и 20 при тексте 16**; в живых продуктах 16 × 16 — 53 % всех иконок.
4. **Правило «одна высота на ряд» выполняют только 2 продукта из 20** — проверяй его скриптом, а не на глаз.
5. **Граница поля: два режима.** Как требует 1.4.11 — ≥ 3:1 (на белом `#959595`); как в практике — 1.2–1.5:1
   с компенсацией заливкой и контрастным фокусом.
6. **Строка таблицы 32 / 36 / 40 / 48**, кегль не меняется с плотностью, шапка без uppercase (`none` у всех
   девяти измеренных), зебра — слабо положительный приём (значимо лучше в 3 вопросах из 8 на 2276 сессиях).
7. **Карточка в админке — граница 1 px без тени** (у Primer 0 из 62 карточек с тенью); двух-трёхслойная тень
   начинается с меню, поповера и модалки по модели «кольцо 1 px + key + ambient».
8. **Оверлеи в числах**: модалка 400 / 520–640 / 800–960 с padding 24, тост 356 с временем жизни 4 с,
   тултип 4–8 × 8–12 с `max-width` 160–250, меню `min-width` 160 с пунктом 32.
9. **Состояния**: hover ΔL 2–6 п.п. (альфа 4–5 %), active 5–9 п.п. (8 %), selected заметнее hover и
   продублирован вторым признаком, фокус — `outline` 2 px с offset 2 и контрастом ≥ 3:1.
10. **Контраст проверен расчётом**: текст бейджа берётся шагом 700 (зелёный и янтарный 600 не проходят
    4.5:1), белый текст на green-600 и amber-600 тоже не проходит, точка-статус требует шага 600.

## Как пользоваться

1. Нужен конкретный компонент — открой тематический файл и возьми блок «спецификация по умолчанию»
   (плотная админка или клиентский сервис): оттуда пишется CSS без догадок.
2. Нужно сравнить системы или выбрать базу — `08-values-by-system-table.md`.
3. Нужны состояния — `07-states-matrix.md`, там же псевдокод проверок.
4. Термин непонятен — `glossary.md`.
5. Значения шкал (отступы, высоты, радиусы, тени, типографика, цвет) не дублируются здесь: они лежат в
   `../01-color/`, `../02-typography/`, `../03-spacing-sizing/`, `../04-shape-elevation/`, и в файлах папки
   на них стоят ссылки.
