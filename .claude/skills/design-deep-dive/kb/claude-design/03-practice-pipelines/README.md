Выжимка:
- Claude Design у практиков — этап исследования и макета; источник правды — код и DS в репозитории; самое слабое звено — перенос в стек
  (агент кода переписывает, теряет детали) и handoff (качать полный ZIP, не кнопку). `[консенсус]`
- Качество держится на входе: DS (лучше из фронтенд-репо), референсы-скриншоты, бриф, ICP; варианты — явно, по 3; мелочи — комментариями.
- Дом-стиль модели в CD узнают до сих пор (бежевый фон, серифы, курсив-акцент, «01/02/03», капс над заголовком); собственный анти-слоп
  список CD его не запрещает — запреты давать самим. `[консенсус]` `[исходник: снимок промта 21.08]`
- Свой недельный лимит CD был до ≈ 19–28.05.2026, потом общий; CD дорогой — доводить в нём до «достаточно хорошо», дальше Claude Code.
- CD нет ни на одной арене; Opus 5.5 внутри CD практиками не описан; прямое сравнение CD против Claude Code + `frontend-design` — тест 1.
- «CD из чата Claude Code» официально — только `/design` и инструмент `ClaudeDesign` (B); сторонние мосты — браузер или чужой токен, не
  брать; рабочая замена — HTML-холсты вариантов в Claude Code + наши базы + метки элементов для правок (§10).
