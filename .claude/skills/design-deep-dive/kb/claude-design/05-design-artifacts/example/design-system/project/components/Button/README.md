# Button

Кнопка действия: основная для главного действия «Записаться» и вторичная для перехода рядом.

- **Варианты**: `btn btn-primary` — фон `color-accent`, текст `color-on-accent`; `btn btn-secondary` — контур и текст `color-text`,
  при наведении — `color-accent`.
- **Размер**: высота `control-h` (48px), отступы `space-5`, радиус `radius-sm`, текст — стиль `strong`.
- **Что даёт потребитель**: текст-результат нажатия в инфинитиве («Записаться на ТО»), `href` для перехода или `type` для формы.
- **Правила**: в одной группе одна основная и не больше одной вторичной; кнопку отправки не блокировать; на телефоне в первом
  экране кнопки растягиваются на всю ширину. Ссылка, оформленная кнопкой, остаётся `<a href>`.
