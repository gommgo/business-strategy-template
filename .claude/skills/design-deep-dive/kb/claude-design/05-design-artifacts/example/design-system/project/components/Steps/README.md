# Steps

Пронумерованные шаги «Как это работает» на тёмной полосе: только для настоящей последовательности действий.

- **Разметка**: секция `.band` → `.section-head` (`h2` + подводка) → `<ol class="steps">` из трёх `.step` (`h3` + `p`) → кнопка
  `btn-primary` с действием («Выбрать время»).
- **Вид**: фон `color-band`, текст `color-band-text`, вторичный текст и верхняя линия шага — `color-band-muted`; номер шага —
  Unbounded 700, 28px; колонки через `space-6`.
- **Что даёт потребитель**: 3 шага, каждый — глагол действия клиента в заголовке и одно предложение, что происходит.
- **Правила**: номера — счётчик списка, не декоративные «01/02/03» над заголовками; на телефоне шаги идут столбиком.
