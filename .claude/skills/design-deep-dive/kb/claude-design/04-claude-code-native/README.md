## Выжимка

1. Ни один путь Claude Code не вызывает серверного агента Claude Design; у заказчика `/design` в режиме consent. «Claude Design в чате» —
   это та же модель сессии + холст из HTML-файлов + скриншоты с номерами `#N` + проверки.
2. Из 35 функций Claude Design в чате сейчас работают 26, 3 — с оговоркой, 2 — только после `/design` (живой промт, редактор мышью),
   4 — невозможны без интерфейса (Google Slides напрямую, живая совместная правка, панель ДС, «request tweaks»).
3. Инлайн-комментарий заменён номером: заказчик пишет «#22: высота ≥ 44 · #16: текст «…» → «…» · Keep», Claude правит и доказывает
   `diffshots`, что изменилось только названное.
4. Прототип `kit/` проверен: номера едины на всех ширинах и темах и переживают итерации; бейджи не закрывают текст; правильный пакет правок —
   0 неожиданных изменений, 3 непрошеные правки пойманы 3 из 3; «ручки» — `--set` без правки файлов; экспорт PDF, PNG 2×, standalone, zip.
5. Смотреть — во встроенном браузере десктоп-приложения (`standalone.html?marks=1` или `shot.py serve`); артефакт — только с разрешения.
6. Теряем правку мышью «без токенов» и живой промт Claude Design; выигрываем глаза модели, версии в git, проверяемую локальность, код без
   handoff. Качество против Claude Design и K3 — тесты T-D6, T-D7.
