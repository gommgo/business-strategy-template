## Как работать в чате Claude Code: рабочий цикл

Основной путь сейчас (схема А базы B, доведённая D до цикла правок). Кто делает: **Claude** — всё, кроме вкуса и решений; **заказчик** —
ответы на вопросы, выбор направления, правки по номерам, «Keep», приёмка.

```
0 сессия      Claude Code (десктоп), модель Opus 5.5, effort xhigh на ДС и первый hi-fi; git в проекте; «Help Improve our AI models» — выкл.
1 бриф        brief.yaml (kimi 07) + ≤ 7 вопросов одним сообщением (факты свободно; выбор 2–4 варианта с умолчанием)
2 ДС          DESIGN.md + tokens.css (шаблоны kimi 07; из репо, бренда или сайта) → артборд-образец → снимок → «Keep»
3 направления 2–4 low-fi артборда по названным осям (фон hex / акцент hex / гарнитура + мотивация и компромисс) → выбор или ремикс
4 вайрфрейм   серые блоки, без цвета и картинок → структура принята
5 hi-fi       артборды 1440 и 390 (+ тёмная тема, если есть) на токенах; frontend-design + нормы ui / ux / site / text
6 правки      снимок с метками → «#N: …» от заказчика → эхо Claude → правка → diffshots (0 неожиданных) → «было → стало» → Keep
7 ревью       ui_audit.py + 34 маркера ui 11/04 + приметы дом-стиля Claude + рубрика ui 13/02 + аудит свежим контекстом
8 экспорт     export.py: PDF (страница на артборд), PNG 2×, standalone.html, zip; артефакт claude.ai — только с разрешения
9 код         та же сессия: компоненты и тема из tokens.css в стеке → снимки сборки теми же ширинами → сверка с макетом
```

Команды (`04-claude-code-native/` §6.2; браузер — headless, под общей блокировкой и при свободной памяти ≥ 2 ГБ):

```bash
K=04-claude-code-native/kit; P=design; L=/home/mm/Документы/app-design/.locks/browser.lock
flock $L python3 $K/shot.py $P review/iter-01 --tiles --iteration iter-01 --min-free-gb 2           # кадры с метками, холст, marks.json
flock $L python3 $K/shot.py $P review/iter-02 --tiles --prev review/iter-01/marks.json --min-free-gb 2
python3 $K/diffshots.py review/iter-01 review/iter-02 --expect 16,22,37,38 --strict                  # код 0 = ничего лишнего не изменилось
flock $L python3 $K/shot.py $P review/try --set "color-accent=#0B6E4F;radius-md=4px"                  # «ручки»: предпросмотр без правки файлов
flock $L python3 $K/export.py all $P export --min-free-gb 2                                          # PDF, PNG 2×, standalone, zip
python3 $K/shot.py serve $P --port 8765                                                              # живой холст для встроенного браузера
```

**Как заказчик даёт правки из чата** (грамматика — D §2.3): `#22: высота ≥ 44 · #16: текст «Посмотреть услуги» → «Услуги и цены» ·
#37: добавить ссылку «Как добраться» перед #38 · Keep`. Широкие правки: «все кнопки: …», «токен --color-accent: …», «везде: углы 8».
Предпросмотр без правки: «покажи #29 с space-section=120». В пакете ≤ 7 пунктов; всё не названное не трогать. Номера живут между
итерациями и одинаковы на всех ширинах и темах. **Где смотреть**: встроенный браузер десктоп-приложения (`standalone.html?marks=1`
или `shot.py serve`); PNG — для точных ссылок и для глаз Claude.

    прогресс — W = 3·critical + major падает. → D §2.5, kimi 08/01 `[практика]`
19. **Проверяй и глазами, и числами.** Глаза поймали бейджи на подписях, когда счётчик показывал 0. `ui_audit.py` поймал контраст 2,55:1,
    который глаза пропустили. → D §6.3 `[проверено]`
20. **Приёмка — по экспорту и сборке своими кадрами**, а не по холсту и не по отчёту модели «совпадает на 100 %». → C §8, V SUMMARY §2
    `[консенсус]`
