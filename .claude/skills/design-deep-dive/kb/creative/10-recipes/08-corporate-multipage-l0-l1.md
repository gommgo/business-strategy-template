## Выжимка для агента

1. **Уровни по шаблонам, а не «сайт L1»**: главная и «о компании» — L1, услуги, проекты-список, документы, контакты — L0 (A `defaults_by_page_type`). `[практика: A, site]` → §1
2. **«Вау» — на маленькой отдельной промо-странице** (запуск, юбилей, проект), не на всём корпорате: «огромный корпорат… погибнете, согласовывая». `[V:ilNOMaR6x_U 23:48] [мнение]` → §8
3. **Единство системы важнее эффектов**: одна сетка, одна пара гарнитур, один язык фото, одни токены движения на 15 шаблонах. `[практика: D 03]` → §2
4. **Переход между страницами — кросс-документный VT «общая ось»** (old 90 мс fade + сдвиг 300 мс, new 210 мс с задержкой 90) внутри `no-preference`. `[V:UcXWY057YuQ 12:33] [документация]` → §5
5. **Повторяемость: переход ≤ 300 мс** — на многостраничнике он повторяется десятки раз (правило частоты ui 08/02 здесь верно). `[практика: E 05/02 §8.3]` → §5
6. **Фото проектов — реальные** (объекты заказчика); раскрытие маской `effect:mask-reveal` одно на секцию проектов главной. `[практика]` → §5
7. **Шапка и навигация — конвенции** (логотип слева → главная, меню, поиск по документам); анимация шапки — только сжатие при прокрутке. `[консенсус: CRV-AL-11]` → §4
8. **Цифры компании — `stat-strip` без счётчиков**, с датой и источником. `[практика: text]` → §4
9. **Для Битрикса — один бандл подачи** через `Asset::addString(<script type=module>)`; композитный кэш и объединение JS проверить. `[документация: G 02 §10]` → §6

## 1. Бриф и уровень

`site_type: corporate-site`; главная `home-multipage` — L1; внутренние (`service-page`, `case-list-page`, `documents-page`,
`contacts-page`, `careers-page`) — L0; промо-страница кампании — отдельный рецепт 04/03 на `static`. Трафик — прямой, поиск по
бренду, тендерные площадки; аудитория — закупщики и инженеры (часто 45+ → L0 по Reinecke 2013, A).

## 2. Концепция

- **Тезис** (образец для «Сталькона» — металлоконструкции): «Сварной шов вместо рекламы: каждая страница собрана из одних узлов —
  фото объекта, цифра проекта, чертёжная сетка; движение только там, где показывает монтаж».
- **Система** (D 03 «единство многостраничника»): сетка 12 колонок, `--space-section-m`, пара Golos Text + Onest, фото — репортаж с
  объектов, один акцент (сигнальный), радиус 0.

## 3. Мудборд

| Роль | Что | Взять | Не брать |
|---|---|---|---|
| composition | годовые отчёты промышленных компаний | таблицы объектов, фото с подписями | «инфографику» с иконками-клипартом |
| material | репортаж монтажа | реальные объекты, люди в СИЗ (с согласием) | стоковые каски и рукопожатия |
| motion | W1: VT «общая ось», `:only-child` шапки | переход ≤ 300 мс | переходы-шоу на каждой странице |

## 5. Подача

| Где | Класс | Что | Reduce |
|---|---|---|---|
| переход страниц | transition | `@view-transition { navigation: auto }`; root: old fade 90 мс + slide 300 мс −30 px, new fade 210 мс (задержка 90) + slide 300 мс; шапка — `view-transition-name: header` (общий элемент) | мгновенно |
| hero, case-studies | one-shot | `clip-path: inset(0 0 100% 0) → inset(0)` 700 мс, `out-expo`, один раз | конечное |
| header | scroll-linked | высота 72 → 56 px через `transform: scale` содержимого, не `height` | без сжатия |

## 6. Эффекты, стек, платформы

- Эффекты: `effect:page-transition` (нативный кросс-документный VT — L1 по `effects.yaml` v0.3, ≤ 400 мс; у рецепта — 300 мс; X-62), `effect:mask-reveal`,
  `effect:header-shrink-on-scroll` (F2), `effect:scroll-reveal-system` — нет (появлений секций нет).
- Стек: Astro 7 / static или CMS заказчика; JS подачи ≤ 5 КБ; VT — CSS.
- **1С-Битрикс**: CSS шаблона сайта; скрипт подачи — один файл `SITE_TEMPLATE_PATH/dist/fx.js` через `Asset::addString`; VT — правило
  в CSS шаблона; композитный кэш не должен кэшировать `html.js`. **WordPress**: `wp_enqueue_script_module` (6.5+). **Тильда** — рецепт 09.

## 7. Бюджет и ворота

Главная L1: первый экран ≤ 2,0 / 3,5 МБ, JS ≤ 100 КБ (реально ≤ 5); внутренние L0: ≤ 1,5 / 2,5 МБ, JS ≤ 20 КБ. Ворота на каждом
шаблоне: EG-PERF-07/09, EG-A11Y-10 (reduce), EG-FB-01…03; переход — вручную: Firefox (VT нет) навигирует обычно, reduce — без анимации.

## 8. Промо-страница «вау» внутри корпората

Отдельный URL (`/85-let`, `/most-2027`), `landing-campaign` L2 по рецепту 04 или 03, своя вёрстка на `static`, ссылка из новостей и
главной; согласуется одна страница, а не сайт (W3). После кампании — 301 на актуальную страницу (site 02 §5).

## 9. Решения о клише

| id | Приём | Решение | Почему |
|---|---|---|---|
| d-fade | `cliche:section-fade-up` | avoid | на 15 шаблонах появления секций нет; маска — только у фото проектов |
| d-parallax | `cliche:parallax-everything` | avoid | параллакса нет; движение показывает только монтаж и переход |
| d-dark-pause | `cliche:dark-pause-section` | avoid | ритм — фото объектов на всю ширину, а не тёмные «паузы» |

## Частые ошибки

1. Разный стиль на страницах разных подрядчиков — сайт «скачет» (W3: «без скачущих стилей со страницы на страницу»).
2. Переход страниц 700 мс с «шторкой» — повторяется при каждом клике по меню.
3. «Вау» на главной корпората с формой тендерной заявки — конверсия L0.
4. Несколько `addJs` с GSAP и плагинами в Битриксе — порядок не гарантирован.
5. Анимация высоты шапки (`height`) — раскладка в движении (MKT-M2).
