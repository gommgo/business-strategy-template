## Выжимка для агента

1. **Экран приложения — HTML в своей рамке-форме, не картинка телефона**: состояния переключаются по кнопкам и прокрутке. `[практика]` → §5
2. **Смена состояний экрана — same-document View Transition** (`document.startViewTransition`) с запасом без API; reduce — мгновенно. `[документация: G 02 §2.1]` → §6
3. **Фирменный приём один: «нажми — экран ответит»** — 3–4 состояния (пусто → ввод → результат → уведомление). `[практика: E]` → §2
4. **Кнопки App Store, Google Play, RuStore, AppGallery — официальные значки SVG**, одинаковой высоты (B3). `[практика: site 02 §8]` → §4
5. **Мокап без рамки устройства** или со своей простой формой: рамка iPhone — `cliche:dashboard-in-browser-frame` для телефона. `[практика: H]` → §9
6. **Пружина — только у отклика кнопки внутри экрана** (перелёт ≤ 4 %), страница — без пружин. `[практика: E 05/01 §7.3]` → §5
7. **Отзывы — рейтинг магазина с датой**, не сгенерированные карточки. `[практика: text]` → §7
8. **Форма не нужна** — кнопки магазинов и QR на десктопе; секции конверсии L0. `[практика: site 02 §8]` → §4

## 2. Концепция

- **Тезис** (образец для приложения записи к врачу): «Экран, который отвечает: вы нажимаете — интерфейс показывает, что будет
  дальше, раньше, чем вы успеете спросить».
- **Направления**: «Отклик» (выбран: средне-серая бумага, скруглённый гротеск, холодный акцент), «Карточка пациента» (бумага, антиква),

## 5. Подача

| Где | Класс | Что | Reduce | Телефон |
|---|---|---|---|---|

## 6. Эффекты, стек, код

- Эффекты: `effect:view-transition`, `effect:hero-entrance-once`, `effect:button-expand-label` (F2), `effect:tilt-card` — нет (телефон).
- Стек: CSS + ≈ 2 КБ JS (переключатель состояний); VT — нативно; без API — смена класса без анимации.

```js
/* Chrome 153 · WebKit 26.6 · 2026-09-25 · [не проверено: пример не собран] смена состояния экрана с запасом */
function show(state) {
  const swap = () => { screen.dataset.state = state; };
  if (!document.startViewTransition || matchMedia('(prefers-reduced-motion: reduce)').matches) return swap();
  document.startViewTransition(swap);
}
```

EG-A11Y-13/14 (фокус внутри экрана-демо), EG-MOB-01 (переполнение), B3 marketing_audit (одна высота значков магазинов).

## Частые ошибки

1. PNG телефона в рамке с «парением» — почерк генератора и 300 КБ картинки вместо живого экрана.
2. Демо только по наведению — на телефоне не работает.
3. Разные высоты значков магазинов и «Скачать» вместо официальных значков.
4. Отзывы-карточки без даты и источника.
