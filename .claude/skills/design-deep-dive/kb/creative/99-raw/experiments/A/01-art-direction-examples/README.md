# A/01 (+ A/02 для паспорта) — процедура «бриф → концепция → направления → выбор» на пяти брифах до art-direction.json

- **Цель:** пройти процедуру `01-concept-and-directions.md` на пяти брифах без генерации и проверить, что документ
  `art-direction` заполняется, различает направления по осям, питает паспорт визуала ai-media и не противоречит уровням.
- **Брифы:** «Кварц» (предзаказ лампы, kimi F/03 + факты text `facts-kvarts.yaml`), «Лесная обжарка» дважды — L0 и L2 (демо
  ai-media 14 + смысл text `meaning-lesnaya-obzharka.yaml`), «Окошко» (SaaS, демо site E/03 + факты text E), «Отвес»
  (лидогенерация услуг, бриф site A + факты text B2). Факты — только из файлов сестёр; всё неподтверждённое — `missing:`.
- **Выход:** `01-creative-direction/examples/art-direction-{kvarts,forest-roast-l0,forest-roast-l2,okoshko,otves}.json`.
- **Команда:** `99-raw/tools/venv-A/bin/python ../../scripts/creative/ad_check.py` → `out/report.json`.
- **Версии:** Python 3.13.5, jsonschema 4.26.0, referencing 0.37.0; схемы: art-direction v0 (наша), visual-dna v0.1 (ai-media),
  treatment v0 (наша, списки эффектов по уровням), словарь site r2 (макроструктуры); контраст — `../../scripts/lib/color.py` (WCAG 2).
- **Результат (2026-09-24 ≈ 15:35):** 5 из 5 примеров — 0 ошибок схемы, 0 ошибок подсхем паспорта визуала (character,
  forbidden_hues, exclusions, abstract, video, composition, subject_matter, materials), 0 нарушений правил, 0 предупреждений
  (одно предупреждение «--allow warm без решения» в L2 закрыто решением d-warm-field); 14 отрицательных случаев пойманы
  (похожие направления, две антиквы, «use» с проваленным критерием, утверждение без подписи, плавная прокрутка на L1,
  boldness не по уровню, контраст 2,46, чужая макроструктура, два буквальных прочтения, выбор несуществующего направления,
  3D-сцена на L1, два направления вместо ≥ 3, профиль бюджета не по типу, тезис длиннее 240 знаков).
- **Сравнение «Лесная обжарка» L0 ↔ L2** (тот же бренд, та же территория «утренний стол»):

| Поле | L0 | L2 |
|---|---|---|
| профиль | landing-product@L0 | landing-campaign@L2 |
| boldness (паспорт) | restrained | bold |
| направление | «Утренний стол»: один широкий кадр | «Утро по минутам»: сюжет прокрутки из 5 глав |
| макроструктура | photographic | scroll-story |
| стратегия цвета | restrained | committed (финал — заливка лесным зелёным) |
| движение (kimi) | subtle: синемаграф пара, стоп через 5 с | cinematic: скраб секвенции + банка к финалу |
| плавная прокрутка | нет | да (Lenis, при reduce выключена) |
| бюджет эффектов, десктоп | ≈ 90 КБ | ≈ 4,3 МБ (секвенция 3,5 МБ после LCP) |

- **Выводы:** (1) процедура даёт различимые направления только при явных осях: без таблицы осей два из четырёх направлений
  «Кварца» совпадали бы по бумаге и шрифту; (2) буквальное прочтение имени («Отвес», «Кварц», «Окошко», «Лес») появляется в
  каждом брифе — правило «≤ 1 кандидат» нужно в процедуре явно; (3) бренд-акцент на краю «ИИ-полосы» (ультрамарин «Кварца»
  268°) — повод записать полосу в exclusions с причиной, а не запрещать цвет; (4) уровень L2 для того же бренда меняет
  макроструктуру, стратегию цвета и бюджет в ≈ 50 раз, а не палитру — бренд узнаётся по территории и цвету;
  (5) model-viewer 240 КБ br превышает потолок JS 3D L1 (200 КБ) — нужен механизм budget.overrides с подписью, он работает.
- **Не проверено:** качество направлений глазами (генерации нет) — строка «Что проверить в живой фазе» отчёта A.
