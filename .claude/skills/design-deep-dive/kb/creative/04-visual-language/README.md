Выжимка:
1. Display 30–160 px — пять ролей размера (`display-s…xl`, `poster`) на clamp; у текста max ≤ 2,5 × min (WCAG 1.4.4, проверено зумом).
2. Роль выбирается по длине H1 и колонке: `font_max = строк × W / (знаков × k)`; H1 ≤ 2 строк при 1440 и ≤ 4 при 390.
3. Кириллица шире латиницы (×1,14), капс с Ё/Й/Д/Ц/Щ требует интерлиньяжа 1,05–1,25, трекинг не туже «уха» (медиана −0,02 em).
4. Гарнитуры — из YAML: латинские display-дефолты без кириллицы, Oswald/Inter/Manrope — нельзя.
5. Метрический фолбэк по русскому тексту даёт CLS 0 при подмене шрифта.
6. Hero: `text_media` из treatment, высота по политике site (`offer-cta` 60–85svh, `poster` 100svh), телефон — свой кадр.
7. Секции — «этажи» 64–160 px, инверсий ≤ 2, стыки градиентом, прозрачная шапка только над hero.
8. Цвет по уровню: L0 ≤ 2 хроматических, L1 ≤ 3, L2 ≤ 4; эффектные сайты держат 0–1 в первом экране.
9. Градиент — с фолбэк-цветом, контрастом в худшей точке и forced-colors; стекло и зерно — бюджет и фактура, не декор.
10. Продукт — настоящим UI; рамки не перерисовывать; многостраничник — одна система токенов.
