## Выжимка (10 строк)

1. Раздел 0 — первым: станция, ворота, craft, роль, уровень, профиль, якорь, хвост, появление, стекло — по два-четыре смысла.
2. Числа 1 / 2 / 3 — три разные величины: петли в видимой зоне, насыщенные приёмы на страницу, пики и акценты (X-19, X-20).
3. SDA — только CSS или WAAPI с `animation-timeline`; сцена ScrollTrigger — «движение по прокрутке» (X-01).
4. Перехват прокрутки — любое изменение скорости или направления, включая виртуальную прокрутку; pin со скрабом — нет (X-15).
5. Между страницами — `effect:page-transition` (нативный — L1, библиотеки — L2), внутри страницы — `effect:view-transition` (X-62).
6. craft рубрики K — меньшая из двух подоценок: типографика и композиция и (при 3D, видео, фото-hero) ремесло медиа (X-63).
7. `effect_role` (эффект) ≠ `visual_role` (секция в ритме) ≠ `section_role` site (вопрос посетителя) (X-54).
8. Id не переводить: `effect:<id>`, `cliche:<id>`, `block:<id>`, `EG-…`, `MKT-…`.
9. Число в статье — ориентир; канон — YAML, токены и схемы; при расхождении действует `CONTRADICTIONS.md`.
10. «Где в базе» — раздел на дату сборки; после правки заголовков файлов — пересобрать (ниже).

## Как пользоваться и как добавлять

- Поиск — `grep -n "<термин>" 00-glossary/glossary.md` (по-русски или по-английски); в группе статьи идут по алфавиту.
- Новая статья — строкой в `99-raw/experiments/S2/01-synthesis-tools/gl*.tsv` (группа, термин, EN, определение в 1–2 строки с
  числом или условием, файл, `§N.M`), затем пересборка по README опыта и `python3 ../../scripts/maint/check_links.py` (0 ERROR); без
  пересборки — строка в таблицу группы вручную в том же формате.
- Два определения одного слова — строка раздела 0 (смыслы и выбор базы) и пункт `CONTRADICTIONS.md`; термин тройки (общий с
  site и text) — через сверку тройки, их глоссарии: `../site/00-glossary/glossary.md`, `../text/00-glossary/glossary.md`.
