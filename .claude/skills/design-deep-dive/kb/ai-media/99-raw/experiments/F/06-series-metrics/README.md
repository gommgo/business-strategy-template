# F/06 — согласованность серии без платного судьи и нарезка сетки 2×2 (судья тестов фазы 5 F-01, F-02)

Агент F, волна 2, 23.09.2026. Python 3.13, numpy, Pillow; палитра и OKLab — `../../../../../../scripts/ai-media/palette.py`. Бесплатно.

**Цель.** Дать числа, которыми фаза 5 сравнивает серии (F-01 A/B/C, сетка F-02), и откалибровать пороги на наборах с
известным ответом: «одна съёмка» против «разные локации».

**Команды.** `python3 series_metrics.py IMG… [--ref REF…]`; `python3 split_grid.py GRID.png OUTDIR 2 2`.
Калибровка — блок в журнале опыта; числа — `results.json`.

**Метрики набора.** `sd_L`, `sd_C` — разброс средней светлоты и медианной хромы (OKLab); `hue_spread_deg` — круговой разброс
среднего оттенка хроматических пикселей; `sd_b_neutral` — разброс b нейтралей (баланс белого); `pal_dE_mean/max` —
попарная симметричная дистанция палитр k = 5; `phash_min/mean` — Хэмминг pHash (дубли < 10 из 64); `dE_to_ref` — ΔE палитры
каждой картинки к палитре эталона.

**Результат (калибровка).**

| Набор | sd_L | sd_C | разброс оттенка | ΔE палитр средн / макс | pHash мин |
|---|---|---|---|---|---|
| одна съёмка (autumn_park ×3) | 0,032 | 0,002 | **5,7°** | **0,038** / 0,044 | 19 |
| две локации (пляж ×2 + площадь ×2) | 0,036 | 0,007 | 27,8° | 0,048 / 0,064 | 22 |

`dE_to_ref` для четырёх локаций к палитре тройки autumn: 0,006 (кадр из той же съёмки) против 0,071–0,115 у остальных.
Сетка 2×2 из 4 кадров 800×533: с белыми желобами 16 px и без желобов — 4 ячейки ровно 800×533 (желоб ищется как полоса
с σ < 4 из 255, иначе равное деление; ложные «ровные» полосы внутри кадра отсеяны).

**Вывод для правил** (`06-art-direction-consistency/02-series-and-consistency.md`): «одна серия» — разброс оттенка ≤ 10°,
ΔE палитр ≤ 0,045 средн (≤ 0,06 макс), sd_L ≤ 0,04, sd_C ≤ 0,005; признак распада серии — оттенок > 25° или ΔE палитр > 0,06;
pHash < 10 — дубль сюжета. Пороги — по фото одной съёмки; для иллюстраций (плоские заливки) ΔE палитр ниже, порог
калибровать на эталоне паспорта. Метрики цвета не видят стиль (свет, линию, обработку) — вторым судьёй остаются
голоса и VLM-вопросы (`F-src-series.md`: CSD ρ 0,565 с людьми, pHash и ΔE людьми не проверялись).
