# F/05 — палитра, ΔE к эталону, перенос цвета и LUT: что годится для гармонизации ассетов бренда

Агент F, волна 2, 23.09.2026. Python 3.13, numpy, Pillow; ffmpeg 7.1.5 (`lut3d`, tetrahedral; libx264). Бесплатно.

**Цель.** Проверить, как довести цвет ИИ-ассетов до паспорта бренда: снять палитру и ΔE, перенести цвет с эталона
(Reinhard, MKL), выразить грейд одним 3D LUT для картинок и видео.

**Данные.** «Эталон бренда» — три CC0-кадра autumn_park (одна съёмка); цели — площадь Сан-Марко, пасмурный пляж,
интерьер кафе (CC0 Poly Haven, `../01-materials/cc0/`).

**Команды.** `python3 run_color.py` (палитры, перенос, LUT → ffmpeg для картинки и видео); проверка «только грейда» и
параметрического LUT — блоки в журнале опыта ниже; библиотека `palette.py`: `palette`, `adherence`, `transfer_reinhard`,
`mkl_params`/`apply_mkl`, `grade_params`/`grade_match`, `parametric_grade`, `write_cube`.

**Результат.**
1. Палитра эталона (k = 6, OKLab, доли): #635020 0,26; #7b6a31 0,25; #473816 0,19; #99884e 0,14; #251f0d 0,12; #a1cced 0,05.
2. Полный перенос статистики снижает ΔE палитры к эталону (средняя по площади дистанция до ближайшего цвета, OKLab):
   площадь 0,117 → **0,027** (Reinhard) / 0,029 (MKL); пляж 0,082 → 0,040; кафе 0,069 → 0,037–0,046. **Но глазами — брак**
   (`contact_transfer.jpg`): белая площадь стала горчичной, пасмурное море получило оранжевый «закат». Эталон — листва и
   трава, глобальный перенос тащит содержание чужой сцены. ΔE к палитре эталона другой сцены — **ложная цель**.
3. «Только грейд» по эталону (перцентили светлоты, масштаб хромы, баланс белого нейтралей): оттенки сохранены, но
   кривая светлоты чужой сцены затемнила площадь и дала постеризацию неба (`contact_grade_only.jpg`) — распределение
   светлоты тоже зависит от содержания.
4. **Параметрический грейд из паспорта** (`parametric_grade`: сдвиг a/b нейтралей (0,002; 0,010), хрома × 0,88, чёрный
   0,035, белый 0,975, S-кривая 0,12) → `brand_warm_consumer.cube` (33³) → ffmpeg: b нейтралей площади −0,005 → +0,004,
   пляжа 0,000 → +0,005; p99 светлоты 1,00 → 0,974; содержание сцен не тронуто, вид единый и мягкий
   (`contact_parametric_lut.jpg`).
5. LUT 33³ через ffmpeg `lut3d` против расчёта в Python: ΔE OKLab средн **0,002**, p99 0,004 (макс 0,06 — единичные
   пиксели у границ решётки). Тот же LUT на видео (H.264 4:2:0, crf 14) против картинки: средн **0,012**, p99 0,042 —
   одна цепочка грейда для картинок и роликов работает [V:I9xdmNZxIfA 16:34–17:36].

**Вывод для правил** (`06-art-direction-consistency/04-slop-and-color-harmony.md`): грейд бренда — явные числа паспорта →
один `.cube` на все ассеты (картинки и видео); перенос цвета с эталона — только внутри одного класса сюжетов (фото той же
съёмки, кадры одной серии, последний кадр → первый кадр видео), с силой ≤ 0,6; ΔE палитры к паспорту считать для
строгих цветов на объектах (`applies_to`) и для плоских иллюстраций, а не для фото разных сцен; для фото мерить баланс
белого нейтралей, медиану хромы и перцентили светлоты против паспорта по классу сюжета.

**Ограничения.** Эталон — одна съёмка; перенос — глобальный (без сегментации); параметры грейда подобраны на глаз
одним проходом, не с заказчиком.
