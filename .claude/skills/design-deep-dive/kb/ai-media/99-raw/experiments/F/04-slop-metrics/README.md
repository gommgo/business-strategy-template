# F/04 — маркеры «среднего вида» и «Instagram-фильтра» кодом (судья теста фазы 5 F-04)

Агент F, волна 2, 23.09.2026. Python 3.13, numpy, scipy, Pillow; цветовые метрики — `../../../../../../scripts/ai-media/image_metrics.py`.

**Цель.** Сделать измеримыми маркеры IMG-M09 (строго по центру, симметрия), «нет места под текст», перегруженность
(«≤ 3 элементов», W2-12) и «эффект Instagram-фильтра» [V:KLDdXOw6jIc 34:38] и проверить, что метрики реагируют на
известные изменения.

**Команды.** `python3 composition_metrics.py IMG…` (JSON-строки); `python3 validate.py` (контроль).

**Метрики** (`composition_metrics.py`): `centroid_x/y` — центр масс карты значимости spectral residual (Hou & Zhang 2007);
`center_offset` = |x − 0,5|; `mirror_sym` — корреляция левой половины с отражённой правой; `empty_share` — доля клеток сетки
16×9 с плотностью краёв ≤ 0,06; `zone_edge` — плотность краёв в зоне текста; `blobs` — связные пятна значимости > 0,5·max;
плюс `colorfulness`, `hdr_index`, `warm_b`, `purple_share`, `lap_var` из A/04.

**Результат.**
- Положение объекта (рендер на ровном фоне 16:9 при x = 0,3 / 0,5 / 0,7): `centroid_x` = **0,302 / 0,501 / 0,693**;
  `mirror_sym` 0,94 только в центре; `blobs` = 1; `empty_share` 0,99.
- «Instagram-фильтр» (насыщенность ×1,6, локальный контраст +0,8, сглаживание + резкость, контраст ×1,15) на трёх
  CC0-фото: colorfulness **54→102, 22→49, 30→60**; hdr_index +0,12…+0,18 (0,58→0,75; 0,21→0,33; 0,37→0,51); lap_var ×4–6;
  спокойные зоны исчезают: empty_share **0,67→0,39** (пляж), 0,35→0,13 (кафе) — фильтр убивает место под текст.
- Глаз (`contact_filter_pairs.jpg`): правая колонка — узнаваемый «HDR»-слоп (кислотная листва, ореолы у крыш, хрустящий
  песок); левая — документальная съёмка.
- Оговорка: исходное autumn_park уже colorfulness 54 и hdr_index 0,58 (> Q3 лидеров 0,35) — яркая осень сама по себе;
  пороги ставить **относительно эталона бренда** (A/04), абсолютные — только как флаг «посмотреть глазом».

**Вывод для правил.** Судья F-04: `centroid_x` ≥ 0,62 (объект в правой трети), `zone_edge` в левых 45 % ≤ 0,06, `blobs` ≤ 3,
colorfulness и hdr_index не выше эталона бренда +20 % (без эталона — Q3 лидеров 54,5 и 0,35); прирост colorfulness > +50 %
при hdr_index > +0,1 к эталону = «Instagram-фильтр».
