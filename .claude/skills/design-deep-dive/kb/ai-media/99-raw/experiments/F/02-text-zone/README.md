# F/02 — контраст HTML-текста поверх фото: какой предсказатель зоны верен и сколько скрима нужно

Агент F, волна 2, 23.09.2026. Python 3.13, numpy, Pillow 11.3 (шрифт DejaVu Sans Bold). Бесплатно, локально.

**Цель.** Проверить, чем мерить контраст текста поверх картинки до вёрстки: средней яркостью зоны, 95-м перцентилем
или худшим пикселем — и какую альфу скрима (затемняющего слоя) брать.

**Данные.** 8 CC0-фото Poly Haven (`../01-materials/cc0/`, 960 px) × 4 зоны (левые 40 %, верхние 35 %, нижние 30 %,
центр 60 × 30 %) × 2 цвета текста (#ffffff, #111111) = 64 комбинации. «Истина» — фон под настоящими буквами: строка
«Заголовок сайта» (DejaVu Sans Bold, по ширине зоны) рендерится в зону, маска глифов раздувается на 2 px, берётся 5-й
перцентиль контраста WCAG 2 по пикселям под маской (`glyph_true`). Скрим — чёрный (под белый текст) или белый (под тёмный),
смешение в sRGB, как делает браузер.

**Команды.** `python3 run_batch.py` (≈ 1 мин), `python3 scrim_quantile.py` (≈ 2 мин); библиотека `text_zone.py`
(`zone_contrast`, `scrim_alpha`, `glyph_true`, `edge_density`, CLI `text_zone.py IMG x0 y0 x1 y1 #fff`).

**Результат.**

| Предсказатель зоны (порог 4,5:1) | Сказал «проходит» | Ложный пропуск (буквы не читаются) | Лишний скрим |
|---|---|---|---|
| средняя яркость зоны | 31 | **17** | 0 |
| p95 яркости (для тёмного текста — p5) | 5 | 0 | 9 |
| худший пиксель | 0 | 0 | 14 |

- Без скрима «по правде» проходят **14 из 64** комбинаций; белый текст — 0 из 32, тёмный — 16 %.
- Скрим, рассчитанный по квантилю зоны до 4,5:1: по p95 — буквы читаются в 50 из 64; **по p99 — 63 из 64; по p99,9 —
  64 из 64**, альфа медиана 0,46 (p90 0,53, максимум 0,54).
- Если цвет текста выбирать по зоне (светлый или тёмный — какой требует меньше скрима), медиана альфы падает с
  0,38–0,44 до **0,21**, без скрима обходятся 5 из 32 зон.
- Плотность краёв (доля пикселей с перепадом перцептивной яркости > 0,10): небо и ровные стены 0,001–0,06, листва,
  трава и архитектура 0,16–0,52.
- Глаз (`contact_scrim.jpg`): равномерная плашка α 0,48–0,53 даёт 4,7–4,9:1, но выглядит «серой коробкой» — годится как
  страховка, не как приём; сначала композиция (спокойная зона нужной светлоты), потом выбор цвета текста, потом
  градиентный скрим по полосе текста.

**Вывод для правил** (`06-art-direction-consistency/03-composition-for-web.md`): мерить по p99–p99,9 яркости полосы под
текстом (не по среднему — 17 ложных пропусков из 31); худший пиксель завышает скрим; цвет текста выбирать по зоне;
скрим — от альфы, найденной по p99,9, с растушёвкой; зона под текст — плотность краёв ≤ 0,06.

**Ограничения.** 8 фото, 1 шрифт и кегль; APCA не считался (WCAG 2); «истина» — геометрия под глифами, а не чтение
людьми; фото — документальные backplates, не ИИ-генерации (в фазе 5 то же на выходах F-04).

**Дополнение F2 (23.09.2026, 18:17) — формальная проверка WCAG F83 после скрима** (`python3 f83_check.py`, 38 с; числа —
`f83_check.json`). F83 шаг 1 (Quickcheck): контраст текста с самым светлым участком фона в полосе текста; шаг 2 — фон за
каждой буквой: строго — минимум под маской глифов, практично — p5 (как выше). Скрим считается по квантилю зоны или полосы
текста (рамка глифов + 8 px).

| Основа | Квантиль | Альфа медиана / p90 | p5 под буквами ≥ 4,5 | F83 шаг 2 строго | F83 Quickcheck по полосе |
|---|---|---|---|---|---|
| зона | p95 | 0,38 / 0,52 | 50/64 | 15/64 | 9/64 |
| зона | p99 | 0,43 / 0,52 | 63/64 | 25/64 | 19/64 |
| зона | p99,9 | 0,46 / 0,53 | 64/64 | 45/64 | 39/64 |
| зона | **p100** | **0,48 / 0,53** | 64/64 | **64/64** | **64/64** |
| полоса | p95 | 0,34 / 0,50 | 45/64 | 9/64 | 5/64 |
| полоса | p99 | 0,41 / 0,51 | 64/64 | 13/64 | 5/64 |
| полоса | p99,9 | 0,43 / 0,52 | 64/64 | 24/64 | 8/64 |
| полоса | **p100** | **0,46 / 0,53** | 64/64 | **64/64** | **64/64** |

Вывод F2: скрим по p99,9 даёт читаемые буквы (p5) во всех 64 случаях, но строгую проверку F83 проходит только в 45 (зона)
и 24 (полоса); скрим по худшему пикселю (p100) проходит F83 во всех 64 и стоит +0,02–0,03 альфы по медиане (p90 тот же 0,53).
Рабочее правило: альфу считать по p99,9 (устойчиво к одиночным пикселям), затем проверять F83; не прошло — поднять альфу до
значения p100. p95 не годится ни как предсказатель «без скрима», ни как основа скрима.
