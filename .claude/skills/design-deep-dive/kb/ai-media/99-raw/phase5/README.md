## Раскладка

```
99-raw/phase5/
  README.md                   ← этот файл
  <агент>-plan.md             ← план агента: таблица тестов (формат ниже)
  jobs/<агент>-<NN>-<имя>.json        ← одно задание polza.py
  jobs/<агент>-<NN>-<имя>.jsonl       ← серия заданий polza.py (одна строка — одна генерация)
  jobs/<агент>-<NN>-<имя>.<канал>.json ← задание вне Media API polza (routerai, genapi, polza-chat)
  inputs/<агент>/…            ← входные файлы тестов (CC0, свои рендеры, заглушки), LICENSES.md
  plan.md                     ← сводный план (пишет агент N в волне 3, утверждает заказчик)
```

`<NN>` — две цифры по порядку в плане агента; `<имя>` — латиница через дефис: `E-03-cyrillic-banner.jsonl`.

## Задание polza.py

Формат — `../../scripts/ai-media/README.md`, раздел «polza»; полный — `02-providers-platforms/01-polza-api.md` §12.

```json
{"model": "bytedance/seedance-1.5-pro",
 "input": {"prompt": "…", "images": ["../inputs/I/frame-A.png", "../inputs/I/frame-A.png"],
           "resolution": "480p", "duration": "4", "generate_audio": "false", "fixed_lens": "true"},
 "provider": {"only": ["mie"], "allow_fallbacks": false},
 "tag": "I-02-loop-AA", "agent": "I", "variant": 1, "max_rub": 6,
 "notes": "гипотеза одной строкой",
 "meta": {"test": "I-02", "inputs_from": {"images[0]": "E-01#1/0", "images[1]": "E-01#1/0"},
          "judge": "metric", "success": "seam_ratio ≤ 1,5; «живость» ≥ 50 % от I-01"}}
```

Правила:
1. **Ценовые параметры — явно** (`resolution`, `duration`, `image_resolution`, `mode`, `generate_audio`/`sound`,
   `aspect_ratio`): у 13 моделей запасная ступень цены = максимум (Seedance 2 «только промт» = 415 ₽). Звук — выключен.
2. `provider` — явно, с `"allow_fallbacks": false`, если цена или параметры зависят от провайдера.
3. `polza.py estimate <файл>` должен давать **0 ошибок**; сумму оценки — в план.
4. Входные картинки — локальные файлы в `inputs/<агент>/` (≤ 4 МБ: уходят base64), путь относительно файла задания.
   Если вход — выход другого теста фазы 5, положи **заглушку** того же соотношения сторон (CC0 или свой рендер) и
   укажи источник в `meta.inputs_from`: `"<тест>#<variant>/<индекс файла>"`. Оркестратор подставит настоящий файл.
5. `meta` — свободный объект (polza.py его не отправляет): `test`, `inputs_from`, `compare_with` (с какими тестами
   сравнивать), `judge` (`metric` | `vlm` | `votes` | сочетание), `success` (критерий), `seed_note`.
6. Серия (JSONL) — одна строка на генерацию; варианты различаются `variant` и `tag`.
7. Минимально различающий тест: одна модель на 1K / 480p, 1–2 повтора, дешёвые модели для перебора. Каждый рубль
   обоснован в плане.

## Задание вне Media API polza (`.routerai.json`, `.genapi.json`, `.polza-chat.json`)

Исполняет `../../scripts/ai-media/mp_client.py` (B2, волна 3; сухой прогон по умолчанию, бюджеты каналов по умолчанию 0). Задание — точный
запрос по документации канала плюс учёт денег:

```json
{"channel": "routerai",
 "method": "POST", "path": "/api/v1/…",
 "body": {"model": "recraft/…", "…": "…"},
 "tag": "G-04-recraft-icons", "agent": "G", "variant": 1,
 "max_rub": 30, "price_rub": 8.74,
 "price_source": "routerai.ru/api/v1/models, 23.09.2026 (99-raw/experiments/P/04-ru-aggregators/…)",
 "docs": "99-raw/cache/routerai.ru_docs_guides_overview_multimodal_image-generation_753f42c7.md",
 "notes": "гипотеза одной строкой",
 "meta": {"test": "G-04", "judge": "metric", "success": "…"}}
```

- `channel`: `routerai` (клон API OpenRouter), `genapi` (задача → опрос), `polza-chat` (текстовые и мультимодальные
  модели polza через OpenAI-совместимый `/api/v1/chat/completions` — LLM → SVG, VLM-судья).
- Поля `body` — строго по документации канала из кэша (`99-raw/cache/routerai.ru_*`, `gen-api.ru_*`,
  `99-raw/cache/polza/2026-09-23/docs-repo/`); если параметр не документирован (passthrough `style_id`, `controls`) —
  это и есть гипотеза теста, пометь в `notes`.
- Цена — по прайсу канала с датой; у `polza-chat` — оценка по токенам (формула в `notes`).

## План агента `<агент>-plan.md`

Первая строка — сумма по плану и минимальный набор (ценность 3). Таблица:

| № | Файл задания | Код задачи | Гипотеза | Что сравниваем | Генераций | ₽ (estimate) | Критерий успеха | Ценность 1–3 | Зависит от | Пересекается с |
|---|---|---|---|---|---|---|---|---|---|---|

- «Ценность»: 3 — без теста нельзя выбрать модель или маршрут; 2 — уточняет правило; 1 — любопытно.
- «Пересекается с» — тесты из отчётов волны 1 и трека W (`A-4`, `C1-5`, `W2-10` …) и других агентов волны: агент N
  сведёт дубли по этой колонке.
- После таблицы — «Как смотреть результат с заказчиком» (что показать, какие вопросы задать, 1–3 строки на тест).
