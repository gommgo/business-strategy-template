# 02 · Провайдеры и платформы

Папка отвечает на вопросы «откуда брать модели, как их вызывать, сколько стоит, как не потерять результат и деньги».
Разделы: **B** (волна 1) — polza как рабочая среда; **P** (волна 1) — другие агрегаторы, прямые API, сервисы, открытые
веса; **B2** (волна 3) — клиент каналов RouterAI, Gen-API, `polza-chat`, `polza-images`. Числа каталога — на 23.09.2026;
на **24.09.2026 медиа-моделей в polza 46 (24 картинки + 22 видео)**, API Sora 2 снят 24.09.2026; выжимки поправлены
аудитом X (`../CONTRADICTIONS.md` X16, X28, X30, X31). Какая модель под задачу — не здесь, а `../13-routing-matrix/routing.yaml`.
**Фаза 5 (25.09.2026)**: протокол T0–T9 и 261 медиа-генерация по трём каналам (polza 1 343,57 ₽, RouterAI 212,68 ₽, Gen-API 384 ₽;
журнал = балансам) — поправки в `01-polza-api.md` (§13, §14, выжимка) и `07-multichannel-client.md` (выжимка, §6); снимок
`2026-09-25_1411` — id Flare в polza сменился на `openai/gpt-image-2.5-flare`, медиа-моделей по-прежнему 46.

Выжимка B на 10 строк:
1. Генерация: `POST https://polza.ai/api/v1/media` с `"async": true` → опрос `GET /v1/media/{id}` (3–5 с картинки,
   5–10 с видео) → скачать сразу: результаты живут 7 дней.
2. Работать только через `polza.py`: проверка по каталогу, оценка цены, журнал `99-raw/experiments/_ledger.jsonl`,
   кэш, паспорт, лимиты; проверен на макете (30/30) [поправка фазы 5, 25.09.2026: и вживую — 205 генераций, журнал = `spentAmount`].
3. Параметры — из каталога этой модели и провайдера, не из OpenAPI и не по памяти; булевы видео — строками.
4. Ценовые параметры (разрешение, длительность, звук, режим) — всегда явно: запасная ступень у 13 моделей = максимум.
5. Seedance 2 «только промт» = 15 с со звуком = 415 ₽; Veo в polza — ролик 45/187,5 ₽ без выбора длительности.
6. Алиасы `model@provider` для медиа не работают; провайдер — объектом `provider` [поправка фазы 5, 25.09.2026: T5 — работает: NB2 Lite через Google AI
   Studio 4,06 ₽ против 2,90 у `mie`]; лишние поля polza принимает и **списывает** (T7), неверное значение — 400 без списания (T6).
7. `mie` (37 из 44 моделей снимка 23.09) ≈ KIE.ai; polza дороже KIE в 1,6–1,8 раза, курс долларовых провайдеров 117,992 ₽/$ =
   ×1,40 к ЦБ (+0,2 % за 23→24.09); Nano Banana Pro через Google flex на 41 % дешевле `mie` (если маршрутизация работает, T5).
8. Ни одна медиа-модель не отмечена как 152-ФЗ / данные в РФ — фото людей и клиентов без согласия не загружать.
9. Нативный прозрачный фон в Media API — только Qwen Image 2.1 (исследовательская лицензия → только черновики); финал —
   ровный фон + вырез или RouterAI GPT Image 2.5 `background` 1,45 ₽ (X28); негатив — только Wan 2.5; неподвижная камера —
   только Seedance 1.5 Pro (BytePlus её снял, в polza живёт через KIE «до поры»).
10. Первый живой вызов — план T0–T8 из `01-polza-api.md` §13 (≈ 16–29 ₽) [поправка фазы 5, 25.09.2026: выполнен за 20,76 ₽, всё сошлось с каталогом; обрыв POST
    — сначала `/v1/history/generations` (17 обрывов по трём каналам, двойных списаний 0)].

Выжимка P (10 строк):
1. `mie` у polza — это KIE.ai: 37 из 44 медиа-моделей (снимок 23.09) идут только через него, у видео запасного провайдера нет.
2. polza ≈ цена KIE × 1,4–1,8, но в рублях polza — самый дешёвый канал для видео KIE-линейки и большинства картинок.
3. polza не выставляет часть параметров тех же моделей (прозрачность GPT Image 2.5, длительность Veo, кадры Seedance,
   мульти-шот Kling, seed FLUX.2) и берёт плоский тариф максимального разрешения у Wan 3.0 / H3 Max / HappyHorse.
4. OpenRouter закрыт для РФ с 27.06.2026; его каталог перепродают RouterAI (×1,3 к цене), AITUNNEL (×2), ProxyAPI.
5. Recraft-вектор за рубли: RouterAI 8,78 ₽ (24.09; 8,74 — 23.09), Gen-API 20 ₽; стиль через RouterAI — референсами в каждом
   вызове, `style_id` — только прямой API (X30); прямой ключ Recraft — вторая очередь [поправка фазы 5, 25.09.2026: списано 8,83 ₽ (Vector) и 33,11 ₽
   (Pro Vector); Styles — 6,07 / 13,80 ₽ с референсом].
6. SVG Recraft — залитые контуры без обводок, с фоном-прямоугольником и подписью Ed25519: для иллюстраций и
   заливочных иконок, не для линейных UI-иконок (P/07) [поправка фазы 5, 25.09.2026: через RouterAI подписи `<recraft-signature>` нет — в `<metadata>`
   C2PA-манифест 17,7 КБ (30–79 % веса, после чистки Invalid) → `../99-raw/experiments/L/05-phase5-provenance/2026-09-25-all/README.md`].
7. Нативная петля видео — только Luma Ray 3.2 `loop` (fal/Replicate/Runware); бесшовная текстура — fal `z-image/turbo/tiling`
   (шов проверен на примере, P/06) — оба за рубежом. Открытые веса: коммерция — только Apache/MIT-строки файла 05 §9;
   локально работают апскейл, интерполяция, удаление фона и глубина, генерация — нет (P/10).
8. Gen-API — рублёвый вход в экзотику: Ideogram V3, удаление фона 2,5–4 ₽, слои Qwen Image Layered, SeedVR2; результаты
   планировать на 24 ч (оферта, X31) — скачивать сразу.
9. Зарубежные каналы (KIE, fal, Replicate, вендоры) требуют иностранной оплаты и содержат санкционные оговорки; сеть из
   среды заказчика доступна через VPN (P/08).
10. Рейтинг ключей: 1 RouterAI, 2 Gen-API, 3 fal или Runware, 4 Recraft напрямую, 5 KIE напрямую; не заводить: OpenRouter,
    Midjourney-прокладки; не строить на Sora 2 (API снят 24.09.2026) и remove.bg (закрывается 01.12.2026).
