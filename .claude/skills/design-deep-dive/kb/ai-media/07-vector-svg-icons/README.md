## Выжимка

1. Знакомую иконку брать из набора продукта (Lucide ISC и др.); LLM воспроизводит их из памяти (IoU ≥ 0,92 у 9 из 20).
2. LLM → SVG — для метафор, которых нет в наборе: спецификация числами + геометрия кодом + `check_icons.py` + одна правка
   по контакт-листу; узнаваемость новых метафор проверять отдельно (узнались 2 из 5).
3. Recraft — для иллюстраций и цветных иконок, не для линейных: только заливки, «линии» в 3–5 раз легче штриха 2.
4. Recraft за рубли — RouterAI (`recraft/recraft-v4.1-vector` 8,78 ₽ на 24.09), палитра параметром через `provider.options` — не
   документирована (тест G-07), стиль — референсом в каждом вызове (`style_id` — только прямой API); запас — Gen-API (явно
   `vector`, `pro:false`, `translate_input:false`). [поправка фазы 5, 25.09.2026: Vector 8,83 ₽ — фоны и черновики, **Pro Vector
   33,11 ₽ — наборы иконок (8 из 8) и спот**; палитра словами — только тон (ΔE00 3–8) → перекраска SVG за 0 ₽; `<recraft-signature>`
   через RouterAI нет — манифест C2PA 17,7 КБ в `<metadata>`, после чистки `Invalid` → на страницу без `<metadata>` (набор иконок
   6,7 / 10,1 КБ); LLM → SVG: 6 из 6 валидных, по полю и зазору 4 из 6 у GPT-5.6 Sol и Gemini 3.8 Flash → `../14-recipes/04-capability-map.md` §2.4]
5. SVG Recraft: фон удалить до svgo, svgo −57…−65 %, подпись провенанса сохранить (особый конфиг), иллюстрации 68–123 КБ —
   не inline; `currentColor` проверять на тёмном фоне (отверстия бывают нарисованы цветом фона → potrace).
6. Векторизация: плоское с ≤ 8 цветами — почти без потерь (vtracer `--palette`, SSIM 0,985); палитра — с цветом контура.
7. Паттерны — кодом (130–180 байт), штрих через край плитки продлевать; перекраска — `mask-image` + `var(--brand)`.
8. Фавиконы сайта — 3 файла ≈ 4 КБ (ico 32, SVG со светлой/тёмной версией, apple-touch 180); PWA — + 192, 512, maskable.
9. Анимация иконок — inline SVG + CSS с блоком `prefers-reduced-motion`; SMIL, SVG в `<img>` и Lottie reduce не слушают.
10. Фаза 5 — блок 5 сводного плана N (polza 35 ₽ в уровне 2; G-01…G-03, G-06 — в минимуме); предложение G (polza ≈ 35 ₽,
    RouterAI ≈ 100 ₽, Gen-API ≈ 21 ₽) — `../99-raw/phase5/G-plan.md`.
