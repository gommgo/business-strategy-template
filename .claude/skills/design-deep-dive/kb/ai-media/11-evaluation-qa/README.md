## Выжимка на 10 строк

1. После каждой генерации — `asset_audit.py audit <файл или папка с паспортами> --strict` (замки `heavy.lock`/`browser.lock` берёт сама — внешним `flock` не оборачивать); `fail` чинить до показа человеку.
2. Код меряет измеримое (альфа, утечка, шов, живость, склейки, камера, звук, палитра, зона текста, текст); VLM — смысл; эстетику — заказчик вслепую.
3. Пороги — только `thresholds.yaml` с источником; паспорт визуала (`--dna`) задаёт приёмку бренда.
4. Кириллица: локальный OCR (PP-OCRv6 det + PP-OCRv5 eslav, 0,1 с) ловит пропуск, удвоение, лишнее слово на 100 %, бракует верные строки 1/144; латиницу-«близнеца» не видит — текст в hero и OG читает человек [поправка фазы 5, 25.09.2026: K-05 — OCR 15 из 24 заложенных ошибок, VLM 11 из 24, «близнецов» не ловит никто].
5. Правка: `--match-color` прячет локальную утечку (H/03: LEAK → PASS) — `QA-EDIT-LOCAL-SHIFT` её ловит; отдавать композит.
6. Петля: шов — на мезонине без потерь (CRF 10 уже даёт 2,08 на идеальной петле), живость — к i2v-контролю; 12/12 поломок K/03 пойманы, чистая петля — pass.
7. VLM: атомарные позитивные вопросы, маркер только с «где», попарно со сменой сторон, одинаковое кодирование; видео — не судит [поправка фазы 5, 25.09.2026: K-03 — по листам видео 2 из 14 дефектов; K-04 — смещения к сжатию нет].
8. Судья по умолчанию `google/gemini-3.1-flash-lite` (0,02–0,1 ₽ за картинку), контроль — судья другого вендора (Qwen-235B).
9. Доверие к судье — согласие с решающими голосами заказчика ≥ 0,8 (Уилсон ≥ 0,65, n ≥ 20); иначе только предфильтр или никак [поправка фазы 5, 25.09.2026: калибровка K-01 не проведена; судья D2-03 согласен сам с собой 100 % (n = 4); `QA-PROV-VISIBLE-MARK` на фактурных углах — 4 ложных из 4].
10. Ручная приёмка ≈ 2 мин по чек-листу типа, журнал решений — разметка для калибровки порогов и судьи.
