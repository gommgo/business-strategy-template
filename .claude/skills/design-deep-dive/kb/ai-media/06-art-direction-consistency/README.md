## Выжимка

1. Перед первой картинкой — паспорт визуала, выведенный из токенов UI (`vlm_to_dna.py from-tokens`), утверждённый человеком.
2. Палитра фото — из эталонной съёмки, иллюстраций — из токенов; бренд-акцент на фото — одним предметом ≤ 3 % площади.
3. Блок стиля — 40–80 слов видимых признаков языком фотографии, без «no X», слов-слопа и ярлыков; замены запретов без предметов.
4. Серия: 1–3 референса одной съёмки с ролью текстом + дословный блок; всё — от утверждённого эталона, не от соседа.
5. Серия — по одному вызову от эталона (1–3 референса + дословный блок); набор одним вызовом (сетка 2×2, Seedream `sequential_image_generation`) согласованнее в T2IS (0,241 → 0,376), но у нас не измерен — плечо тестов F-02, G-17/G-18 (X34).
   [поправка фазы 5, 25.09.2026: F-01 — 3 референса + роль + блок: ΔE 0,031–0,035 (3 из 3 ≤ 0,05), только блок — 2 из 3 > 0,05;
   F-02 — сетка 2×2 наравне (0,031–0,036); E-12 — стиль эталона держит Flare из 4 моделей; блок композиции F-04 — 3 из 3
   (`centroid_x` 0,81–0,85) → `../14-recipes/04-capability-map.md` §2.1]
6. Пороги серии (фото): оттенок ≤ 10°, ΔE палитр ≤ 0,045; распад — > 25° или > 0,06; смысл — бинарные вопросы VLM, 2 прогона.
7. Контраст поверх фото: соответствие — WCAG F83 (худший участок, каждая буква); альфа — по p99,9, затем F83; p95 и среднее не годятся.
8. Фокус `{x, y}` задаёт автор; `object-position` по формуле F/03; телефону — свой кадр 4:5–9:16 (из 16:9 остаётся 31,6 % ширины).
9. «Средний вид» и «Instagram-фильтр» измеримы (центр масс значимости, colorfulness × 2, `hdr_index` +0,15) — пороги к эталону бренда.
10. Цвет: палитру снимать кодом; перенос с эталона другой сцены — ложная цель; грейд бренда — числа паспорта одним `.cube` на картинки и видео, и это отделка, а не стиль.
