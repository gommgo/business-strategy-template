## Выжимка для агента

### Перед работой (0 ₽)

1. Свежие каталоги: `python3 ../../scripts/ai-media/polza_catalog.py snapshot`, `python3 ../../scripts/ai-media/mp_client.py snapshot --channel all`.
2. Маршруты против каталогов: `python3 ../../scripts/ai-media/routing_check.py 13-routing-matrix/routing.yaml` — 0 ошибок; модель с ошибкой
   не вызывать (пример 25.09: id Flare сменился `gpt-image-2-5-flare` → `openai/gpt-image-2.5-flare`).
3. Деньги: `python3 ../../scripts/ai-media/polza.py ledger --sum`, `python3 ../../scripts/ai-media/mp_client.py ledger --sum`; `polza.py balance` —
   `spentAmount` должен равняться «потрачено до» + журнал (в фазе 5 сошлось до копейки).
4. Ключи — только файлами `~/.config/{polza,routerai,genapi}/api_key` (права 600); не читать, не печатать, не класть в чат.
5. Каждое задание — сначала `estimate` (`polza.py estimate`, `mp_client.py estimate`), 0 ошибок; `--live` — с согласия владельца денег.

### Деньги и сеть

- **Gen-API: цена каталога — минимальная ступень** (Hunyuan3D 32 → 96, Hunyuan Image V3 22,5 → 45, TRELLIS.2 62,5 → 75, Tripo
  50 → 75): считать по таблице страницы модели; оплата по факту — **лимит клиента не спасает** (96 ₽ при лимите 32).
- Расхождение с оценкой > 10 % — стоп модели или канала (FLUX.2 max через RouterAI — +43 %).
- **Обрыв POST → сначала история** (polza `/v1/history/generations`, RouterAI — `usage` ключа, Gen-API — баланс), повтор — только
  несозданного: 17 обрывов фазы 5, 0 двойных списаний.
- polza молча принимает и **списывает** лишние поля (T7); без `image_resolution` берёт ступень каталога (T8).
- **Верх цены чата = (`max_tokens` + перерасход на рассуждения) × ставка самого дорогого провайдера модели**: рассуждения
  биллятся сверх `max_tokens` и могут съесть ответ (Sonnet 5 — 9,77 ₽ за пусто); закреплять `provider.only`, давать запас `max_tokens`.
- Gen-API не принимает data:URI во входе (422) — публичный URL; при нуле на счёте — 402.
- RouterAI списывает GPT Image 2.5 только за выходные токены (× 0,0033113 ₽); судья Gemini 3.1 Flash Lite в polza-chat — по ступени
  провайдера Google, ×1,8–2,6 к оценке (DeepSeek — ставка провайдера ×3,6 к оценке, итог ×6,9).
- Вся фаза 5 — 1 940,25 ₽ за 261 медиа-генерацию и 190 чат-вызовов (polza 1 343,57, RouterAI 212,68, Gen-API 384).
- Правила каналов одной строкой на канал, недоступные 25.09 модели и «не маршруты» — `../13-routing-matrix/routing.yaml`
  (`defaults.channel_rules`, `defaults.unavailable_2026_09_25`, `defaults.not_routes`).

### Не делать

1. 3D-модель по картинке как основной путь объёма и товар со стеклом или надписью в 3D — видео по картинке вместо.
2. Кроссфейд хвоста петли на крупной форме («фантом») — RIFE-мост или пинг-понг.
3. Премиальную видео-модель ради шва петли; Kling 3 pro [A,A] как петлю (стоп-кадр); Seedance 2.x как петлю (референсы).
4. JSON как формат промта — JSON только спецификация, в модель — родной диалект.
5. Кириллицу моделями Qwen 2.1 и FLUX.2 Pro; интерфейсный текст — картинкой.
6. Аутпейнт и «не трогать остальное» без композита.
7. Слой рендера без сведения — во вход видео-модели.
8. Riverflow `transparent`, FLUX.2 max через RouterAI, H3 Max, Topaz Video, Wan 3.0 (на 25.09).
9. Две независимые генерации как «два состояния» под прожектор.
10. Повтор POST после обрыва без проверки истории; цену Gen-API — по каталогу.
11. Стекло через `background: transparent`; SVG Recraft на страницу с `<metadata>` (манифест 17,7 КБ, после чистки — `Invalid`).
12. Считать предметку «без бренда» свободной от чужого дизайна («наушники» вышли узнаваемыми AirPods Pro); судить видео VLM по листу кадров.

## Частые ошибки

- Брать модель «лучшую вообще» вместо строки под возможность — в фазе 5 модели различались по задаче.
- Не проверять размер выхода: Seedream 4 «4K» = 2352×1008; Sunburst 1K при долгой генерации — 1152×768 за те же 4 ₽.
- Считать петлю готовой по одной метрике: смотреть ролик ×3 глазами.
- Считать «24,4 КБ после svgo» весом иконок — 17,7 КБ из них манифест C2PA; без него набор 6,7 КБ (Pro) / 10,1 (Vector), спот 4,5 / 6,9, фон 5,1 / 2,3.
- Выводы по 1 образцу писать без «предварительно».
