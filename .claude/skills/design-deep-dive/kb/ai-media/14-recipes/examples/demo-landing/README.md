## Что смотреть глазами

- Hero: свет окна справа и тень переплёта на штукатурке; пар — тонкие струйки 5 с, петля без стыка; салфетка читается как
  «карточка» (CG) — после M-01 уходит.
- Иконки фич запечены на цвете секции `#F4EFE6` — страница только светлая (`color-scheme: light`); для тёмной темы нужен второй
  комплект иконок, иначе видны кремовые квадраты.
- «Кофемолка» в полосе иконок узнаётся плохо (банка? рюкзак?) — держится только подписью; новая метафора — всегда с текстом (G).
