## Выжимка на 10 строк (пересобрана по фазе 5, 25.09.2026)

1. Главный путь — картинка 2K → видео по картинке: мастер Sunburst/Flare 2K (7 ₽) → Seedance 1.5 Pro 720p 4 с 10,5 ₽ / 1080p 8 с
   45 ₽; 3D-модель по картинке — побочный путь (вердикт заказчика «так себе, лишнее»; `04` §2.5).
2. Hero-кадр: блок композиции даёт место под текст в 3 из 3 кадров; выбор на 1K (4 ₽) → финал 2K с пробой-референсом (7 ₽);
   телефону — свой мастер 3:4 (аутпейнт 16:9 → 9:16 перерисовывает центр).
3. Гладкий кадр сжимается до 2,6–3,4 КБ AVIF и выпадает из LCP на десктопе — LCP становится H1 или видео-слой; это нормально.
4. Постер кадра 0 — `avif_pick.sh 80`, не фиксированный Pillow q50 (79,5 < 80 — fail).
5. Петля: [A,A] + `fixed_lens`, шов — на мезонине без потерь; крупная форма сама не замыкается (3,29) — RIFE-мост 8 кадров
   (0,69–0,84; 1080p — 0,41), не кроссфейд хвоста («фантом»); после кодирования стык «пульсирует» (0,8 → 2,4).
6. Синемаграф дёшево: 720p i2v + мастер 2K `maskedmerge` (локально: 5 с 1536×864 — 18 КБ AV1); живьём в фазе 5 не проверен.
7. Товар — только композитом: по эталону этикетка во фронте у 4 из 4, сбоку — у 1 из 4; правка без маски — утечка в 5 из 6;
   облёт видео-моделью держит надпись в 11 из 11 кадров (Kling 3, 50 ₽).
8. Серия: 3 референса эталона + роль + дословный блок — ΔE палитры 0,031–0,035; сетка 2×2 одним вызовом — так же; 3D-иконки из
   формы и материала — IoU 0,92–0,95.
9. Вектор: Recraft V4.1 Pro Vector (33,11 ₽) — наборы иконок ровно по заданию, Vector (8,83) — фоны; палитра и тёмная тема —
   перекраской SVG за 0 ₽; на страницу — без `<metadata>` (манифест C2PA 17,7 КБ): набор иконок 6,7 / 10,1 КБ, фон 2,3–5,1 КБ;
   кириллица и OG — HTML-шаблоном → Playwright, буквы — OCR `--expect` + глаз.
10. Кириллица моделью — только коротко (дословно 7 из 10 моделей с растровым Recraft V4.1; Qwen 2.1 и FLUX.2 Pro — ошибки); JSON
    как формат промта не нужен (Δ +2,8 п. п. [−2,7; +9,1]); альфа генерацией — мех да, стекло нет; видео — метриками, не VLM.

Скелеты из роликов: «машина бренда» Weave (`01` §0.4), три графа Rory Flynn (`02` §1.3б, §2.1а, §5.3), редакционный поток Т—Ж
