## Частые ошибки

- Выбирать модель «лучшую вообще»: в фазе 5 модели различались по задаче (Flare держит серию, Seedance 1.5 Pro — петлю, Grok —
  трансформацию, Kling — облёт с надписью); строку карты брать по возможности, а не по «рейтингу».
- Принимать петлю по одной метрике шва: кроссфейд дал 1,46–1,76 и всё равно «фантом» — смотреть ролик ×3 глазами.
- Считать 1080p-модель «лучше» для петли: Kling 3 pro 1080p выдал почти стоп-кадр за 48 ₽.
- Верить заказанному размеру: Seedream 4 «4K» — 2352×1008, Sunburst 1K иногда 1152×768 — проверять `files[].media` в паспорте.
- Писать палитру словами и ждать точного цвета в SVG: ΔE00 заливок 3–8 — перекрашивать кодом.
- Брать «24,4 КБ после svgo» за вес иконок: 17,7 КБ из них — манифест C2PA в `<metadata>`; без него набор — 6,7 КБ (Pro) / 10,1
  (Vector), иконка после нарезки — 1–2,5 КБ; манифест после чистки путей всё равно `Invalid` → на страницу без `<metadata>`.
- Считать `background: transparent` годным для стекла: у GPT 2.5 через RouterAI тело флакона непрозрачно, вокруг — облако фона.
- Проверять видео VLM-судьёй по листу кадров: временные дефекты он пропускает (2–3 из 14) — только метрики и глаз.
- Считать предметку «без бренда» свободной: модель воспроизводит узнаваемый чужой дизайн и дописывает надписи без запроса.
- Считать деньги Gen-API по каталогу и полагаться на лимит клиента при оплате по факту (96 ₽ при лимите 32).
- Отдавать видео-модели служебный слой рендера (тень, маску) вместо сведённого кадра — SSIM ошибку не видит.
- Строить «два состояния» из двух независимых генераций — не совмещаются.
- Ставить метку «проверено» выводу по 1 образцу без «предварительно» — все выводы фазы 5 предварительны.

  (отменено) — вывод предварительный.
- **Recraft Pro против Vector**: выбор по числам (8 из 8, 35 путей против 12 с повторами, 63 пути), голоса заказчика нет.
- **Альфа GPT Image 2.5 через RouterAI** — разобрано (V): мех годен, стекло нет (облако фона вокруг тела); открыто — другие типы
  объектов (n = 1 на тип) и Riverflow `transparent` без `output_format`; `alpha_check.py halo` на этих объектах не различает (HALO у обоих).

- **Цвет выходов Kling и Omni ближе к BT.601** — n = 5, малонасыщенные сцены: вывод слабый.
- **Секвенция 214 МБ раскодированных кадров** на настоящем телефоне не проверена; замеры — headless Chromium без GPU.
