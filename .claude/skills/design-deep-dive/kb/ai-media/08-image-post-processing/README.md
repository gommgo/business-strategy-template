## Выжимка (10 строк)

1. Выход модели никогда не публиковать как есть: AVIF по порогу SSIMULACRA2 (≥ 80 hero, ≥ 70 прочее) — гладкий рендер 1 Мп ≈ 5 КБ.
2. После **любой** правки — `../../scripts/ai-media/edit_check.py check` (утечка ≤ 0,02, дрейф ≤ 2): вердикт утечки — по прогону **без** `--match-color` и по локальному сдвигу K (`QA-EDIT-LOCAL-SHIFT`), подгонка растворяет утечку (LEAK 0,131 → PASS 0,0001, X23); утечка — композит по маске.
3. Удаление объекта с композитом — маска объект + тень + ≈ 9 % стороны и растушёвка ≈ 3 %, иначе «призрак» контура.
4. Аутпейнт проверять тремя критериями (SSIM центра, ΔE00, резкость краёв) — один SSIM перерисовку не ловит.
   [поправка фазы 5, 25.09.2026: подтверждено — H-08 9:16 у Sunburst и NB2: SSIM центра 0,94 / 0,98 проходит, резкость 0,14 / 0,56 —
   REGENERATED; E-15 — правка без маски LEAK в 5 из 6; альфа генерацией — Qwen 2.1 (63,6 % прозрачных) и GPT 2.5 через RouterAI
   (1,45 ₽: мех да, стекло нет — облако фона), Riverflow — пусто → `../14-recipes/04-capability-map.md` §2.7]
5. Вырез — по типу объекта: мех/волосы — u2netp + matting или хромакей, тонкое — isnet (веса спорные: в финал — u2netp, хромакей или BiRefNet, `../12-legal-provenance/01-licenses-by-vendor-and-channel.md` §4), стекло — хромакей или нативная альфа; модель rembg — всегда явно.
6. Real-ESRGAN не консервативен (хуже Lanczos на 15–103 пункта, выдумывает структуру); фото генерировать в целевом разрешении.
7. Бесшовность — только постобработкой: шов ≤ 1,3; органика — разрез минимальной ошибки, сетка — заделка маской или SVG/CSS.
8. Дизеринг до сжатия бандинг не лечит — шум поверх (CSS/SVG), гладкие градиенты — CSS.
9. Глубина: Depth Anything V2 Small, вход 518, 0,3 с на CPU; края размазаны — слои по альфе выреза, не по порогу глубины.
10. C2PA не переживает оптимизацию; мастер вендора хранить побайтно, на страницу — производные + XMP `DigitalSourceType`, манифест — sidecar/CDN.
