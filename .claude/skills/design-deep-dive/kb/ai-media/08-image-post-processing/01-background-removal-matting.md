## Выжимка для агента

1. **Сначала реши, нужен ли вырез вообще**: если фон страницы ровный, генерируй объект сразу на этом цвете (тени и рефлексы
   «запечены»), а цвет фона дотягивай кодом; вырез — когда объект ложится на фото, видео, градиент или выходит за край
   карточки → §1.1 [практика; V:_Bc4g6fFMp0 05:07].
2. **Универсального локального выреза нет — маршрут по типу объекта** (H/01): мех и волосы — `u2netp` + alpha matting или
   хромакей; проволока, листья, тонкие детали — `isnet-general-use`; твёрдые предметы — любой (IoU 0,97–1,00); стекло и
   полупрозрачное — хромакей или нативная альфа модели → §1.2 [проверено: 99-raw/experiments/H/01-background-removal].
3. **`isnet-general-use` без проверки не ставить на пушистое**: на светлых кудрях IoU 0,00 (вырезал фон вместо объекта), на
   мехе 0,38 → §1.2, §3.2 [проверено: H/01].
4. **Стекло на светлом фоне нейросети выреза делают непрозрачным или выкидывают** (потеря полупрозрачного 0,92–0,97 у u2netp
   и isnet); лучший локальный путь — хромакей со своим кеингом (ошибка края 207–239 против 242–556 у нейросетей, потеря
   полупрозрачного 0,23–0,57), но и он не идеален → нативная альфа — фаза 5 → §1.2, §2.2 [проверено: H/01].
5. **Под вырез просить ровный фон**: пёстрый фон роняет u2netp с IoU 0,80 до 0,68; формула — «plain seamless light-gray studio
   background, even soft light, nothing else in the frame» → §2.1 [проверено: H/01].
6. **Хромакей — цвет, далёкий от оттенков объекта**: `#00B140` по умолчанию, пурпурный — для зелёных и золотых объектов (золото
   на зелёном теряет детали); без теней, градиента и линии пола → §2.2 [практика; V:_Bc4g6fFMp0 07:07].
7. **Хромакей правкой той же модели** («change only the background to flat chroma-key green») даёт две картинки из одной: ключ
   для выреза и исходник для сверки; критерий фона — ΔE00 ≤ 3 к ключу на ≥ 98 % площади → §2.2 [не проверено: фаза 5 H-07 v3;
   V:BVMuRw8BgJg 01:00].
8. **Свой кеинг CbCr + despill** (10 строк numpy, 0,01 с на кадр) — лучшая средняя ошибка края (139 против 184–297 у нейросетей)
   → §3.3 [проверено: H/01].
9. **В rembg модель — только явно**: по умолчанию 2.0.85 берёт `bria-rmbg` (RMBG-2.0, CC BY-NC, 1 ГБ скачивания) → §3.1
   [проверено в коде: P/10; документация rembg].
10. **Alpha matting rembg — по типу объекта**: на волосах ошибка края −33…−40 %, на твёрдых краях +47 % (кружка 66 → 97) →
    §3.2 [проверено: H/01].
11. **Деконтаминацию (`decontaminate=True`) включать всегда на цветном фоне** — почти бесплатно (0,19 с) и снижает ΔE ореола на
    зелёном 18,9 → 17,1 → §3.2 [проверено: H/01].
12. **Нативная альфа в polza — только `qwen/image-2.1` `background: transparent`** (png/webp, 3 ₽; несовместимо с `mask_url`;
    веса — исследовательская лицензия: по решению L только черновики и тесты, не финал —
    `../12-legal-provenance/01-licenses-by-vendor-and-channel.md` §5) → §4 [документация, polza 2026-09-23] [поправка X
    24.09.2026: было «коммерция — вопрос L»].
13. **GPT Image 2.5 с прозрачностью**: в Media API polza параметра `background` нет; `/v2/images/generations` — не
    документирован (тест H-02, 4 ₽); RouterAI документирует `background: transparent` (H-03, ≈ 1,4 ₽) → §4 [документация;
    не проверено] [поправка фазы 5, 25.09.2026: H-03 через RouterAI (1,45 ₽) — мех и волокна — годен, стекло — нет (облако фона вокруг
    тела, внутри флакона полупрозрачных 0 %, маска блоками 16 px); H-02 не запускался → `99-raw/phase5/runs/S5-analysis/H-03_alpha.json`].
14. **У Nano Banana Pro прозрачности нет** («not in this release») — только ровный фон + вырез → §4 [V:y-RQ48sfPgM 15:23].
15. **«Нарисованная шахматка» — не прозрачность** (OpenAI): после любой «прозрачной» генерации — `alpha_check.py fake` и
    `halo` → §5 [документация OpenAI; проверено: утилита].
16. **Критерий приёмки выреза**: ореол ≤ 2 px на чёрном и белом (`alpha_check.py halo`); стекло — ≥ 30 % тела с 0,1 < α < 0,9;
    волокна — частичная альфа ≥ 3 % объекта; смотреть контактный лист на чёрном, белом и фото → §5 [проверено: утилита H].
17. **Платный вырез не лучше «везде»**: Ideogram remove-background — лучший на стекле и дыме (MAE 0,034), но худший по сумме
    категорий (0,051); на волосах лучше открытые RMBG-2.0/BiRefNet → маршрут по классу, а не «один сервис» → §4.2
    [исследование: Lucida, 203 картинки, эталонная альфа].
18. **Тень объекта вырез срезает** (все модели P/10 и H/01): контактную тень восстанавливать отдельным слоем (multiply) или
    ставить объект на цвет страницы; объект без тени и контакта выглядит «прифотошопленным» → §6 [проверено: P/10;
    V:5dnNUB27HBQ 06:11].
19. **BiRefNet-lite на этой машине — только при ≥ 8 ГБ свободной памяти** (6,5 ГБ RSS на CPU), иначе хостинг (fal) → §3.4

20. **Вырез отдавать AVIF/WebP с альфой**, PNG — только для мелкого (< 256 px); вырез не кадрировать до края объекта — поле
    ≥ 2 % под ореол и тень → §7 [документация A `01/01` §4.3; практика].

## 1. Маршрут

### 1.1 Нужен ли вырез

| Ситуация на странице | Что делать | Почему |
|---|---|---|
| Ровный фон секции (#F5F5F2) | генерировать объект на этом цвете, край кадра — растушёвка в фон кодом (`mask-image`) | тени и рефлексы правдивы; hex модель попадает ≈ в 50 % случаев [исследование: E-helper J11] → фон карточки подогнать к фактическому цвету кадра, а не наоборот |
| Фото, видео, градиент, анимация под объектом | вырез + слой тени | фон под объектом меняется |
| Объект выходит за край карточки, перекрывает текст | вырез | [V:hzPKb8bDvdY 24:29] |
| 2.5D-параллакс, слои | вырез + чистая подложка + глубина | `03-color-tiling-depth-layers.md` §4–5 |
| Товар реального клиента | вырез **фото** товара, модель рисует только окружение | товар без дефектов у моделей лишь в 53–75 % случаев [исследование: E-helper J14, 996 товаров] → `02-upscale-outpaint-edit.md` §3 |

## 2. Какой фон просить у генератора

### 2.1 Ровный светлый фон под нейросетевой вырез

```text
// qwen/image-2.1 (или любая модель без альфы) · polza 2026-09-23 · 1K, 1:1, png, enhance_prompt: false · [не проверено: фаза 5 H-01 v3–v4]
A frosted glass perfume bottle with pale amber liquid and a brushed-gold cap, three-quarter view, soft studio reflections,
subtle caustics inside the glass, standing on a plain seamless light-gray studio background, even soft light,
nothing else in the frame.
```

- Светлый ровный фон — для тёмных и насыщенных объектов; для светлых (белая керамика, светлые волосы) — средне-серый или
  хромакей: ключевая трудность H/01 — светлые кудри на светлом (IoU 0,78 у u2netp).
- Recraft кладёт объект на чистый фон под вырез, а Nano Banana на «neutral background» рисует фактурную стену — просить
  «plain seamless … nothing else», не «neutral» [V:AOPKK0LlI_Q 35:54].
- Критерий входа под вырез: ΔE00 ≤ 3 к медиане фона на ≥ 95 % площади вне объекта (иначе — перегенерация или хромакей).

### 2.2 Хромакей

- Цвет ключа — дальше от оттенков объекта: `#00B140` (зелёный) по умолчанию; пурпурный (magenta) — для зелёных, золотых,
  жёлтых объектов (золото на зелёном теряет детали: «лапы» пропадают) [V:_Bc4g6fFMp0 07:07]; hex модели не
  гарантирован — ключ берётся по **медиане фона кадра**, а не по заданному hex.
- Блестящий объект отражает ключ: зелёный отсвет на металле и стекле — despill обязателен; если объект будет стоять на
  известном цвете страницы, лучше генерировать сразу на нём [V:_Bc4g6fFMp0 05:07].
- Хромакей **правкой** исходника (та же модель, второй вызов) — «две картинки из одной»: исходная сцена + ключ того же объекта
  (W5-3); проверка сохранности объекта — `edit_check.py check --protect` (SSIM ≥ 0,9, ΔE00 медиана ≤ 5).

```text
// google/gemini-3.1-flash-image-preview (NB2) · polza 2026-09-23 · images: [исходник], 1K, png · [не проверено: фаза 5 H-07 v3]
Change only the background to a flat, uniform chroma-key green (#00B140), with no shadows, no gradient and no floor line.
Keep the red can and the yellow ball exactly unchanged, including their edges.
```

### 3.2 Ловушки rembg (проверено в коде и опытом)

- `only_mask=True` **пропускает** alpha matting и деконтаминацию — для них нужен полный вырез RGBA [проверено: H/01].
- Время почти не зависит от размера картинки: модель всегда работает на своём входе (320² / 1024²), маска потом растягивается
  → на 4K-картинке край u2netp грубый (маска из 320²); для крупных кадров — isnet/BiRefNet или хромакей [проверено: P/10, код].
- CLI не входит в `rembg[cpu]` — нужен `rembg[cpu,cli]` [проверено: P/10].
- isnet на пушистом объекте иногда инвертирует выбор (IoU 0,00) — проверять `alpha_check.py metrics` на эталоне класса
  или глазами на контактном листе до пакетной обработки.

### 3.3 Свой хромакей (numpy, без моделей)

```python
# Python 3.13 + numpy · [проверено: 99-raw/experiments/H/01-background-removal/run_matting.py, chroma_key]
import numpy as np
def chroma_key(rgb, key, t0=0.10, t1=0.30):
    """rgb, key — float 0..1 (key = медиана фона кадра, не заданный hex); альфа по расстоянию в CbCr + despill."""
    def cbcr(x):
        r, g, b = x[..., 0], x[..., 1], x[..., 2]
        return np.stack([-0.1687 * r - 0.3313 * g + 0.5 * b, 0.5 * r - 0.4187 * g - 0.0813 * b], -1)
    d = np.linalg.norm(cbcr(rgb) - cbcr(np.asarray(key, np.float32)), axis=-1)
    a = np.clip((d - t0) / (t1 - t0), 0, 1)                        # мягкий порог → полупрозрачность стекла сохраняется
    out = rgb.copy(); out[..., 1] = np.minimum(out[..., 1], np.maximum(out[..., 0], out[..., 2]))   # despill (зелёный ключ)
    return a, out
```

Для пурпурного ключа despill — `R, B ← min(·, G)` по смыслу; пороги 0,10–0,30 подобраны на `#00B140` и рендерах H/00
(0,01 с на кадр, 0,23 ГБ). Видео-хромакей (`colorkey`/`hsvkey` + `despill` ffmpeg) — у I (`../09-video-pipeline/`).

### 3.4 Что не запускается здесь

BiRefNet (полный и lite) ONNX на CPU: 6,5 ГБ RSS, при свободных 4–6 ГБ уходит в своп (повтор 25 с вместо 10 с) → только
при `free -g` ≥ 8 ГБ под `heavy.lock` или хостинг (fal `fal-ai/birefnet/v2`) [проверено: P/10]. Видео-матирование
(MatAnyone, RVM) — `../02-providers-platforms/05-open-weights-landscape.md` §3.3 и I.

- Вывод: платный вырез — для стекла и дыма (H-04 проверяет Ideogram и Pixelcut на эталонных флаконе и волосах); волосы —
  открытые матирующие модели (RMBG-2.0 — только некоммерчески; BiRefNet — MIT).

## 5. Проверка альфы — `../../scripts/ai-media/alpha_check.py`

```bash
# Python 3.13 + numpy + scipy + Pillow · [проверено: H/01]
python3 ../../scripts/ai-media/alpha_check.py metrics pred_alpha.png gt_rgba.png --rgb gt_rgba.png --src onbg.png  # есть эталон
python3 ../../scripts/ai-media/alpha_check.py halo cutout.png --bg "#E8E8E6"   # без эталона: ширина «грязной» каймы → PASS ≤ 2 px
python3 ../../scripts/ai-media/alpha_check.py fake out.png                     # «нарисованная шахматка»: REAL_ALPHA / OPAQUE / FAKE_CHECKERBOARD
```

| Что | Поле | Порог приёмки |
|---|---|---|
| альфа вообще есть | `halo.transparent_frac` | > 0,2 для объекта в кадре; `NO_ALPHA` — брак |
| ореол | `halo.halo_px` (95-й перцентиль расстояния «грязных» пикселей каймы от ядра) | ≤ 2 px |
| стекло полупрозрачно | доля пикселей тела с 0,1 < α < 0,9 | ≥ 30 % |
| волокна не «подстрижены» | `pred_partial_frac` относительно площади объекта | ≥ 3 % |
| против эталона (есть рендер) | `iou`, `band_mae_x1000`, `comp_black_band_de_mean` | IoU ≥ 0,95 твёрдое, ≥ 0,85 волосы; ошибка края ≤ 150 (позиция H по лучшим методам H/01) |

Контактный лист для заказчика: объект на чёрном, белом и фото-фоне, край 200 % — ореол виден только на контрасте.

## 6. Тень и контакт

- Все проверенные модели выреза срезают мягкую тень (P/10, H/01) — объект «висит»; вставка без контакта и свечения
  выглядит «прифотошопленной» [V:5dnNUB27HBQ 06:11].
- Если есть исходник на ровном фоне и тот же фон без объекта (чистая подложка — рендер или правка удалением), слой тени =
  отношение яркостей `onbg / clean` вне объекта → PNG/AVIF в оттенках серого, на странице `mix-blend-mode: multiply`
  [практика; не проверено здесь — задача J/M].
- Проще и надёжнее для товара на ровном фоне страницы: генерировать объект сразу на цвете страницы и не вырезать (§1.1).

## 7. Доставка выреза

- Формат: AVIF или WebP с альфой; PNG — только мелкие (< 256 px); кодирование и качество — `04-encoding-metadata.md` §1,
  таблица форматов — `../01-web-assets-landscape/01-asset-slots-by-page-type.md` §4.3.
- Поле вокруг объекта ≥ 2 % стороны: кадр по краю объекта обрезает ореол-растушёвку и тень, а `object-fit` потом «прилипает»
  объект к краю контейнера [практика].
- Видео с альфой (VP9-alpha, stacked alpha) — I (`../09-video-pipeline/02-…`).

## Частые ошибки

- Вызов `remove(img)` без сессии — некоммерческая RMBG-2.0 и скачивание 1 ГБ (умолчание rembg 2.0.85).
- Один метод выреза на все объекты («isnet лучше u2netp» — на проволоке да, на волосах IoU 0,00).
- Alpha matting включён для твёрдых предметов — край становится мыльным (ошибка края +47 %).
- `only_mask=True` вместе с `alpha_matting=True` в надежде на мягкую маску — matting не применяется.
- Прозрачный PNG от модели принят без проверки — внутри непрозрачная «шахматка» (`alpha_check.py fake`).
- Ключ хромакея взят из заданного hex (#00B140), а модель нарисовала #0FAE4A с градиентом — ключ брать по медиане фона.
- **Ошибки нейросетей-агентов**: «у Nano Banana есть прозрачный фон» (нет); «GPT Image 2.5 в polza принимает `background`»
  (в Media API нет, `/v2` — не проверено); «remove.bg — стандарт» (закрывается 01.12.2026); «BiRefNet легко запустить
  локально» (6,5 ГБ RSS); перенос параметров OpenAI (`background`, `quality`) в polza без сверки каталога; hex ключа как
  гарантия цвета фона.

## Чек-лист

- [ ] Вырез действительно нужен (фон под объектом не ровный цвет страницы)?
- [ ] Тип объекта определён (мех/волосы, стекло, тонкие детали, твёрдый) и метод выбран по таблице §1.2?
- [ ] Генерация под вырез — на ровном фоне без теней и градиента (или хромакей дальше от оттенков объекта)?
- [ ] Модель rembg задана явно, `REMBG_HOME` указывает на свои веса, лицензия весов подходит проекту?
- [ ] `alpha_check.py fake` — REAL_ALPHA; `halo` — ≤ 2 px на чёрном и белом?
- [ ] Стекло полупрозрачно (≥ 30 % тела с 0,1 < α < 0,9), волокна не подстрижены?
- [ ] Тень и контакт восстановлены (слой multiply) или объект стоит на цвете страницы?
- [ ] Отдаётся AVIF/WebP с альфой, поле вокруг объекта ≥ 2 %?

## Открытые вопросы и противоречия

- **Нативная альфа против «ровный фон + вырез»** на стекле и волосах — прямого замера с эталоном нет ни у кого (Lucida не
  включала GPT/Qwen) → фаза 5 H-01…H-04 (один лист «стекло, волокна × 4 пути»).
- Пропускает ли `/v2/images/generations` polza `background: transparent` для GPT Image 2.5 — H-02.
- Коммерческие права на выход Qwen 2.1 через `mie` при исследовательской лицензии весов — L.
- isnet-general-use: лицензия весов не указана, датасет некоммерческий — брать ли в коммерческий конвейер — L.
- BiRefNet (MIT) — главный кандидат без меры: нужен прогон при ≥ 8 ГБ свободной памяти или fal (≈ по GPU-секундам).
- CG-эталон против фото: пороги (ошибка края ≤ 150) откалиброваны на рендерах; на CC0-фото волос — не проверено.
- Восстановление тени отношением `onbg / clean` — не проверено; кандидат в опыт J/M.
