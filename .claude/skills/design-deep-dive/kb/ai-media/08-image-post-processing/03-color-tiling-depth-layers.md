## Выжимка для агента

1. **Грейд бренда — один `.cube`, применять одним инструментом к картинкам и видео** — ffmpeg `lut3d` (tetrahedral):
   ffmpeg = расчёт Python с ΔE OKLab 0,002, кадр видео после H.264 против картинки — 0,012 → §1.1 [проверено].
2. **Pillow `Color3DLUT` с ffmpeg не сверялся** (у Pillow трилинейная интерполяция, таблица ≤ 65³) — в конвейере не смешивать
   два интерполятора; при смешивании — сверить ΔE на кадре-эталоне → §1.1 [документация Pillow; не проверено].
3. **После правки — подгонка цвета по неизменной зоне** (`edit_check.py --match-color`: медиана ΔE 3,7 → 0,9), а не «на
   глаз»; утечку при этом смотреть до подгонки и локальным сдвигом (`02-upscale-outpaint-edit.md` §2.3, K) → §1.2
   [проверено] [поправка X 24.09.2026].
4. **Перед FLF-видео правленый конечный кадр подгонять по цвету к начальному** — иначе сдвиг цвета в ролике; кадр из видео
   сдвигает цвет чаще, чем картинка → §1.2 [V:WmC1nqz10Qk 06:19; V:FvzFXrzgioc 10:15; стык с I].
5. **Перенос цвета с эталона другой сцены — ложная цель** (белая площадь стала горчичной); переносить только внутри одного
   класса сюжетов → §1.3 [проверено].
6. **Грейд без нормализации источника не переносится** («way too green» на другом видео) и «запекается» в генерации — грейд
   задавать блоком стиля (F) или одним LUT после, не копировать цепочку → §1.3 [V:I9xdmNZxIfA 16:34–17:36; V:ttgNFJ25xfU 1:01:07].
7. **Бесшовность промтом не получается**: параметра tile нет ни у одной модели polza; «seamless tileable» у топ-модели
   тайла не даёт (NB Pro) → проверять всегда: сдвиг 50 % + метрика шва → §2.1 [документация C1; исследование: E-helper J12].
8. **Метрика шва ≤ 1,3 — бесшовно, > 1,5 — чинить** (тайлы Poly Haven после ресайза 0,87–1,23; вырез из середины 1,6–3,9)
   → §2.2 [проверено].
9. **Органику (жаккард, камень, шум) делать тайлом разрезом минимальной ошибки** (Efros–Freeman, полоса 96 px): шов 1,11,
   высокие частоты 0,99–1,0; смешивание со сдвинутой копией даёт двоение (−12 % ВЧ); зеркало — «Роршах» → §2.3
   [проверено].
10. **Регулярную сетку (ткань, плитка, кирпич) — генеративной заделкой креста шва маской** (Qwen 2.1, 3 ₽, H-09) или «тайл +
    код» (SVG/CSS-паттерн — G): разрез оставляет видимый сдвиг фазы нитей → §2.3 [проверено: H/05a; не проверено: H-09].
11. **Дизеринг перед сжатием не спасает от бандинга**: после AVIF/WebP/JPEG «лестница» 0,33–0,40 кода — как без
    дизеринга; зерно выживает ценой веса ×12 → зерно и шум — поверх, после декодирования (CSS/SVG) → §3 [проверено].
12. **Тёмный гладкий градиент hero — CSS-градиентом**, а не растром; если растр — накрыть шумом кодом: повышение качества
    AVIF бандинг не лечит (q60 0,381 → q80 0,394) → §3 [проверено: H/05b; практика].
13. **10-битный AVIF не лечит бандинг, если путь отображения 8-битный без дизеринга** (0,31–0,36 при декоде в 8 бит) →

## 1. Цвет: применить одинаково и проверить

### 1.1 Один LUT для всех ассетов

```bash
# ffmpeg 7.1.5 · один .cube (33³) на картинку и видео · [проверено: 99-raw/experiments/F/05-color — ΔE OKLab 0,002 / 0,012]
ffmpeg -i in.png -vf "lut3d=file=brand.cube:interp=tetrahedral" out.png
ffmpeg -i in.mp4 -vf "lut3d=file=brand.cube:interp=tetrahedral,format=yuv420p" -c:v libx264 -crf 14 out.mp4   # мезонин
```

- Генератор `.cube` из чисел паспорта (сдвиг нейтралей, хрома, чёрная и белая точки, S-кривая) — F
  (`../../scripts/ai-media/palette.py: parametric_grade, write_cube`; обёртка `../../scripts/ai-media/vlm_to_dna.py lut`).
- Грейд ставить на мастер или мезонин **до** финального кодирования и до лестницы `srcset`, не на AVIF/WebP-выход.
- Pillow `ImageFilter.Color3DLUT` — «interpolating the nearest elements» (трилинейно), размер ≤ 65 по оси [документация
  Pillow 11.3, docstring]; с ffmpeg tetrahedral не сверялся → один инструмент на весь конвейер.

### 1.2 Подгонка цвета после правки и перед видео

- После любой правки моделью: `edit_check.py check … --match-color` — линейная подгонка по каналам на пикселях вне цели
  (H/03: общий дрейф ΔE00 3,3 → медиана вне цели 0,9) → `02-upscale-outpaint-edit.md` §2.3.
- Цепочка «картинка → правка → FLF-видео»: конечный кадр после правки сдвинут по цвету — подогнать к начальному
  [V:WmC1nqz10Qk 06:19]; у I запасной путь — `video_loop_check.py colormatch` (OKLab-Рейнхард по маске неизменных зон),
  основной — тот же LUT (`../09-video-pipeline/`).
- Товар: цветовая температура — по спецификации товара (4000 K), а не «как красиво» [V:5dnNUB27HBQ 25:33]; ручная доводка без
  ИИ (экспозиция, температура, уровни) — нормальный последний шаг [V:I9xdmNZxIfA 13:32].

### 1.3 Чего не делать

- Переносить статистику цвета с эталона другой сцены (Reinhard, MKL): ΔE палитры падает 0,117 → 0,027, а глазами — брак
  (белая площадь горчичная, пасмурное море «на закате») [проверено].
- Копировать чужую цепочку грейда на другой источник — «way too green» [V:I9xdmNZxIfA 16:34–17:36]; грейд «запекается» в
  генерации [V:ttgNFJ25xfU 1:01:07] — сначала нейтральная генерация, грейд — одним LUT.
- Мерить цвет VLM-судьёй: VLM путают цвета (Qwen2-VL 49 % на бинарной задаче), мерить пикселями — маска + CIEDE2000
  [исследование: E-helper J11]; утилиты — `../../scripts/lib/color.py` (ΔE, OKLCH), метрики A/04 (красочность Hasler–Süsstrunk,
  `hdr_index`, тёплый сдвиг b*) — сводит K.

## 2. Бесшовные текстуры

### 2.1 Почему только постобработкой

- Параметра tile нет ни у одной модели polza и изученных API; `--tile` — только Midjourney без официального API
  (`../03-image-models/03-capabilities-by-task.md` §9).
- NB Pro на задаче тайлинга «fail to preserve the input patch distribution and do not satisfy the task constraints»
  [исследование: E-helper J12, качественно, надёжность C].
- Латентный тайлинг работает у моделей с circular padding: пример fal Z-Image Turbo tiling — шов 0,90 / 0,94 против 3,1 у
  контроля [проверено на 1 образце вендора]; fal — вне доступных каналов (ключа нет).

### 2.2 Метрика шва и проверка

- `seam_ratio` = средняя |разница| на стыке по кругу (последний столбец ↔ первый; строки так же) / медиана разницы соседних
  столбцов (строк) внутри картинки; ≈ 1 — стык как внутренняя структура, ≫ 1 — шов [P/06].
- Пороги базы: **≤ 1,3 — бесшовно** (тайлы Poly Haven после ресайза Lanczos 0,87–1,23 — краевой режим ресайза слегка портит
  стык), **> 1,5 — чинить**; P/06 предлагал ≤ 1,2 — строже, чем проходят настоящие тайлы после ресайза [проверено].
- Глазами — сдвиг на 50 % (`np.roll`, шов уходит в центр крестом) и плитка 2×2; периодичность повторов (узнаваемое пятно
  каждые N px) метрика шва не ловит — открытый вопрос.

### 2.3 Как сделать тайл (H/05a: вырез 1024² из середины CC0-ткани → тайл)

| Способ | Мешковина шов (гор. / верт.) | Жаккард шов | ВЧ | Когда |
|---|---|---|---|---|
| вырез как есть (ИИ-«seamless» без tile) | 2,79 / 3,93 | 1,64 / 1,58 | 1,0 | — брак |
| смешивание со сдвинутой на 50 % копией | 1,34 / 1,01 | 1,26 / 1,13 | 0,87–0,88 (двоение) | бесструктурные фоны, облака, шум |
| зеркальная плитка 2×2 | 0 / 0 | 0 / 0 | 1,0 | никогда для узнаваемой фактуры («Роршах») |
| **разрез минимальной ошибки, полоса 96 px** | 1,40 / 1,15 | **1,11 / 1,11** | 0,99–1,0 | органика; тайл меньше на 96 px |
| кадр по периоду узора | 2,48 / 1,51 | 1,51 / 1,47 | 1,0 | не работает на реальных текстурах |

```bash
# ../../scripts/ai-media/tile_check.py (функции H/05a) · Python 3.13 + numpy + Pillow · [проверено: жаккард 1,64/1,58 → 1,11/1,11]
python3 ../../scripts/ai-media/tile_check.py check texture.png             # {"seam_ratio": [гор., верт.], "verdict": SEAMLESS|BORDERLINE|SEAM}
python3 ../../scripts/ai-media/tile_check.py cut texture.png tile.png --overlap 96   # разрез минимальной ошибки, размер −96 px, шов до/после
python3 ../../scripts/ai-media/tile_check.py preview tile.png preview.jpg  # сдвиг 50 % | плитка 2×2 — глазами
```

- Регулярная сетка: разрез оставляет видимый сдвиг фазы нитей → заделка креста шва маской: сдвиг 50 % → маска креста
  48 px (белое = менять) → Qwen 2.1 правкой «Repair the seam… matching thread direction, scale and color» → снова
  `seam_ratio` (фаза 5 H-09, 10 ₽; вход-заглушка `99-raw/phase5/inputs/H/texture_rolled_stub.png`,
  `mask_seam_cross_white.png`).
- Геометрические паттерны — не растр: SVG/CSS кодом (`VEC-PATTERN`, `../07-vector-svg-icons/03-icon-sets-and-patterns.md`).
- На странице: `background: url(tile.avif) repeat; background-size: 256px` — размер тайла в CSS-пикселях задаёт масштаб
  фактуры; тайл 512–1024 px для DPR 2; паттерн «плывёт» между соотношениями, если генерировать под каждый формат отдельно —
  один тайл + код (W3-11, C1-13).

## 3. Бандинг градиентов

H/05b: тёмный градиент hero `#0B1026` → `#2E1E54` со свечением, 1024×576, эталон — float64; «лестница» — амплитуда ступеней
профиля яркости в кодах (float 0,03; 8 бит 0,20):

| Вариант | PNG 8 бит | AVIF q60 | AVIF q80 | WebP q80 | JPEG q85 |
|---|---|---|---|---|---|
| 8 бит без дизеринга | 0,197 (45 КБ) | 0,381 (1,5 КБ) | 0,394 (2,8 КБ) | 0,351 | 0,316 |
| TPDF-дизеринг ±1 младший бит | **0,065** (433 КБ) | 0,335 (1,3 КБ) | 0,355 | 0,397 | 0,334 |
| зерно σ = 2 | 0,256 (631 КБ) | 0,320 (3,3 КБ) | 0,306 (**34 КБ**) | 0,278 | 0,261 (29,8 КБ) |
| 16-бит мастер → AVIF 10 бит, декод в 8 бит | — | 0,361 (1,0 КБ) | 0,312 (1,8 КБ) | — | — |

- Кодек съедает шум ±1 код: дизеринг, сделанный до сжатия, после AVIF/WebP/JPEG не виден — гипотеза «дизеринга перед
  кодированием достаточно» (волна 1, [V:y6GCXcLVYd4 18:33–19:36]) **не подтверждена** [проверено].
- Что делать: (1) гладкий фон — CSS-градиентом (0 байт, браузер рисует без 8-битного файла); (2) растр с градиентом — зерно/шум
  **поверх** после декодирования (SVG `feTurbulence` или маленький тайл шума с `mix-blend-mode`), 1–3 % против «пластика»;
  (3) повышение качества AVIF бандинг не лечит (q60 0,381 → q80 0,394) — лечит только шум поверх или CSS; 16-битный мастер
  «Reduces banding a lot» — это про производство [V:y6GCXcLVYd4 16:26–17:31], а не про веб-файл.
- Метрика для видео и сложных сцен — CAMBI (Netflix): 0 — нет бандинга, ≈ 5 — «slightly annoying», 24 — максимум
  [документация Netflix vmaf]; для видео — у I.
- Оговорки: один синтетический градиент; метрика «лестницы» чувствительна к шуму зерна (0,256 у PNG с зерном — шум, не
  ступени); дизерит ли Chrome CSS-градиенты и 10-битный AVIF при 8-битном выводе — не проверено (J).

## 4. Карты глубины

### 4.1 Depth Anything V2 Small против точной глубины Blender (H/06)

10 сцен 640² (2 сцены глубины + 8 объектов на циклораме), ORT 1.30 CPU, 4 потока; выравнивание масштаба и сдвига в
диспаритете (модель выдаёт относительный диспаритет):

| Вход | с/кадр | Пик ОЗУ | AbsRel комната / двор | δ1 комната / двор |
|---|---|---|---|---|
| 364² | 0,145 | 353 МБ | 0,059 / 0,070 | 0,992 / 0,928 |
| **518²** | **0,296** | **476 МБ** | **0,036 / 0,027** | 0,994 / 0,981 |
| 644² | 0,642 | 767 МБ | 0,048 / 0,047 | 0,995 / 0,948 |

- База «низ кадра ближе»: AbsRel 0,39 / 0,36, δ1 0,48 / 0,33 → модель даёт настоящую геометрию; порядок случайных пар
  пикселей верен в 98,4 / 99,5 %; небо (двор) — дальше 5-го перцентиля сцены у 99,9 % пикселей [проверено].
- Объекты на студийной циклораме (518²): на объекте AbsRel 0,022–0,042 (банка, кружка, флаконы, бокал, растение), мех 0,067,
  светлые кудри 0,116, проволочная корзина 0,104; на фоне-циклораме 0,06–0,28 (`object_vs_backdrop.json`).

```python
# onnxruntime 1.30 CPU · Depth Anything V2 Small (onnx-community, fp32, 99 МБ, Apache-2.0) · [проверено: H/06; сниппет прогнан дословно]
import numpy as np, onnxruntime as ort
from PIL import Image
so = ort.SessionOptions(); so.intra_op_num_threads = 4
sess = ort.InferenceSession("99-raw/tools/models/depth/depth_anything_v2_small.onnx", so, providers=["CPUExecutionProvider"])
img = Image.open("in.png").convert("RGB"); w, h = img.size
x = np.asarray(img.resize((518, 518), Image.BICUBIC), np.float32) / 255      # квадратный кадр; для 16:9 — стороны кратно 14 [не проверено]
x = ((x - [0.485, 0.456, 0.406]) / [0.229, 0.224, 0.225]).transpose(2, 0, 1)[None].astype(np.float32)
d = sess.run(None, {"pixel_values": x})[0].squeeze()                             # диспаритет: больше = ближе
d = np.asarray(Image.fromarray(d.astype(np.float32)).resize((w, h), Image.BILINEAR))
Image.fromarray(((d - d.min()) / (np.ptp(d) + 1e-6) * 65535).astype(np.uint16)).save("depth16.png")   # 16 бит — без ступеней
```

### 4.2 Что это значит для 2.5D на странице

- **Края**: AbsRel в полосе ±4 px вокруг разрывов — 0,18 против 0,02–0,03 вне полосы на сценах глубины (×6–9), на объектах
  ×1,2–1,7; 17–44 % пикселей полосы получают промежуточную глубину → в параллаксе/3D-фото контур растягивается «резиной».
  Рецепт: слой переднего плана — по альфе выреза (H/01), его глубина — медиана диспаритета внутри альфы (или карта внутри
  слоя, расширенная на 4–8 px наружу), фон — отдельный слой с дорисованной подложкой под объектом (§5) [проверено: H/06;
  рецепт — практика].
- **Порог глубины ≠ вырез**: маска по Оцу — IoU с альфой 0,20–0,93; по эталонной глубине — 0,17–0,80, потому что пол
  циклорамы перед объектом ближе объекта [проверено].
- **Мех, волосы**: гладкий «ком» с ореолом, полнота краёв 8,5–9,5 px — край пушистого объекта брать из альфы матирования.
- **Стекло**: модель видит тело бокала (AbsRel 0,02 при подгонке по объекту) — стекло движется вместе с объектом, что и
  нужно в параллаксе.
- **Циклорама и бесшовный студийный фон**: глубины «нет» по замыслу — ошибка 0,06–0,28; фон двигать плоским слоем.
- Для видео-глубины (мерцание между кадрами) — Video-Depth-Anything или хостинг (`../02-providers-platforms/05-open-weights-landscape.md`
  §5) — не проверялось; в браузере — `onnx-community/depth-anything-v2-small` через Transformers.js (19–99 МБ весов,
  «по требованию», не на первом экране) — вопрос J.

## Частые ошибки

- Два разных интерполятора LUT (Pillow для картинок, ffmpeg для видео) — серия расходится на сотые ΔE неизвестно где.
- Грейд на AVIF/WebP-выходе, а не на мастере — повторное сжатие и бандинг.
- «Seamless tileable» в промте принят за тайл без проверки сдвигом.
- Зеркальная плитка для ткани или камня — узнаваемая симметрия.
- Смешивание со сдвинутой копией на регулярной сетке — двоение нитей.
- Дизеринг в PNG перед AVIF «против бандинга» — после кодека его нет; PNG с дизерингом весит ×10.
- Глубина на 1024+ px «для точности» — хуже и дольше, чем 518.
- Параллакс по сырой карте глубины — «резиновые» края; маска слоя по порогу глубины — пол прилипает к товару.
- **Ошибки нейросетей-агентов**: «у модели X есть параметр tile» (в polza — нет); Depth Anything V2 Large в коммерческий
  конвейер (CC BY-NC); «10-бит AVIF решает бандинг»; перенос цвета Reinhard с чужой сцены как «бренд-грейд»; ΔE палитры к
  эталону другой сцены как цель.
