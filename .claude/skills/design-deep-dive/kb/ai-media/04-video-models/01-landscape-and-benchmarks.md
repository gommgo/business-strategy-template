## Выжимка для агента

1. **Верхушка сентября 2026 в обеих аренах одна**: Gemini Omni Flash (Google), Wan 3.0 (Alibaba), MiniMax H3 / H3 Max,
   Seedance 2.0 / 2.5 (ByteDance); Veo 3.1 и Kling 3.0 — второй эшелон → §2 `[исследование, консенсус двух арен]`.
2. **Разница меньше ~15 Elo незначима**: у AA 95 % доверительный интервал ±6…13 Elo; «Wan 3.0 1336 против Gemini Omni
   1330» — ничья → §2.1 `[исследование]`.
3. **Для беззвучных фонов смотри рейтинги «No Audio»**: AA по умолчанию показывает «With Audio», а порядок меняется —
   без звука T2V лидирует Wan 3.0, со звуком I2V — MiniMax H3 Max → §2.1 `[исследование]`.
4. **Арены меряют общее впечатление на обычных промтах**, а не петли, неподвижную камеру, сохранность логотипа или
   попадание в заданный кадр — для этих задач нужны свои тесты (`03-capabilities-by-task.md`) → §4 `[консенсус]`.
5. **Цена «за минуту» у AA — 1080p на умолчаниях вендора** (со звуком, если он по умолчанию включён); у страницы
   провайдеров AA — 720p 5 с; сравнивать с ₽/с polza только после приведения → §2.1 `[документация AA]`.
6. **Лучшее «качество за деньги» в сентябре 2026 — MiniMax H3 Max**: №1 I2V со звуком (1195) и №3 T2V со звуком (1227)
   при $2,40/мин; в polza — 9,44 ₽/с плоско → §2.3 `[исследование]`.
7. **Открытые веса догнали закрытые**: MiniMax H3 (открытые веса) — №3 T2V без звука (1302) и №4 I2V без звука (1354);
   дальше LTX-2.5, NVIDIA Cosmos3, MAGI-2 → §1.3 `[исследование]`.
8. **За 12 месяцев поменялись все флагманы**: Veo 3 → 3.1, Kling 2.5 Turbo → 3.0, Seedance 1.0 → 2.0 → 2.5, Wan 2.5 →
   3.0, Hailuo 02/2.3 → H3, Grok Imagine → 1.5; появились Gemini Omni, HappyHorse; Sora 2 уходит из API 24.09.2026 → §1.2
   `[документация]` + `[исследование]`.
9. **Главные сдвиги года**: звук по умолчанию, 15–30 с за проход, «всё в одной модели» (t2v/i2v/кадры/референсы/правка),
   мульти-шот по умолчанию, черновые режимы, китайские вендоры в топе, открытые веса в топ-5 → §1.4 `[консенсус]`.
10. **Мульти-шот по умолчанию — ловушка для фонов**: Gemini Omni и Kling API монтируют несколько планов, если не
    запретить («single continuous shot») → §1.4 `[документация]`.
11. **Veo 3 → Veo 3.1 почти не сдвинул общий рейтинг** (AA T2V без звука 1211 → 1213) — выигрыш 3.1 в управлении
    (кадры, референсы, extension), а не в «картинке» → §2.1 `[исследование]`.
12. **Seedance 2.5 на LMArena равна Seedance 2.0** (T2V 1474 против 1479, I2V 1477 против 1475); её плюсы — 30 с и до 50
    референсов, а не качество кадра → §2.2 `[исследование]`.
13. **Рейтинги меняются за месяцы**: Seedance 2.0 была №1 на LMArena 08.04.2026 (1450/1449), к 21.09.2026 — №5 →
    перед решением о маршруте перепроверяй арены и ставь дату → §2.4 `[исследование]`.
14. **Физику движения меряет AV-Phys Bench (май 2026)**: Seedance 2.0 V-PC 0,840 > Kling 3.0 Omni 0,716 > Veo 3.1 0,519 —
    независимо, но единичный источник и только модели со звуком → §3.3 `[исследование]`.
15. **VBench-2.0 полезен методикой, а не рейтингом**: «Camera Motion» по трекингу точек CoTracker, «Instance Preservation»,
    «Motion Rationality»; модели в статье — 2024–2025 гг. → §3.2 `[исследование, устарело]`.
16. **SeedVideoBench 2.0 — бенчмарк вендора** (ByteDance оценивает конкурентов сам): полезно как мнение с методикой, не
    как независимый рейтинг → §3.4 `[мнение вендора]`.
17. **Для петель есть только исследовательские метрики** — Cyclic Smoothness и Dynamic Score (Loopy, TOG 2026); наши
    практические — seam_ratio, cut_ratio, «живость» (опыт 02) → §3.5 `[исследование]` + `[проверено: опыт 02]`.
18. **Время генерации публикуется редко**: AA — Kling 3.0 720p ≈74 с, 1080p ≈95 с; HappyHorse 1.1 ≈112 с; MiniMax H3
    ≈115 с на ролик 5 с; Google — от 11 с до 6 мин → §2.3 `[исследование]` + `[документация]`.
19. **Не бери рейтинги с агрегаторов-«контент-ферм»** (например, llm-stats «Kling v3 leads with 1934» при «$0.17/M tokens»)
    — нет методики, противоречат обеим аренам → §4 `[мнение, отброшено]`.
20. **Нет в аренах (23.09.2026)**: Seedance 2.5 (у AA), Seedance 2 Fast/Mini, Luma Ray 3.2, Kling 3.0 Turbo, Wan 3.0 Prime —
    для них выводы только по документации и родственным моделям → §2.4 `[исследование]`.
21. **AA местами отстаёт от вендоров**: Runway Gen-4.5 помечен «No API available», хотя API есть [S29]; дата Grok

### 1.4 Главные сдвиги года

1. **Звук стал нормой**: Veo 3.x — «Always on» [S5]; Seedance 2.x — `generate_audio` по умолчанию `true` [S1][S15]; Wan 3.0
   — звук по умолчанию [S49]; Kling 3.0 и MiniMax H3 — нативный звук [S13][S25]. AA разделил рейтинги «со звуком» и «без».
   Для фонов сайта звук — лишняя дорожка, иногда лишняя цена `[документация]`.
2. **Длина за проход выросла**: 5–10 с в 2025 году → 15 с (Kling 3.0, Seedance 2.0, H3) → 30 с (Seedance 2.5, Wan 3.0);
   продление — до 40 с у Gemini Omni и до 148 с у Veo [S5][S6][S17][S22] `[документация]`.
3. **«Всё в одной модели»**: Wan 3.0 «All-in-One» (текст, кадры, до 20 референсов, документы, правка, продление) [S49],
   Seedance 2.x omni reference [S16], Kling 3.0 Omni [S53], Gemini Omni [S6], MiniMax H3 «unified» [S23]. Роль картинки
   (первый кадр или референс) теперь задаётся полем или тегом — и именно её часто теряют агрегаторы (polza, §2.2 файла 03).
4. **Мульти-шот по умолчанию**: Gemini Omni «By default… a few different shots» [S6]; Kling API `multi_shot` по умолчанию
   `true` [S10] → для фонов обязательно «single continuous shot» `[документация]`.
5. **Черновые режимы**: Seedance 2.5 Draft (480p → 1080p) [S17], MiniMax Regeneration (768P → 2K) [S24], Luma Draft
   (360p → master) [S34][S51] — официальный путь «дёшево выбрать → дорого доделать»; в polza не выставлены.
6. **Китайские вендоры в топе**: в топ-10 AA T2V без звука — Alibaba (Wan 3.0, HappyHorse ×2, Wan 2.7), ByteDance, MiniMax,
   Kuaishou, PixVerse; из США — Google и xAI [S40]. OpenAI уходит из видео-API [S36].
7. **Открытые веса в топ-5** (MiniMax H3) [S40].
8. **Агрегаторы стали нормой**: Runway Dev API продаёт чужие модели (Veo, Seedance, Wan, H3, Grok, Omni) [S29]; polza —
   через KIE; у агрегатора параметров меньше, чем у вендора (`02-model-cards.md` §7).
9. **Маркировка происхождения**: SynthID и C2PA у Google [S5][S6][S48]; китайская неявная метка `AIGC` в метаданных MP4 у
   ByteDance, Kuaishou, MiniMax — требование с 01.09.2025 [S48] `[проверено: опыт 02]`.

## 3. Бенчмарки с методикой: что меряют и чего не меряют

### 3.1 Арены (AA, LMArena)

- **Меряют**: общее предпочтение зрителя в слепом попарном сравнении на обычных промтах (T2V) или одной картинке (I2V);
  у AA — отдельно со звуком и без, отдельно правку видео [S40][S41].
- **Не меряют**: замыкание петли, неподвижность камеры, точность попадания в заданные кадры, сохранность логотипа и
  текста, стабильность серии, пригодность под наложение текста сайта, вес файла. Промты арен — «кино» и сюжеты, а не
  фоны сайтов `[вывод]`.
- **Ограничения**: цена у AA — за минуту 1080p на умолчаниях вендора (со звуком, если он включён по умолчанию); разные
  пулы голосующих; предварительные рейтинги новых моделей; дата снимка важна (§2.4).

### 3.2 VBench, VBench++ и VBench-2.0 (Vchitect)

- **VBench / VBench++** (TPAMI 2025): автоматические измерения — subject/background consistency, temporal flickering,
  motion smoothness, dynamic degree, aesthetic/imaging quality; есть VBench-I2V (согласованность с исходной картинкой,
  движение камеры) и VBench-Long; «VBench-I2V Arena» — с марта 2026 [S42] `[исследование]`.
- **VBench-2.0** (Zheng et al., arXiv 2503.21755, март 2025): 5 категорий / 18 измерений «внутренней достоверности» —
  Human Fidelity, Controllability, Creativity, Physics, Commonsense; оценка — VLM (LLaVA-Video-7B), LLM (Qwen2.5-7B) и
  детекторы; **Camera Motion** — 9 типов (включая орбиту и «airborne dolly») по трекингу точек CoTracker-v2;
  «Instance Preservation» — слияния и исчезновения объектов; «Motion Rationality» — фальшивое движение [S42].
- **Результаты устарели**: Camera Motion — Kling 1.6 61,73 %, HunyuanVideo 33,95 %, CogVideoX-1.5 33,33 %, Sora 27,16 %;
  Instance Preservation 82–94 %; Complex Plot ≈10 % [S42]. Моделей 2026 года (Veo 3.1, Kling 3, Seedance 2, Wan 3) нет.
- **Польза для базы**: методики мерцания, плавности, «dynamic degree» и камеры (CoTracker) — готовые инструменты агенту K
  для своих роликов; рейтинг — не использовать `[мнение]`.

### 3.3 AV-Phys Bench (май 2026)

- «Do Joint Audio-Video Generation Models Understand Physics?» (Cui et al., UTD/UW/UCLA, arXiv 2605.07061): 268
  «физических» промтов в трёх типах сцен (Steady State, Event Transition, Environment Transition) + «анти-физика»; оценка
  людьми (3 из 10 аннотаторов на элемент, Fleiss κ ≈0,63–0,69) и агентом на Gemini 3.1 Pro с DSP-инструментами [S43].
- **Результаты**: визуальная физика V-PC — Seedance 2.0 **0,840**, Kling 3.0 Omni 0,716, Veo 3.1 0,519, LTX-2.3 0,295, Ovi 1.1
  0,127; общий pass rate — 0,660 / 0,343 / 0,216; на переходах сцен падение до 67 % [S43].
- **Для сайта**: вода, дым, ткань, свет — материал фоновых петель; независимый тест 2026 года ставит Seedance 2.0 выше
  Kling 3.0 Omni и Veo 3.1 `[исследование, единичный источник, только модели со звуком]`.

### 3.4 SeedVideoBench 2.0 (ByteDance — бенчмарк вендора)

- Из технического отчёта Seedance 2.0 (arXiv 2604.14148): эксперты, шкала 1–5; T2V Motion — Seedance 2.0 3,75, **Kling 3.0
  3,10**, Veo 3.1 2,73, Kling 2.6 2,72, Sora 2 Pro 2,69, **Seedance 1.5 2,39**; «usability» движения (≥3) — Kling 3.0 82,8 %,
  Veo 3.1 67,1 %, Seedance 1.5 46,9 %; «Among competitors, Kling 3.0 is the most balanced overall, Sora 2 Pro stands out on
  prompt following, and Veo 3.1 is weaker on audio» [S20] `[мнение вендора с методикой]`.
- Нативные разрешения Seedance 2.0 — 480p и 720p («native output resolutions»); 1080p и 4K в API — выше натива [S20].

### 3.5 Метрики петли

- **Loopy** (Dong et al., ACM TOG 45, 2026): «Cyclic Smoothness» — склеить вторую половину ролика с первой и оценить
  плавность (VBench motion smoothness); «Dynamic Score» (GPT-4o) — ловит «статичный коллапс». EDEN (интерполяция по
  первому/последнему кадру): 0,9824 / 0,38; Loopy: 0,9925 / 3,20 [S44] `[исследование]`.
- **Наши практические метрики** (опыт 02, 28 публичных роликов вендоров): `seam_ratio` (шов / медианный шаг кадра;
  у незамкнутых роликов 3,4–102), `cut_ratio` (максимальный скачок / медиана; у мульти-шотов 18–84, у однопланных
  1,4–7), `motion_med`, `static_frac` [S48] `[проверено]`. Пороги приёмки — `03-capabilities-by-task.md` §2.5.

### 3.6 Не прочитаны целиком (кандидаты следующей волне)

PhysicsIQ (Motamed et al., 2026), PhyGenBench (2024), VideoPhy-2 (2025), PhyWorldBench (2025), T2VPhysBench (arXiv
2505.00337), VideoScience-Bench (arXiv 2512.02942) — физика; специализированного бенчмарка управления камерой для моделей
2026 года (CameraBench и др.) в выдаче не нашлось; бенчмарков петель, неподвижной камеры и сохранности логотипа в видео
нет вовсе `[не проверено]`.

## 5. Что это значит для базы и следующих волн

- **Маршрутизация (агенты E, N)**: рейтинг — только первый фильтр; решение по `VID-*` — по возможностям через polza
  (`02-model-cards.md` §2) и тестам фазы 5 (`03-capabilities-by-task.md` §15). Хранить дату снимка арены рядом с решением.
- **Оценка (агент K)**: взять из VBench/VBench-2.0 метрики мерцания, плавности, «dynamic degree» и камеры (CoTracker), из
  Loopy — Cyclic Smoothness/Dynamic Score, из опыта 02 — seam_ratio и cut_ratio; откалибровать пороги на глаз заказчика.
- **Видео-конвейер (агент I)**: проверить «две половины», кроссфейд, пинг-понг, обрезку дубля кадра на открытых образцах;
  метрики — те же.
- **Провайдеры (агент P)**: доступ к Luma Ray 3.2 (`loop`), прямым API Seedance (FLF, Draft, `camera_fixed`) и Wan 3.0
  (FLF, правка) из России — там лежат возможности, которых нет в polza.
- **Обновление**: при появлении новой модели — снимок каталога polza, AA «No Audio» и LMArena I2V, минимальный тест петли
  (№1-подобный) на новой модели.

## Частые ошибки

1. **Смотреть рейтинг AA «со звуком» для беззвучного фона** — порядок моделей другой.
2. **Считать разницу 5–10 Elo победой** — это внутри доверительного интервала.
3. **Переносить место в арене на задачи сайта** (петля, статика, логотип) — арены этого не меряют.
4. **Брать выводы VBench-2.0 о камере для моделей 2026 года** — там модели 2024–2025 гг.
5. **Сравнивать цену AA ($/мин 1080p на умолчаниях) с ₽/с polza напрямую** — разные разрешения, звук и курсы.
6. **Верить бенчмарку вендора как независимому** (SeedVideoBench — ByteDance оценивает конкурентов).
7. **Цитировать рейтинг без даты** — за полгода лидер сменился трижды.
8. **Брать «лидерборды» агрегаторов без методики** (llm-stats и подобные).
9. **Выбирать модель «по памяти»** (Sora 2, Kling 2.1, Hailuo 02) — в сентябре 2026 это устаревшие или снимаемые модели.
