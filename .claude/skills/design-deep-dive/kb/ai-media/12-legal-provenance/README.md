2. Сам — абстракция, иконки, иллюстрации, окружение без людей; спрашиваю — реалистичные люди, «место как настоящее», метки
   вендора; не делаю — отзывы/команда/знаменитости, товар «как есть», чужие знаки, стиль живого автора по имени (`04` §2).
3. Дипфейк по ЕС — реалистичные люди, объекты, **места и события**, способные сойти за подлинные; фон за реальным товаром —
   обычно нет (Руководство п. 113–116).
4. Видимая метка — иконка ЕС «AI GENERATED / MODIFIED» в правом верхнем углу: 0,35 % площади кадра, контраст 10–18 : 1 (L/03).
