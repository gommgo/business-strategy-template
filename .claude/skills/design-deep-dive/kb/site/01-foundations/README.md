## Выжимка

1. Бриф — один YAML по `site-brief.schema.json`; в kimi уходит проекция по `site-brief.kimi-map.tsv`, не сам бриф.
2. Смысл — блок `meaning` по схеме text, доказательства — только `proof.facts_ref` на `facts.yaml` text; нет факта — нет блока.
3. Тип — `site_type` + `primary_page_type` (словарь B); действие — одно macro-id `action`; вторая цель — иным стилем.
4. Первый экран продолжает обещание источника; путь до просьбы — по осведомлённости и температуре трафика.
5. Модели решения — языки диагностики, не законы; решение — по данным и тестам по методике P.
6. Доверие — способность, доброжелательность, честность; реальная организация и внешние отзывы сильнее лиц со стока.
7. Кейс — гипотеза, не норма; «+N %» — с базой, числом конверсий, длительностью и метрикой до сделки.
8. Косметика (цвет, кнопки, формулировки призывов) в среднем даёт ноль; «средняя конверсия отрасли» — не цель.
9. Срочность, дефицит, соцдоказательство, гарантии — только на реальных фактах; ложные — тёмный паттерн и нарушение.
10. Пустое поле брифа — решение модели: минимум по типу проверяет схема, допущения — вопросы в статусе `assumed`.
