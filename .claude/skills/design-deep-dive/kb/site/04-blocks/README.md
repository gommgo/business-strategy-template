## Выжимка

1. Роль секции (C) → блок из `blocks.yaml` → структурный вариант; подача — creative, тексты — text по id слота.
2. Отдельный блок — другое назначение или набор слотов; раскладка — вариант (`hero-media`: 7 вариантов).
3. Нет факта — нет блока: числа, отзывы, логотипы, цены, люди — только data-слоты `fact:` с `binds`; пробел — `missing:` с `on_missing`.
4. Hero — по задаче, со словесным H1 и своим кадром телефона; политика первого экрана — поле плана (A3 kimi).
5. Цена у ЛУ — рано; калькулятор — до 3 параметров (4–5 — с причиной), иначе цены типовых случаев; сравнение — до 5 колонок.
6. Главный призыв повторяется, второй путь — иным стилем; липкое, баннер cookie, чат, окна — в `overlays`.
7. Разметка: `<header>` — только шапка, секции — `<section>` в `<main>`, один H1, DOM = визуальный порядок.
8. Телефон: сворачивать, перекадрировать, лентой с краем — не вырезать смысл, цены, условия, доказательства.
9. Элементы групп в плане — `группа.элемент`, экземпляры — `группа-N`; стык с copy-deck — прямой перенос полей.
10. Каталог покрывает роли 234 секций 22 живых страниц (E/04); раскладку по тексту не отличить — нужен кадр (M).
