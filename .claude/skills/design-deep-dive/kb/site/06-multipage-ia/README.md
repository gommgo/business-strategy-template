## Выжимка

1. Карта сайта пишется до `page-plan`: страницы, шаблоны, родители, URL, коллекции, навигация, порядок сборки (01 §1).
2. Карта по умолчанию — по `site_type` (01 §2); список брифа её дополняет; страница без фактов — `blocked-facts`.
3. Серия однотипных страниц — шаблон с коллекцией, один `page-plan` и 1–3 образца; главная — отдельный шаблон (01 §3).
4. У раздела с подстраницами — хаб; «услуга × город» — только с уникальными фактами и местом в иерархии (01 §3.4, §3.6).
5. Модель контента — коллекции, поля, связи; цены, люди, адреса — `fact-ref` один раз; связи порождают перелинковку (01 §4).
6. Шапка, подвал, крошки и поиск — один раз в `site-map.chrome`; каждый пункт ведёт на страницу карты (02 §1).
7. Архетип шапки — один из 7 по структуре сайта; подменю — по клику, ссылка + кнопка, без роли `menu`; гамбургер на
   десктопе запрещён (02 §1.2–§1.3).
8. Подвал: служебные ссылки всегда, группы из реальных страниц, на телефоне открыт; крошки — с глубины ≥ 2, на телефоне
   одна строка (02 §1.4, §2.1).
9. Ссылки навигации — `<a href>` в исходном HTML; у индексируемой страницы ≥ 1 входящая ссылка; URL строчными, транслитом,
   глубина ≤ 3 (02 §3–§4).
10. Второй язык — `/en/`; переключатель — самоназвание языка, на ту же страницу, без автоперенаправления; сборка — сначала
    главная с общими шапкой и подвалом (02 §5, 01 §6).
