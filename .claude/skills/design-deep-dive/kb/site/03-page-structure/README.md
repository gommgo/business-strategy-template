## Выжимка

1. Порядок секций выводится из вопросов посетителя: тип страницы → осведомлённость → источник трафика → макроструктура → роли.
2. Роль секции — вопрос, на который она отвечает; блок — форма ответа; роль с доказательствами — только при фактах.
3. Каркасы (AIDA, PAS, StoryBrand, Big 8) — чек-листы полноты, сравнительных данных нет.
4. Живые страницы: медиана 10 секций; цена у лидогенерации — рано (позиция 0,31); FAQ — в конце (0,90); шаблон
   «hero → фичи → отзывы → тарифы → CTA» — 1 из 30.
5. Длина — сколько доводов нужно трафику: коротко для дешёвого и горячего, длинно для дорогого, тревожного и холодного.
6. Одна страница — одно действие; меню сайта с посадочной под платный трафик убирать, логотип и контакты оставлять.
7. Первый экран продолжает обещание источника; подстановка по параметру — только из белого списка и до отрисовки.
8. Первый экран: оффер, признак продукта, доказательство, призыв, признак продолжения; ядро ≤ 40 слов.
9. Политика первого экрана — поле `page-plan` (`offer-cta` по умолчанию, `poster` — для кампаний L2 и писем по условиям).
10. Телефон: тот же порядок секций в DOM, детали свёрнуты, hero — свой кадр; баннеры и липкие слои не закрывают призыв.
