## Выжимка для агента

1. **Раздел 0 читать первым**: слова с двумя смыслами в базе, у соседей и у сестёр; выбранный вариант перевода обязателен в
   новых файлах. `[практика]` → §0
2. **Конверсия — событие успеха, подтверждённого сервером, а не клик**; доля — «коэффициент конверсии». `[документация: Метрика]`
   → 05/01 §9.3
3. **Посадочная ≠ лендинг**: посадочная — страница под трафик (`page_type landing-*`), лендинг — сайт из одной посадочной
   (`site_type landing-site`). `[практика]` → 02/01 §2–§3
4. **Секция ≠ блок ≠ вариант**: роль отвечает на вопрос посетителя, блок — форма ответа, вариант — раскладка блока.
   `[практика]` → 04/01 §1.1
5. **«Уровень», «профиль», «шаблон» — только с уточнением**: у каждого слова в базе три-четыре смысла. `[практика]` → §0
6. **Id словаря не переводить и не придумывать**: в YAML — только id `vocabulary.yaml` (443), чужие — с пространством имён.
   `[практика]` (контракт тройки §3) → 02/02 §2
7. **Температура трафика — сила намерения по источнику**; осведомлённость — отдельная ось; отношения с брендом — признак
   источника. `[практика]` → 01/01 §3
8. **Ворота, пункт чек-листа и маркер — разные инструменты**: порог исхода; проверка любым способом; признак решения без
   причины. `[практика]` → 07/03 §4; 09/02 §1; 09/01 §4

## Частые ошибки

- «Клик по кнопке — конверсия»: цель по клику завышает заявки (автоцель Метрики считает и неудачные отправки).
- «CTA-матрица» ux в плане сайта: действия посетителя — пространство `action`, объектная модель лендингу не нужна.
- Ключ `section_role` из `effects.yaml` creative принят за роль секции сюжета.
- В новых файлах — «сопоставление с объявлением», «бустер тревоги», «сдерживающая метрика», «ложноположительный результат»:
  выбранные варианты — раздел 0.
- «Лендинг» в значении «любая посадочная» в правилах уровня сайта — путает `site_type` и `page_type`.
- «Профиль», «уровень», «S2» без уточнения.
- Самодельные id секций (`kak-rabotaem`) вместо id роли или блока (`how-it-works`).
