## Выжимка на 10 строк

1. Пиши для сканирующего и для читающего подряд: заголовки секций пересказывают страницу, суть — в первом слове строки.
2. «Читают 20 %», «79 % сканируют», «57 % над сгибом» — числа 1997–2018 годов с узкими выборками: только с годом и материалом.
3. Первый экран словами объясняет, что это и для кого; ядро hero ≤ 40 слов (по-русски 30 с ≈ 75–95 слов, не 150).
4. На телефоне понимание не хуже (2016), трудный текст медленнее: режь сложность и воду, а не смысл.
5. Оценки → факты → сценарий («и что с того?»); три вопроса к фразе: представить, опровергнуть, «конкурент не скажет».
6. Рекламный язык ≈ −21 % к объективному (1997; значима только удовлетворённость); превосходные степени вредят.
7. Длину задают цена, тревога и осведомлённость; кейс «+220 %» — не норма; A/B доказывает только для своей страницы.
8. Лендинг — активация: доводы и условия обязательны; эмоция — сценой; вопрос и негатив в заголовке — не по умолчанию.
9. Формула — каркас после смысла и фактов; `page`-формулы — порядок секций у site C.
10. Балл Главреда и формулы читаемости — сигналы, не ворота: гладкая пустота получает лучший балл, чем факты.
