## Выжимка на 10 строк

1. Голос постоянен, тон сдвигается по ситуации; голос бренда — сайт до входа и письма вокруг форм, голос продукта — кабинет.
2. Голос выводят из назначения, аудитории, цены ошибки и голоса клиента; прилагательные брифа — сырьё, не принципы.
3. Принцип = имя + ≥ 2 проверяемых правила исполнения + «каким не бывает»; «мы не» — соседний перегиб, а не антоним.
4. «Вы» со строчной по умолчанию; юмора нет в цене, гарантии, праве, согласиях и ответе на жалобу; эмодзи и «!» — по профилю.
5. Голос не меняет факты, оговорки и длины слотов — после смены голоса длины перепроверяются (E).
6. Редполитика — методичка ≤ 12 строк с образцами для генератора, полная версия для проверки и журнал ошибок.
7. Числа в утверждениях — цифрами: сверка не видит «пять лет»; оценку — фактом, голый факт — сценарием.
8. Проходы: смысл → факты и право → структура → слова и голос → набор → регресс → человек.
9. История — доказательство с героем: каждое предложение из факта, конфликт в первой фразе, деталь работает на решение.
10. Код не видит выдуманную сцену, голый факт и английскую выдумку без английского словаря профиля — их проверяет человек.
