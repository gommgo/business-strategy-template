**Выжимка B1 (10 строк).**
1. Смысл начинается с альтернатив клиента (включая «ничего не делать»), а не с функций и не с категории.
2. Отличие — только с доказательством из `facts.yaml`; проверка «только мы»: подставь альтернативу — осталось правдой?
3. Категория выбирается последней и называется словами клиента; стратегия категории задаёт тип hero.
4. У каждого утверждения смысла — основание; допущение → вопрос заказчику (≤ 10, в сообщении ≤ 7), не обещание.
5. Главное сообщение не пишется до сбора фактов: бриф даёт 6–24 % смысла, факты — ещё около трети.
6. Уровень осведомлённости трафика задаёт hero, порядок доказательств и длину аргумента; стадия рынка — на чём держать обещание.
7. Одна иерархия — один уровень: 1 главное сообщение, 3–5 опор с доказательствами и возражениями, у секции — один вопрос.
8. Иерархию строят от цели назад: действие → возражения → ответы с доказательствами → опоры → главное сообщение.
9. Возражения-блокеры снимаются до главного призыва; тревогу — доказательством и снятием риска, привычку — малым обратимым шагом.
10. Снятие риска — только реальные условия из фактов; порядок и набор секций решает site, слова — text.

**Выжимка B2 (10 строк).**
1. Любое число, имя, дата, цитата, логотип, рейтинг, цена, гарантия текста — запись `facts.yaml`; нет записи — `[PLACEHOLDER]`.
2. Факт — от источника вне модели и с дословной выдержкой `source.quote`; вывод агента — вопрос, не факт («сборка в Казани»).
3. Текст не сильнее факта: не больше, не точнее, не о другом объекте, не шире по смыслу.
4. Объективное и точное убеждает сильнее оценочного, но точное — только из источника; у скоропортящегося — источник и дата.
5. Отзывы: первые пять важнее всего, 5,0 и одни восторги вызывают сомнение; подробный отзыв сильнее похвалы.
6. Цитата — дословно (опечатки и многоточие — можно, смысл — нет); без отбора лучших; связь автора — рядом; результат — с обычным.
7. `never_claim` запрещает непроверенное, а не весь слой доказательств; голос компании ≠ цитата клиента.
8. Доказательства собирают анкетой `proof-intake.md` до текстов, с разрешениями, сроком и ответственным.
9. Голос клиента — дословные фрагменты с кодами и темами; частота ≠ важность; кодируют двое; цитата на сайте — только из `facts.yaml`.
10. `claims_check.py` на copy deck — ворота: «Кварц» 3 из 3, ложных 1 из 40; на живых лендингах источник виден у 25 % доказательств.
