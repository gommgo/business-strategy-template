# Словарь перевода жаргон → язык бизнеса

Скилл общается с клиентом **только** правой колонкой. Слой про разведку
клиентов — поэтому язык про **людей и их поведение**, не про методологию.

## Сущности

| жаргон | бизнес |
|---|---|
| сегмент (segment) | «группа ваших клиентов» / «тип клиента» (по общей цели, не по возрасту/полу) |
| segment-slug / папка | не упоминается |
| работа (job) | «что ваш клиент пытается сделать», «какую задачу он решает для себя» |
| Big Job (верхняя работа) | «зачем ему это в конечном счёте», «к чему он в итоге стремится» |
| Core Job (целевая работа) | «главное, ради чего он к вам приходит / за что платит» |
| low / работа-шаг | «мелкий шаг», «что конкретно он для этого делает» |
| `so-that` / «чтобы» | «зачем ему это — чтобы что?» |
| `when` / контекст+триггер | «в какой момент / после чего он за это берётся» |
| `want` / результат | «какой результат он хочет получить» |
| success-criteria | «по чему он поймёт, что получилось хорошо» |
| тип работы (разовая/частотная/…) | (внутреннее; клиенту — «это бывает раз / повторяется регулярно / тянется цепочкой») |
| решение (solution) | «чем он пользуется сейчас, чтобы это сделать» |
| hire / «нанимает» | «к чему он прибегает», «что выбирает для этого» |
| product/service/diy/substitute/inaction | «готовый продукт / услуга / делает сам / обходится по-другому / ничего не делает» |
| satisfaction | «насколько он этим доволен» |
| price-value-fit | «стоит ли это своих денег, по его мнению» |
| competitor / конкурент | «кто ещё делает похожее для этих людей» |
| трение / проблема сегмента (segment-problem) | «где у него не получается», «что выходит плохо» |
| strength (сила трения) | «насколько это болезненно для него» |
| drivers | «почему он всё равно так делает / не бросает» |
| barriers | «что мешает ему перейти на что-то лучше», «чего он боится / в чём сомневается» |
| граф работ (job-graph) | «путь клиента целиком» |
| CPR / критический путь | «обязательные шаги, без которых ничего не получится» |
| value-mechanics / 11 механик | (не упоминаем; это идеи ценности — собирает аналитик) |
| Score сегмента | (не упоминаем; приоритет групп — аналитик) |

## Поля и процедуры

| жаргон | бизнес |
|---|---|
| slug / kind / status | не упоминается |
| draft / stable | «в работе» / «закрыто» |
| research / рой / web-research | (не упоминаем; просит — эскалируем: «отправим помощников поискать») |
| JTBD-интервью | «разговор с вашим клиентом» / «запись интервью» |
| маппинг на конкурента/офер (maps-to) | «это, по сути, конкурент N» / «это наш собственный продукт» |
| feeds-problem | «это бьёт по такой-то задаче бизнеса» |
| фаза / phase | «блок» / «тема разговора» |
| promote draft → stable | «закроем этот блок?» |
| escalation | «передать аналитику» |
| branch / push | «отдельная папка для аналитика» / «отправить» |

## Главное про характер разговора (проговаривать)

- «Это **разведка**: мы складываем картину про ваших клиентов, чтобы
  потом точно понять, что строить. Тут нет обещаний-цифр — мы выясняем,
  что людям реально нужно.»
- Спрашиваем про **прошлое и реальные поступки** клиента, не про мечты:
  «что он **делал** в прошлый раз», а не «что он хотел бы».
- «Работа» клиента — это **его цель**, а не наш продукт и не кнопка в
  приложении.

## Чего никогда не говорить

- «Это draft / stable», «slug в kebab-case».
- «Это job уровня Core», «Big Job», «CPR», «применим механику №7».
- «Сегмент» как термин — говорим «группа клиентов».
- «Гарантируем, что клиенты так себя поведут» — это разведка, не
  обещание.
- «Spawn agent / рой / web-research» — не упоминаем (просит — эскалируем).

## Как формулировать критерии и anti-patterns

Вместо «работа = решение, нарушение ядра» →
> «Звучит как описание вашего будущего продукта. А что человек **сам
> пытается сделать** — какую свою задачу он закрывает?»

Вместо «гипотетика вместо поведения» →
> «А в прошлый раз он что **сделал** на самом деле — на что потратил
> время или деньги? По этому виднее, чем по “хотел бы”.»

Вместо «демография как сегмент» →
> «“Женщины 25–35” — это про возраст. А что этих людей объединяет по
> сути — какую одну большую цель они все пытаются достичь?»

Вместо «проблема без решения» →
> «Где именно не получается — и с чем именно он это делал, когда не
> получилось? Трудность всегда привязана к тому, чем человек
> пользовался.»

## Если клиент использует жаргон

Подхватываем его язык, не «переучиваем», но остаёмся на пол-шага проще.
