# Формат заметок `state/`

Память скилла — рабочее состояние знания о сущности. Не журнал.
Forward-only.

## Расположение

```
.claude/skills/business-problem-deep-dive/state/
├── frame.md                  (singleton: frame-заметка)
├── factor/<slug>.md
├── bet/<slug>.md
├── goal/<slug>.md
├── metric/<slug>.md
├── subject/<slug>.md
├── hypothesis/<slug>.md
└── task/<slug>.md
```

Заметки лежат **рядом со скиллом**, не в `docs/business-problem/`.
Каталоги создаются по требованию.

## Шаблон kind-заметки

```markdown
---
kind: metric
slug: paid-churn
ref: docs/business-problem/metric.md#paid-churn
---

## Открытые вопросы
- (**blocker**) Какой источник истины для оттока — CRM или биллинг?
  От этого зависит формула.

## Доменные решения
- Атрибуция = A/B vs контроль (не baseline-период), потому что
  сезонность сильная — нужен контроль.

## Что копать дальше
- После согласования с бизнесом — добавить guardrail на маржу.
```

Frontmatter: `kind` (один из 8), `slug` (для frame отсутствует), `ref`.

## Секции (все опциональны)

- **`## Открытые вопросы`** — незакрытые смысловые вопросы, одна строка
  каждый. Префикс/суффикс `**blocker**` блокирует `draft → stable`.
  Закрытый вопрос **удаляется** (не зачёркивается). Пусто → удалить
  секцию.
- **`## Доменные решения`** — неочевидные смысловые решения, не лезущие в
  таблицу. Форма «⟨что выбрано⟩ — ⟨почему⟩». Без «было/стало», без дат.
  Растворилось в записи → удалить.
- **`## Что копать дальше`** — локальные следующие шаги по сущности.
  Выполнен → удалить строку.

## Жизненный цикл

- **Создаётся** только когда есть что записать (≥1 непустая секция).
- **Перезаписывается** свободно.
- **Удаляется**: все секции пусты → файл; запись удалена каскадом → файл.
- **Не аккумулировать** журнал (история — в git).

## Особый случай: `_phase-jump.md`

`state/<phase>/_phase-jump.md` фиксирует решение перепрыгнуть фазу (напр.
`state/goal/_phase-jump.md` — «начали с цели, минуя SWOT, потому что
бизнес дал ясную цель») как доменное решение. Не блокер.

## Read-only видимость клиентского скилла

Скилл может read-only смотреть
`../business-problem-deep-dive-for-business/state/<kind>/<slug>.md` —
что наработал клиент. **Писать туда запрещено.**
