# Чек-лист `draft → stable`

После каждой правки скилл прогоняет 5 пунктов. Все ✅ → предлагает
аналитику повысить через `AskUserQuestion`. **Не повышает сам.**

## 5 пунктов

1. **Обязательные слоты заполнены** (см. `field-checklists.md`).
   Опциональные могут быть `—`. `frame` — все пять разделов; `hypothesis`
   — четыре части `if/then/because/so`.
2. **`Критерии <kind>` пройдены** — каждый критерий из секции в
   `docs/business-problem/<kind>.md` явно подтверждён аналитиком через
   `AskUserQuestion` (не «скилл уверен», а «аналитик нажал ✅»).
3. **`Что <kind> НЕ` не нарушены** — по каждому anti-pattern скилл
   спросил «не похоже ли?» и получил ❌. Один подтверждённый anti-pattern
   блокирует stable до переформулировки.
4. **`Тест-критерий` ✅** — аналитик прошёл бинарный вопрос из секции.
5. **Нет `**blocker**`-вопросов** в `state/<kind>/<slug>.md`.

Все 5 ✅ → `AskUserQuestion`: «Запись `<kind>:<slug>` прошла все 5
пунктов. Повышаем `draft → stable`?» (Да / Нет, ещё подумаю / Да, но
сначала закрою: Other). По «да» — `status: draft → stable`.

## Особое для этого слоя

- **Метрика** не становится stable, пока нет `source`, `attribution`,
  `acceptance` и хотя бы одной парной `balancing`-метрики у целевой.
- **Гипотеза** не становится stable, если «тогда» не ссылается на
  существующую метрику или «потому что» не опирается на мотивацию
  субъекта.
- **Задача** не становится stable без привязки к гипотезе.
- **frame** не становится stable, если метрика где-то подана как гарантия
  (нарушение юр-рамки).

## Понижение `stable → draft`

Скилл **сам не понижает**. Подсвечивает («запись stable, но критерий X
нарушен / появился `**blocker**` / соседняя запись удалена») и через
`AskUserQuestion` предлагает понизить. Только по «да» — меняет status.

## Когда чек-лист нельзя пройти — это нормально

Сущность может проектно не дойти до stable (нужно интервью, замер,
решение бизнеса). Не «натягивать» stable: закрыть запись `draft`,
оставить `**blocker**` в state, предложить следующий шаг по `phases.md`.
Stable-запись, ссылающаяся на draft, — допустимо (`stable` = «прошла свои
критерии», не «вся цепочка зрелая»).
