# Словарь перевода жаргон → язык бизнеса

Скилл общается с клиентом **только** правой колонкой.

## Сущности

| жаргон | бизнес |
|---|---|
| profile | «чем занимаетесь и как зарабатываете» |
| segment | «кого обслуживаете» / «ваши клиенты» |
| offering | «что продаёте» / «продукт / услуга» |
| channel | «как привлекаете и продаёте» / «канал» |
| competitor | «кто на рынке делает похожее» / «конкуренты» |
| current-metric | «ключевое число» / «текущий показатель» |
| material | «материал» / «документ» (сайт, презентация, PDF) |

## Поля и процедуры

| жаргон | бизнес |
|---|---|
| slug / kind / status | не упоминается |
| draft / stable | «в работе» / «закрыто» |
| description | «коротко, одним предложением» |
| needs | «что им нужно от вас» |
| value | «какую пользу приносит» |
| value (метрики) | «сколько сейчас» |
| as-of | «на какую дату» |
| source | «откуда это число» / «из какого отчёта» |
| position | «прямой конкурент / косвенный / замена» |
| uri | «ссылка или файл» |
| research / рой | (не упоминаем; просит — эскалируем) |
| escalation / branch / push | «передать аналитику» / «отдельная папка» / «отправить» |

## Важное про числа

- «Назовите число и **на какую дату** оно, и **откуда** взято (из какого
  отчёта/системы). Это станет точкой отсчёта.»
- Не помнит точно → «ничего, пометим уточнить — аналитик поможет
  поднять».
- Это **текущие** числа («как есть»), не цели — цели будут позже.

## Чего не путать (проговорить мягко, если всплывёт)

- «Кого обслуживаете» (ваши клиенты сейчас) ≠ «кто будет пользоваться
  продуктом, который сделаем» — второе обсудим позже, это другой разговор.

## Чего никогда не говорить

- «Это draft / stable / slug / kind».
- «По канону слоя business…».
- «Spawn agent / рой».

## Если клиент использует жаргон

Подхватываем, не переучиваем, остаёмся на пол-шага проще.
