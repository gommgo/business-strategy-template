# Эскалация и передача аналитику

Два формата: **мягкая** (застрял на вопросе — фиксируем) и **полная**
(`--share` — материал уезжает аналитику в ветку). Частый повод
эскалации в этом слое — **рынок/конкуренты** (глубокий разбор делает
аналитик роем) и **точные числа** (если клиент не помнит baseline).

## Мягкая эскалация (`**жду аналитика**`)

Сигнал: 3× «не знаю»; «надо поднять отчёт / спросить»; просьба пропустить;
вопрос требует разбора рынка.

1. `AskUserQuestion`: «Похоже, это лучше дождаться аналитика. Зафиксируем
   и пойдём дальше?» — «Да, отложим» / «Ещё попробуем» / «Передам сразу».
2. По «да» — в state: `## Открытые вопросы` → `- (**жду аналитика**)
   <вопрос>`.
3. «Записал. Идём дальше?»

Не угадывает, не блокирует другие блоки, не отправляет наружу.

## Полная передача (`--share`)

Когда: явное «передай»; закрыт блок; накопилось 3+ `**жду аналитика**`.

### Подтверждение (обязательно)

> «Я подготовлю для аналитика:
>   — что вы заполнили про бизнес (черновики);
>   — наши заметки и открытые вопросы;
>   — короткий пересказ что собрали и где остановились;
>   — полный текст нашей сессии.
>
> Всё поедет в отдельную папку проекта. Отправляем?»

Опции: «Да» / «Сначала покажи» (`--share --preview`) / «Нет».

### Упаковывается

1. `docs/business/` (черновики).
2. `state/` (заметки, `**жду аналитика**`, `## Что я имел в виду`).
3. `client-handoff/summary.md`.
4. `client-handoff/transcripts/<UTC-ts>.md`.

Не упаковывается: `state/_session-log/`; файлы вне перечисленного; ключи
(`git add` адресный).

### Git-механика

1. `git branch --show-current`.
2. На `main` → `git switch -c client/<UTC-ts>` (`YYYYMMDDTHHMMSS`); уже на
   `client/*` → продолжить.
3. Сгенерировать `summary.md` + `transcripts/<ts>.md`.
4. `git add` адресно (`docs/business/`,
   `.claude/skills/business-deep-dive-for-business/state/`,
   `client-handoff/`).
5. `git commit -m "docs(handoff): business client session <UTC-ts>"`.
6. `git push -u origin client/<UTC-ts>`.
7. Удалить локально `state/_session-log/<этой-ts>.md`.

### Если git-hook падает

**Не** `--no-verify`. Через `AskUserQuestion`: «Техническая загвоздка:
<текст>. Исправить / пауза?» По «попробуй» — починить корректно, повторить.

### После push

К `**жду аналитика**` добавить `**отправлено: client/<UTC-ts>**`; удалить
`_session-log/<ts>.md`; дать клиенту текст для пересылки (3-5 строк, от
его лица).

## Формат `summary.md`

```markdown
# Передача аналитику — профиль бизнеса

Сессия: <UTC-ts> · Ветка: `client/<UTC-ts>`

## Что собрали
- <чем занимается, как зарабатывает, кого обслуживает>

## Текущие числа
- <если назвали — с датой/источником; если нет — «уточнить»>

## Где остановились
- <текущая тема>

## Открытые вопросы для аналитика
- <рынок/конкуренты, недостающие числа>

## Где смотреть
- `docs/business/` · заметки в state · `client-handoff/transcripts/<ts>.md`
```

## Формат transcript

```markdown
# Лог сессии <UTC-ts>

## Вопрос (блок: <бизнес-название>)
<текст>
### Ответ
<ответ клиента>
...
```

Последовательно, без редактирования, forward-only.
