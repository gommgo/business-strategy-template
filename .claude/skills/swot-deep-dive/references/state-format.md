# Формат заметок `state/`

Память скилла — рабочее состояние знания о сущности. Не журнал.
Forward-only.

## Расположение

```
.claude/skills/swot-deep-dive/state/
├── factor/<slug>.md
└── bet/<slug>.md
```

Заметки лежат **рядом со скиллом**, не в `docs/swot/`. Каталоги создаются
по требованию.

## Шаблон kind-заметки

```markdown
---
kind: bet
slug: online-booking-push
ref: docs/swot/bet.md#online-booking-push
---

## Открытые вопросы
- (**blocker**) До какой цели доводим — удержание или конверсия? От этого
  зависит promoted-to.

## Доменные решения
- Баланс факторов = сильный бренд (strength) × спрос на онлайн (trend),
  потому что именно эта пара объясняет «за счёт чего шаг».

## Что копать дальше
- После заведения goal в Карте гипотез — проставить promoted-to.
```

Frontmatter: `kind` (`factor`/`bet`), `slug`, `ref`.

## Секции (все опциональны)

- **`## Открытые вопросы`** — незакрытые смысловые вопросы, одна строка
  каждый. Префикс/суффикс `**blocker**` блокирует `draft → stable`.
  Закрытый вопрос **удаляется** (не зачёркивается). Пусто → удалить секцию.
- **`## Доменные решения`** — неочевидные смысловые решения, не лезущие в
  таблицу. Форма «⟨что выбрано⟩ — ⟨почему⟩». Без «было/стало», без дат.
  Растворилось в записи → удалить.
- **`## Что копать дальше`** — локальные следующие шаги по сущности.
  Выполнен → удалить строку.

## Жизненный цикл

- **Создаётся** только когда есть что записать (≥1 непустая секция).
- **Перезаписывается** свободно.
- **Удаляется**: все секции пусты → файл; запись удалена каскадом → файл.
- **Не аккумулировать** журнал (история — в git).

## Особый случай: `_phase-jump.md`

`state/<phase>/_phase-jump.md` фиксирует решение перепрыгнуть фазу (напр.
`state/bet/_phase-jump.md` — «начали со ставки, факторы до-насытим позже»)
как доменное решение. Не блокер.

## Единый контекст: read-only видимость соседних state

Для единой картины скилл read-only смотрит соседние `state/`: бизнес-слой
(`../business-deep-dive*/state/` — профиль, конкуренты, реестр проблем),
разведку AJTBD (`../segment-deep-dive*/state/`,
`../job-graph-deep-dive*/state/` — трения и сегменты, питающие факторы) и
Карту гипотез (`../hypothesis-map-deep-dive/state/` — куда доводятся
ставки). **Писать в чужой state запрещено.**

При чтении клиентского state маркер `**жду аналитика**` трактуй как
**blocker-кандидат** — семантический эквивалент аналитического `**blocker**`.
