# shared-lib

> Сквозные утилиты поверхности без доменной привязки: локали (i18n),
> observability-потребности, generic-хелперы. Здесь — **что** нужно
> поверхности; **чем** это реализуется (библиотеки, файлы) — платформа
> фронт-форка (`docs/stack/`).

## i18n

- `locale` — код локали (`ru`, `en`) · строка · обяз.
- `роль` — `default` \| `supported` · enum · обяз.
- `status` — зрелость записи · `draft | stable` · обяз.

| locale | роль | status |
|---|---|---|
| `ru` | `default` | `draft` |
| `<locale>` | `supported` | `draft` \| `stable` |

Поверхность одноязычна — таблица из одной строки `default`.

## Состав

Generic-утилиты, наличие которых — осознанное решение поверхности
(observability, конфиг, testing-обвязка). Хелперы-однострочники сюда не
заносятся — они появляются в коде по мере надобности.

- `slug` — идентификатор утилиты/группы · строка-идентификатор · обяз.
- `name` — человекочитаемое имя · строка · обяз.
- `description` — зачем поверхности · строка · обяз.
- `status` — зрелость записи · `draft | stable` · обяз.

| slug | name | description | status |
|---|---|---|---|
| `<slug>` | <имя> | <зачем> | `draft` \| `stable` |

## Что shared-lib НЕ

- ❌ Выбор библиотек и версий — `docs/stack/` фронт-форка.
- ❌ Доменная логика — она живёт в слайсах.
- ❌ Каталог всех хелперов кода — только осознанные решения поверхности.
