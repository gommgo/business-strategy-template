# features

> Сценарий (feature) — action-oriented слайс: законченное действие
> пользователя, дающее результат (войти, оформить заказ, сменить тему).
> Источник — ситуация (situation) своей поверхности. На `slug` ссылаются
> `pages.features` и `widgets.features`.

## Критерии feature

1. **Есть ситуация-источник.** `situation` указывает на запись в
   `interface/<surface>/situation.md` — фича не выдумывается без шага
   деятельности.
2. **Action-oriented.** Отвечает на «что делает пользователь и что
   меняется», не «что за вещь» (это entity).
3. **Имя — по сценарию источника.** Slug читается как действие
   (`login`, `submit-order`), не аббревиатура.
4. **Опирается только на entities.** `entities` перечисляет сущности из
   `entities.md`; другой фичи в зависимостях нет (cross-feature запрещён —
   общее поднимается в entities/shared или композируется в page/widget).

## Что feature НЕ

- ❌ Сущность данных («заказ») — это entity.
- ❌ Целый экран («страница профиля») — это page.
- ❌ Микро-взаимодействие без результата («ховер по кнопке») — это craft
  компонента.
- ❌ Зависимость от другой feature — cross-feature запрещён.

## Тест-критерий

«Пользователь совершает это как законченное действие с результатом — и оно
восходит к ситуации из interface?»

- «**Войти в систему**» (есть ситуация `login`) → `login` ✅
- «**Заказ**» — вещь → entity ❌
- «**Экран настроек**» — маршрут → page ❌

## Колонки

- `slug` — идентификатор сценария · строка-идентификатор · обяз.
- `name` — человекочитаемое имя действия · строка · обяз.
- `description` — что делает пользователь · строка · обяз.
- `situation` — ситуация-источник · реф → `interface/<surface>/situation.md` · обяз.
- `entities` — задействованные сущности · массив ссылок → `entities` (или `—`) · опц.
- `результат` — что меняется по завершении · свободный текст · обяз.
- `status` — зрелость записи · `draft | stable` · обяз.

| slug | name | description | situation | entities | результат | status |
|---|---|---|---|---|---|---|
| `<slug>` | <имя> | <что делает> | `<situation>` | [`<entity>`] \| — | <изменение> | `draft` \| `stable` |
