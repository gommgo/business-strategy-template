# pages

> Маршрут (page) — слайс «1 page = 1 route»: адресуемое место поверхности с
> минимальной композицией из widgets/features/entities. Источник — экран
> (screen) своей поверхности: путь и доступ page берёт из его маршрута и
> доступа. `pages.widgets` / `pages.features` / `pages.entities` —
> канонические источники использования (зеркало — `widgets.pages`).

## Критерии page

1. **Есть экран-источник.** `screen` указывает на экран
   `screens/<surface>/screens/<slug>/` — page не выдумывается без экрана.
2. **Путь — маршрут экрана.** `path` совпадает с `route` экрана-источника,
   параметры пути — его `params`. Состояние в адресе (`url-state` экрана)
   код читает из экрана — своей колонки у page нет.
3. **Доступ — доступ экрана.** `guard` совпадает с `access`
   экрана-источника: `public` · `authenticated` · роли — `who` экрана при
   `access: roles`. Роль-участник становится ролью доступа через `access`
   маршрута, а не через `who` как список прав.
4. **Композиция, не логика.** Page собирает widgets/features/entities;
   собственной бизнес-логики не описывает.
5. **Pages-first.** Блок, живущий на одной page, остаётся её частью — в
   widget не выносится.

## Что page НЕ

- ❌ Переиспользуемый блок — это widget (при ≥2 page-референсах).
- ❌ Сценарий действия — это feature.
- ❌ Модальное окно без адреса (маршрут экрана `modal:<имя>`) и шаг внутри
  экрана — композиция самого экрана (screens), а не page.

## Тест-критерий

«Сюда можно прийти по адресу, и путь и доступ совпадают с экраном из
screens?»

- «**/orders** — список заказов» (есть screen `orders` с `route: /orders`)
  → `orders` ✅
- «**Фильтр заказов**» — часть экрана → блок/widget ❌
- «**/admin/orders**», когда маршрут экрана `orders` — `/orders` → путь
  расходится с экраном ❌

## Колонки

- `slug` — идентификатор маршрута · строка-идентификатор · обяз.
- `name` — человекочитаемое имя · строка · обяз.
- `description` — что здесь происходит · строка · обяз.
- `screen` — экран-источник · реф → `screens/<surface>/screens/<slug>/` · обяз.
- `path` — маршрут = `route` экрана `screen` с его параметрами (`/orders/:id`) · строка · обяз.
- `guard` — доступ = `access` экрана `screen` · `public` \| `authenticated` \| роли — реф → `interface/<surface>/who.md` (`who` экрана при `access: roles`) · обяз.
- `widgets` — используемые widgets · массив ссылок → `widgets` (или `—`) · опц.
- `features` — используемые сценарии · массив ссылок → `features` (или `—`) · опц.
- `entities` — используемые сущности · массив ссылок → `entities` (или `—`) · опц.
- `status` — зрелость записи · `draft | stable` · обяз.

| slug | name | description | screen | path | guard | widgets | features | entities | status |
|---|---|---|---|---|---|---|---|---|---|
| `<slug>` | <имя> | <что происходит> | `<screen>` | </path> | `public` \| `authenticated` \| `<who>` | [`<widget>`] \| — | [`<feature>`] \| — | [`<entity>`] \| — | `draft` \| `stable` |
