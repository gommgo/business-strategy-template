# client-onboarding — комплект онбординга заказчика

**[META / handoff]** Это не аналитический артефакт, а готовый комплект,
который мы (sftbmb) отдаём заказчику, чтобы он за ~10 минут поставил
**Claude Desktop**, скачал свой форк `<org>/docs` и сам поработал через
`/entrypoint-for-business` (homework: профиль бизнеса, проблемы, продукт).

Заказчик получает **один** файл под свою ОС:

| Файл | Кому |
|---|---|
| [`windows.md`](./windows.md) | заказчику на Windows |
| [`macos.md`](./macos.md) | заказчику на Mac |

Каждый файл **самодостаточен** — заказчику не нужно читать соседние.

## Как отправлять (чек-лист для нас)

1. **Подставить адрес репозитория.** В файле один плейсхолдер —
   `<ВАШ-АДРЕС-РЕПОЗИТОРИЯ>`. Замените на HTTPS-адрес форка заказчика,
   напр. `https://git.sftbmb.ru/<org>/docs.git`. Транспорт — **HTTPS**
   (логин/пароль), не SSH: под это написана вся инструкция.
2. **Подставить контакт.** Плейсхолдер `<КОНТАКТ>` в блоке «Если что-то
   пошло не так» → ваш канал поддержки (телеграм/почта).
3. **Креды — отдельным сообщением, не в файле.** Логин/пароль к Gitea
   заводим заказчику с доступом только к его `<org>/docs` и шлём вне этого
   md. В сам файл секреты не вписываем.
4. **Доступ к Claude.** Запуск Code-вкладки требует **платного плана
   Claude (Pro/Max/Team/Enterprise)** — без него локальные сессии не
   работают. Решите заранее: заказчик использует свой план или мы выдаём
   доступ; в файле это оставлено как «согласуем».

## Что заказчик делает по инструкции

`winget`/`brew`/`.dmg` ставят **Claude Desktop** + **Git** → `git clone`
по нашим кредам тянет форк → **Code → New session → Local → Select
folder** открывает папку → заказчик пишет `/entrypoint-for-business`
(единый вход — оркестратор сам разложит разговор по темам) → по
завершении говорит «передай аналитику», и скилл пушит наработанное в
единую ветку `client` (`--share`-механизм клиентского оркестратора;
доступ к репозиторию скилл спрашивает один раз и сохраняет; см.
`references/escalation.md`).

Desktop и CLI — один движок и общий конфиг (CLAUDE.md, skills, settings),
так что `.claude/skills/entrypoint-for-business` доступен в Code-вкладке как
слэш-команда.
