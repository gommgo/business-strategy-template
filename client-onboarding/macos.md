# Запуск за 10 минут — Mac

Привет! Это короткая инструкция: поставить приложение Claude, скачать вашу
рабочую папку и начать разговор с ассистентом — он будет задавать вопросы
по-русски и записывать ваши ответы. Всё под нашим присмотром, **сломать
ничего нельзя**. Займёт минут десять.

---

## Что мы пришлём вам отдельным сообщением

- 🔗 **Адрес вашей рабочей папки** — длинная ссылка вида
  `https://git.stit.tech/.../strategy.git`. Её надо будет подставить в команду
  ниже вместо `<ВАШ-АДРЕС-РЕПОЗИТОРИЯ>`.
- 🔑 **Логин и пароль** для скачивания этой папки.
- 👤 **Доступ к Claude.** Для работы нужен платный тариф Claude (Pro или
  выше). Если у вас его ещё нет — просто напишите нам, согласуем.

> Логин и пароль из этой инструкции — это доступ **к папке**, а не к
> Claude. Это разные вещи, не перепутайте.

---

## 1. Поставить приложение Claude

Откройте <https://claude.ai/download>, скачайте файл для Mac и установите
как обычное приложение: откройте скачанный `.dmg` и перетащите значок
**Claude** в папку **Программы (Applications)**.

> С Homebrew? Можно одной строкой в Терминале:
> `brew install --cask claude`

---

## 2. Скачать рабочую папку

Откройте **Терминал**: нажмите `Cmd + Пробел`, наберите `Терминал`
(или `Terminal`), **Enter**.

Вставьте эти две строки, подставив **адрес, который мы прислали**, вместо
`<ВАШ-АДРЕС-РЕПОЗИТОРИЯ>`, и нажмите **Enter**:

```bash
cd ~/Desktop
git clone <ВАШ-АДРЕС-РЕПОЗИТОРИЯ> docs
```

- Если выскочит окошко **«Установить инструменты разработчика»** — нажмите
  **Установить (Install)**, дождитесь конца и повторите команду. Так на
  Mac ставится Git (отдельно качать не нужно).
- Git спросит **Username** и **Password** — введите логин и пароль,
  которые мы прислали (при вводе пароля символы не отображаются — это
  нормально, печатайте вслепую и нажмите Enter).

✅ На **рабочем столе** появится папка `docs`. Это и есть ваша рабочая
папка.

---

## 3. Открыть папку в Claude и начать

1. Запустите **Claude** (из папки Программы или через `Cmd + Пробел` →
   `Claude`) и **войдите** в свой аккаунт.
2. Вверху по центру выберите вкладку **Code**.
   - Если просит оформить подписку — нужен платный тариф Claude, напишите
     нам.
3. Нажмите **New session** → выберите **Local** → **Select folder** →
   укажите папку `docs` на рабочем столе.
4. Внизу, в строке ввода, напишите команду и нажмите **Enter**:

   ```
   /entrypoint-for-business
   ```

   (или просто наберите `/` — появится список, выберите нужную). Дальше
   Claude сам поведёт вас вопросами по-русски.

> Команда одна — Claude сам разложит разговор по темам:
>
> | Команда | О чём поговорим |
> |---|---|
> | `/entrypoint-for-business` | всё про ваш бизнес, клиентов и продукт, одной командой; ИИ сам разложит по темам |

---

## Когда наговорились — передать нам

Просто напишите Claude:

> давай передадим всё аналитику

Claude спросит подтверждение и отправит нам всё, что вы наработали.
Больше ничего делать не нужно.

---

## Что вы увидите по ходу (это нормально)

- Иногда Claude показывает кнопки **Accept / Reject** — это он спрашивает
  разрешение записать вашу заметку. Смело жмите **Accept**: вы ничего не
  ломаете, всё у нас под ревью.
- Отвечайте обычными словами. Можно приложить сайт, презентацию или PDF —
  перетащите файл прямо в окно.
- Не знаете, что ответить — так и напишите Claude, он подскажет или
  отложит вопрос для аналитика.

---

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| Окошко про «инструменты разработчика» | Нажмите **Установить**, дождитесь конца, повторите команду `git clone` |
| Git не принимает пароль | Проверьте Caps Lock и раскладку; логин/пароль — те, что прислали мы (это доступ к **папке**, не к Claude) |
| Вкладка **Code** просит upgrade/подписку | Нужен платный тариф Claude — напишите нам |
| `command not found: brew` (если шли через Homebrew) | Поставьте Claude кнопками с <https://claude.ai/download> |
| Совсем застряли | Напишите нам: **<КОНТАКТ>** — поможем |
